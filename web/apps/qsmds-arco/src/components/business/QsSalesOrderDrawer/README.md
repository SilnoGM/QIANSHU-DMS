# QsSalesOrderDrawer

销售订单专用只读抽屉，以 `FaDrawer` 实现自定义订单摘要 Header、固定 Footer 和滚动正文；不使用 `QsSalesOrderDesc`，后者继续服务创建/编辑核对页面。

- 页面适配器负责请求、取消请求、登录身份变化和过期响应防护；组件接收现有 DTO，触发 `reload` 与开关事件。
- 默认打开订单详情信息 Tab；换单或重新打开重置 Tab。收款和订单凭证分别使用单展开手风琴，默认折叠。
- 收款凭证仅跟随其收款记录，订单凭证区仅展示未解除的出单凭证和签收单。作废收款保留状态与原因，避免被误认为有效收款。
- 产品主图按行 ID 使用列表授权预览，仅在列表与详情订单 ID 一致时传入。
- 变更记录合并现有 `statusHistory` 和 `amountRevisions`，按时间倒序显示。当前详情 API 不提供产品名称、备注等内容修改明细，组件不推测此类历史。
- 金额使用 `AmountDisplay` 展示原始精度，图片用 `ImageGroup` 在展开详情内预览。折叠触发按钮内不嵌套预览按钮。
- 打印按钮仅触发指定轻提示，不调用打印或外部业务接口。
