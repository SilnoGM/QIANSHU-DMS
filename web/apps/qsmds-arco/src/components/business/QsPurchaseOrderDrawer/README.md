# QsPurchaseOrderDrawer

采购订单正式详情抽屉，参照 `QsSalesOrderDrawer` 的视觉与交互，不复用创建页的 `QsPurchaseOrderDesc`，也不修改销售组件。

## 展示结构

- 顶部：采购图标、订单编号、CNY 标签、采购日期和关闭按钮。
- 订单详情信息：基础信息与三维状态、供应商与销售来源、采购产品与真实采购价/数量/行小计、采购总价/定金/尾款/已付/未付、采购唛头和备注、实际付款记录（展开查看对应付款凭证）。
- 订单变更记录：仅聚合接口已持久化的状态历史，按时间倒序；不编造金额或产品变更记录。
- 底部：紧凑打印按钮，仅显示后续版本推出的轻提示。

## 数据与职责

- 父页面保留请求、取消、权限和写入生命周期；组件只接收详情与权限，向上派发已有付款/凭证操作事件。
- 每次打开读取最新详情；产品主图从详情 `lineSummary.previews` 按采购行 ID 匹配，不依赖旧列表快照。
- 采购可无凭证付款；凭证按 `paymentId` 关联，仅在对应付款记录内展示，保留预览、下载和受权限控制的解除关联操作，不再重复展示独立凭证小节。无凭证时显示“本次付款未关联凭证”；解除关联后保留历史信息但不预览、不下载。
- 状态、金额及记录数量均直接使用服务端字段，不做本地财务重算。
- 付款记录默认折叠、最多展开一条；展开隐藏小图、收起恢复，180ms 透明度与 FLIP 位移动画支持减少动态效果。
- 使用主题 token、单一正文滚动容器、键盘 Tabs、关闭焦点恢复；窄屏改为单列，不影响销售抽屉。
