# QsShipmentStorageCard

运营「货物寄仓」卡片的展示组件。卡片只负责渲染寄仓记录，列表请求、状态计数、详情抽屉与操作结果由页面负责。

## 组件契约

- `record`：寄仓列表 DTO，包含状态、位置、产品摘要、唛头、来源单据、成本与转入时间。
- `currencies`：传给 `AmountDisplay` 的币种描述符。
- `statusLabel` / `statusClass`：由页面复用寄仓域状态逻辑传入，避免组件重复维护状态语义。
- `applyDisabledReason`：`null` 表示可申请调货；非空时按钮置灰，并通过 tooltip 展示原因。
- 事件：`detail`、`apply`，组件不跳转、不调接口。
- 卡片自身是容器（`container-type: inline-size`），宽窄形态按卡片宽度切换；唛头/来源行使用 `ResizeObserver` 和隐藏测量层按实际宽度收敛。

## 展示口径

- 产品只展示第一条，其他数量显示「另有 N 项产品，可在详情中查看」；仅一条时提示「只有 1 项产品，可在详情中查看」。产品名单行省略，悬停读取完整名称。
- 产品主图点击复用项目 `useFaImagePreview` 打开原图预览；无主图时显示占位图标。
- 产品面板与成本面板之间保留 1rem 列间距，成本分割线不与产品面板贴边。
- 成本仅展示总计；采购成本、包装成本与完整产品留在现有详情抽屉。
- 装柜唛头按值区实际宽度选择最大可容纳数量（如 3 个、2 个 +1、1 个 +2），剩余显示 `+N`；复制和悬停使用完整唛头。
- 来源销售单/采购单在「人员 + 单号」一行放不下时自动隐藏人员，仅保留单号；宽度恢复后自动恢复人员。
- 卡片顶部展示转入寄仓时间与原单客户，两者统一 12px 字号与基线；底部只保留详情与申请调货，不重复时间。
- 编号、唛头、来源单号均以文字本身作为复制入口，点击复制；悬停/聚焦时显示点状下划线；人员显示复用 `QsPersonDisplay`。
- 海外/内地使用不同颜色的位置标签；产品编号使用浅绿色标签，缺编号时显示「自定义产品」。

## 响应式

- 卡片宽度 ≥ 33rem：产品/成本左右排列；唛头与来源组成 2×2 事实网格，标签列等宽；来源优先显示人员 + 单号，超宽时隐藏人员只留单号。
- 卡片宽度 < 33rem：产品与成本、事实网格、底栏动作依次堆叠。
- 页面列表容器宽度 ≥ 68rem 时固定两列，低于该宽度单列；每行最多两个卡片，单项结果占满整行。
