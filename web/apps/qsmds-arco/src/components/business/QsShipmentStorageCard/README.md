# QsShipmentStorageCard

运营「货物寄仓」卡片的展示组件。卡片只负责渲染寄仓记录，列表请求、状态计数、详情抽屉与操作结果由页面负责。

## 组件契约

- `record`：寄仓列表 DTO，包含状态、位置、产品摘要、唛头、来源单据、成本与转入时间。
- `currencies`：传给 `AmountDisplay` 的币种描述符。
- `statusLabel` / `statusClass`：由页面复用寄仓域状态逻辑传入，避免组件重复维护状态语义。
- `applyDisabledReason`：`null` 表示可申请调货；非空时按钮置灰，并通过 tooltip 展示原因。
- 事件：`detail`、`apply`，组件不跳转、不调接口。
- 卡片自身是容器（`container-type: inline-size`），宽窄形态按卡片宽度切换。

## 展示口径

- 产品只展示第一条，其他数量显示「另有 N 项产品，可在详情中查看」；仅一条时提示「只有 1 项产品，可在详情中查看」。
- 成本仅展示总计；采购成本、包装成本与完整产品留在现有详情抽屉。
- 装柜唛头最多展示两个，剩余显示 `+N`；复制仍使用完整唛头。
- 卡片顶部展示转入寄仓时间，底部只保留详情与申请调货，不重复时间。
- 复制按钮统一复用 `CopyCellButton`，人员显示复用 `QsPersonDisplay`。

## 响应式

- 卡片宽度 ≥ 33rem：产品/成本左右排列，唛头/来源两列。
- 卡片宽度 < 33rem：产品与成本、唛头与来源、底栏动作依次堆叠。
- 页面卡片网格使用 `repeat(auto-fit, minmax(min(100%, 33rem), 1fr))`，由可用宽度决定单列或双列，不依赖固定视口断点。
