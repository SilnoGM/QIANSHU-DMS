# QsOrderProductLineEditor

`QsOrderProductLineEditor` 是业务中立的订单产品明细编辑器。调用方负责固定币种、
候选产品 loader、字段标题、最终领域校验和保存；组件只处理数据库/临时产品行、
原子应用选择结果、价格数量编辑、删除、行小计与两项汇总。

数据库产品缺少当前订单币种标准价时显示“暂无”；数据库产品和临时产品的新行都
以 `0.00` 初始化本单售价，且不会复制标准价。调用方负责校验用户输入最多两位
小数；缺少标准价的产品不计入标准价汇总，汇总区域同时提示未计入的产品数量。

产品选择器以当前数据库产品行为会话初始值，确认时把新增、累计数量和删除变更
一次性应用到明细；取消选择器不会修改任何数据库产品行，临时产品也不参与同步。

数据库产品不可在行内切换，临时产品不会生成产品主数据、产品编号、主图或标准价。
产品名称和备注均保持单行，Hover 与键盘聚焦通过 `FaTooltip` 展示完整内容。宽表
只在组件内部横向滚动，不隐藏任何业务列。
