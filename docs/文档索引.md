# 千树 DMS 文档索引

本文件是项目正式文档的唯一索引，也是当前指导文档与工程归档的统一入口。新增、移动或归档正式文档时，必须同步更新对应索引。

## 全局文档

- [项目工程组织方案](./全局文档/项目工程组织方案.md)：定义仓库边界、目录职责、技术栈、接口契约、CI 与发布模型。
- [开发工作流](./全局文档/开发工作流.md)：提供 runtime 前置、安装启动、变更流程、契约与数据库规则、验证矩阵、Git 协作和异常诊断的日常操作入口。
- [发布与版本管理](./全局文档/发布与版本管理.md)：提供统一产品版本准备、Annotated Tag、Release 附件校验、Draft 恢复、部署边界和管理员配置的操作手册。

## 前端文档

- [前端架构](./前端文档/前端架构.md)：定义 Web 独立工作区、技术栈、目录职责、依赖方向和移植发布边界。
- [应用边界规范](./前端文档/应用边界规范.md)：明确正式业务应用、参考应用和共享包的写入及依赖规则。
- [接口接入规范](./前端文档/接口接入规范.md)：记录 OpenAPI 快照与类型生成、Axios response、统一错误、Blob、重试、取消及 fake 接入规则。

## 后端文档

- [后端架构](./后端文档/后端架构.md)：记录 Server 独立依赖域、NestJS HTTP 基线、Prisma 生命周期、健康检查与测试边界。

## 工程归档

- [工程归档索引](./工程归档/归档索引.md)：按任务进入已完成项目、故障修复和文档治理的历史资料。

工程归档内容仅用于历史追溯，不作为当前执行依据。日常开发必须优先使用本页列出的当前指导文档。

## 文档约定

- `docs/` 下的目录和 Markdown 文件使用中文名。
- 文档正文整体使用中文，代码、命令、路径、包名、API、字段、错误码和日志保留英文。
- 当前指导文档与工程归档分层维护；根索引只展开当前指导文档，不逐篇列出阶段设计、实施计划或故障资料。
- 工程归档按任务命名并保留完整上下文，不按文档类型拆散任务。
- 新增、移动或归档文档时，必须同时核对并同步本索引与工程归档索引。
- 只索引真实存在的文档，不创建空文档或空目录。
