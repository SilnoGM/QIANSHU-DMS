# 服务器发布归档硬链接根因修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development`（推荐）或 `executing-plans` 按任务执行本计划。生产代码修改必须遵循 RED → GREEN，所有步骤使用 checkbox 跟踪。

**Goal:** 让 GNU tar 在创建 Web/Server release archive 时把 filesystem hardlink 序列化为 regular file，从而使 Ubuntu 24.04 x64 的真实 Server packaging 通过，同时保持 inspector 对 hardlink archive member 的拒绝策略。

**Architecture:** 只修改共享 `tarArguments()` 的创建参数，不修改 archive inspector、extractor、size limit、cleanup 或依赖布局。单元测试固定 argv 契约，`linux/amd64` 容器和 Draft PR CI 验证真实 `pnpm deploy → prune → validate → tar → inspect → digest` 链路。

**Tech Stack:** Node.js 24.16.0、`node:test`、pnpm 11.9.0、GNU tar、Docker `linux/amd64`、GitHub Actions Ubuntu 24.04 x64。

以下命令必须作为同一个 shell block 执行，使 `trap` 在任意失败路径都清理容器：

```bash
set -e
container=$(docker create --platform linux/amd64 node:24.16.0-bookworm sleep infinity)
cleanup() {
  docker rm -f "$container" >/dev/null 2>&1 || true
}
trap cleanup EXIT

docker start "$container" >/dev/null
docker exec "$container" mkdir -p /workspace
git archive HEAD | docker cp - "$container":/workspace
docker exec -w /workspace "$container" corepack enable
docker exec -w /workspace "$container" \
  corepack prepare pnpm@11.9.0 --activate
docker exec -w /workspace "$container" \
  pnpm -C server install --frozen-lockfile
docker exec -w /workspace "$container" \
  pnpm -C server build
docker exec -w /workspace "$container" \
  node --run release:package:server -- \
  --tag v0.1.1 \
  --output /tmp/release-server-ci
docker exec "$container" node --input-type=module --eval '
import fs from "node:fs"
import { gunzipSync } from "node:zlib"

const archive = "/tmp/release-server-ci/qsmds-server-v0.1.1-linux-x64.tar.gz"
const gzip = fs.readFileSync(archive)
const tar = gunzipSync(gzip)
const counts = new Map()
let offset = 0

while (offset + 512 <= tar.length) {
  const header = tar.subarray(offset, offset + 512)
  if (header.every(byte => byte === 0)) break
  const type = header[156] === 0 ? "0" : String.fromCharCode(header[156])
  counts.set(type, (counts.get(type) ?? 0) + 1)
  const sizeText = header.subarray(124, 136)
    .toString("ascii")
    .replace(/[\0 ]+$/u, "")
    .trimStart()
  const size = Number.parseInt(sizeText, 8)
  offset += 512 + Math.ceil(size / 512) * 512
}

console.log("archive-bytes=" + gzip.length)
console.log("tar-bytes=" + tar.length)
console.log("type-counts=" + JSON.stringify(Object.fromEntries(counts)))
if (
  gzip.length > 256 * 1024 * 1024
  || tar.length > 512 * 1024 * 1024
  || (counts.get("1") ?? 0) !== 0
) process.exitCode = 1
'
cleanup
trap - EXIT
```

Expected: packaging CLI 成功；header audit exit `0`；`type-counts` 不包含
`"1"`；`archive-bytes <= 268435456`；`tar-bytes <= 536870912`；一次性容器
最终删除。若 registry 出现 `ECONNRESET` 后最终失败，必须报告为网络失败并重试
验证，不得伪装成代码 GREEN。
