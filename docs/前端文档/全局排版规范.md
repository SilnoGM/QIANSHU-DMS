# 全局排版规范

## 适用范围与真相源

本规范适用于正式应用 `web/apps/qsmds-arco`，用于统一页面标题、正文、表单、按钮、标签、表格、弹窗、结构化数据和移动端卡片的排版语义。

实现真相源按以下顺序确定：

1. `web/apps/qsmds-arco/src/assets/styles/globals.css`：字体家族、基础尺度、根排版和 Fa/Arco 应用级 bridge。
2. `web/uno.config.ts`：全部 `qs-type-*` 语义 shortcut 及静态 fallback。
3. 组件自身的稳定 `data-slot`、`cellClass` 和 slot：把具体内容映射到语义角色。
4. 浏览器 computed style：确认最终级联，不以某一条源码声明代替运行时结果。

字体资源、Unicode 分片、首屏加载、原生 Emoji 和构建产物零残留机制见[全局字体统一设计](./全局字体统一设计.md)。业务页面不得再创建独立字体栈。

## 基本原则

- 普通中文、标题、说明、表单和操作统一使用 `var(--qs-font-sans)`。
- 只有单号、编码、数量、百分比、日期时间、金额等结构化数据使用 `var(--qs-font-mono)`。
- 普通中文重点值使用 `qs-type-body-medium`，不要为了加粗而改用 Mono。
- 排版颜色只消费 `foreground`、`muted-foreground`、`destructive` 等既有主题语义；不得硬编码只适合亮色主题的文字颜色。
- `qs-type-*` 只表达排版，不承载间距、尺寸、背景、边框、圆角或交互。
- 对齐只表达布局。右对齐、列名、显示文案和 Tag variant 都不能作为数据语义的推断依据。
- 显式语义角色应替换同一节点上冲突的 `text-*`、`font-*`、`leading-*` 和 `tracking-*`，避免两套规则竞争。

## 基础 Token

基础 Token 是字号、行高、字重和字距的唯一数值真相源。

### 字号

| Token | 值 | 像素基准 |
| --- | --- | --- |
| `--qs-type-size-xs` | `0.75rem` | `12px` |
| `--qs-type-size-sm` | `0.875rem` | `14px` |
| `--qs-type-size-md` | `1rem` | `16px` |
| `--qs-type-size-lg` | `1.125rem` | `18px` |
| `--qs-type-size-xl` | `1.25rem` | `20px` |
| `--qs-type-size-2xl` | `1.5rem` | `24px` |
| `--qs-type-size-3xl` | `1.875rem` | `30px` |
| `--qs-type-size-4xl` | `2.25rem` | `36px` |

`13px / 18px` 是高密度表头的组件特例，由 `table-header` 直接定义，不扩展为通用基础字号。

### 行高

| Token | 值 | 像素基准 |
| --- | --- | --- |
| `--qs-type-leading-xs` | `1rem` | `16px` |
| `--qs-type-leading-sm` | `1.25rem` | `20px` |
| `--qs-type-leading-md` | `1.5rem` | `24px` |
| `--qs-type-leading-lg` | `1.75rem` | `28px` |
| `--qs-type-leading-xl` | `2rem` | `32px` |
| `--qs-type-leading-2xl` | `2.375rem` | `38px` |
| `--qs-type-leading-3xl` | `2.5rem` | `40px` |

### 字重与字距

| 类型 | Token | 值 |
| --- | --- | --- |
| 字重 | `--qs-type-weight-regular` | `400` |
| 字重 | `--qs-type-weight-medium` | `500` |
| 字重 | `--qs-type-weight-semibold` | `600` |
| 字重 | `--qs-type-weight-bold` | `700` |
| 字距 | `--qs-type-tracking-normal` | `0` |
| 字距 | `--qs-type-tracking-tight` | `-0.025em` |
| 字距 | `--qs-type-tracking-wide` | `0.16em` |

## 语义角色

模板中使用完整类名，例如 `qs-type-page-title`。下表中的颜色名称均指现有主题语义颜色。

| 角色 | 字体 | 桌面规格 | 移动规格 | 颜色与特性 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| `display-title` | Sans | `30/38/600` | `24/32/600` | foreground，`-0.025em` | 组件目录 Hero |
| `auth-display` | Sans | `36/40/700` | 同桌面 | foreground | 登录主标题 |
| `page-title` | Sans | `24/32/600` | `20/28/600` | foreground | 正式页面标题 |
| `section-title` | Sans | `18/28/600` | 同桌面 | foreground | 页面业务区块标题 |
| `component-title` | Sans | `16/24/600` | 同桌面 | foreground | 卡片组、权限分组标题 |
| `compact-title` | Sans | `14/20/600` | 同桌面 | foreground | 移动卡片标题、紧凑小节 |
| `body` | Sans | `14/20/400` | 同桌面 | foreground | 普通正文和普通值 |
| `body-medium` | Sans | `14/20/500` | 同桌面 | foreground | 普通中文重点值 |
| `body-relaxed` | Sans | `14/24/400` | 同桌面 | foreground | 较长说明正文 |
| `description` | Sans | `14/20/400` | 同桌面 | muted | 页面、组件和字段说明 |
| `meta` | Sans | `12/16/400` | 同桌面 | muted | 行号、来源、辅助信息 |
| `compact-label` | Sans | `12/16/500` | 同桌面 | muted | 移动卡片字段名 |
| `form-label` | Sans | `14/20/500` | 同桌面 | foreground | 表单标签 |
| `form-help` | Sans | `12/16/400` | 同桌面 | muted 或 destructive | 帮助信息、校验信息 |
| `form-control` | Sans | `14/20/400` | `16/24/400` | foreground | Input、Textarea、Select |
| `action` | Sans | `14/20/500` | 同桌面 | 继承按钮语义色 | 按钮和操作入口 |
| `action-disabled` | Sans | `14/20/500` | 同桌面 | `opacity: 0.5` | 非原生 disabled 的静态禁用展示 |
| `tag` | Sans | `12/16/500` | 同桌面 | 继承标签语义色 | 普通分类标签、Badge |
| `status-tag` | Sans | `12/16/600` | 同桌面 | 继承业务状态色 | 成功、失败、启用等状态 |
| `dialog-title` | Sans | `18/24/600` | 同桌面 | foreground | Modal、Drawer 标题 |
| `table-header` | Sans | `13/18/600` | 不适用 | muted，`0.01em` | 桌面表头 |
| `data` | Mono | `14/20/400` | 同桌面 | foreground，`tabular-nums` | 数量、百分比、日期时间 |
| `data-emphasis` | Mono | `14/20/500` | 同桌面 | foreground，`tabular-nums` | 单号、编码、金额、数值汇总 |

`form-control` 在小于 `768px` 时使用 `16/24/400`，避免移动浏览器聚焦输入框时自动缩放；从 `768px` 起恢复 `14/20/400`。

## 组件自动映射

### Fa 组件

正式应用通过稳定 `data-slot` 或共享组件内的显式类自动完成以下映射：

| 组件或 slot | 默认角色 |
| --- | --- |
| `FaPageHeader` title | `page-title` |
| `FaPageHeader` description | `description` |
| `[data-slot="button"]` | `action`；原生 disabled 自动 `opacity: 0.5` |
| `[data-slot="label"]`、`[data-slot="form-label"]` | `form-label` |
| FormDescription、FormMessage | `form-help` |
| Input、Textarea、Select trigger | `form-control` |
| `FaTag` | `tag` |
| `FaBadge` | `tag` |
| `FaTable`、普通 table cell | `body` |
| table head | `table-header` |
| table footer | `body-medium` |
| Modal、Drawer title | `dialog-title` |
| Modal、Drawer description | `description` |

普通 Tag 不会自动升级为状态 Tag。业务状态调用点必须显式增加 `qs-type-status-tag`。

### Arco Design Vue

应用级 bridge 只覆盖已确认的字体指标，不改变 Arco 的高度、padding、边框、背景或交互：

| Arco 表面 | 默认角色或规则 |
| --- | --- |
| 普通 `.arco-btn` | `action` |
| `.arco-btn-size-mini` | 保留组件原生 `12px`，只统一 Sans 与 `500` |
| Form label | `form-label` |
| Form extra、message | `form-help` |
| Input、Textarea | `form-control` |
| 普通 Tag | `tag` |
| Modal title | `dialog-title` |
| Modal body | `body` |

Arco 状态 Tag 同样必须在调用点显式增加 `qs-type-status-tag`。

### 应用展示组件

| 组件 | 自动角色 | 使用约束 |
| --- | --- | --- |
| `DateTimeDisplay` | `data` | 保持既有格式、时区、空值和 invalid value 处理 |
| `AmountDisplay` | `data-emphasis` | 保持既有币种、精度、符号和业务颜色 |
| `QsGenericTable` | 表头 `table-header`，普通值 `body` | 具体数据语义由调用方声明 |
| `QsTableStackedLine` | 根节点 `body`，label `meta` | 复合内容通过 `content-class` 指定数据角色 |

## 数据与表格

### 数据分类

| 数据类型 | 角色 | 示例 |
| --- | --- | --- |
| 普通值 | `body` | 路线、负责人、显示名称 |
| 普通中文重点值 | `body-medium` | 事件名称、角色名称、汇总文字 |
| 标识 | `data-emphasis` | 结算单号、角色编码、权限编码、请求 ID |
| 数字 | `data` | 数量、票数、百分比 |
| 日期时间 | `data` 或 `DateTimeDisplay` | 创建时间、最近登录、发生时间 |
| 金额 | `data-emphasis` 或 `AmountDisplay` | 应收、实收、结算金额 |
| 数值汇总 | `data-emphasis` | 合计、平均、总数 |
| 辅助信息 | `meta` | 行号、来源、补充说明 |
| 状态 | `status-tag` | 启用、禁用、成功、失败 |
| 操作 | `action` | 查看、编辑、复核 |

### QsGenericTable

`QsGenericTable` 只提供默认正文排版，不根据数据内容自动猜测语义：

- 单值桌面列优先使用现有 `TableColumn.cellClass`。
- 复合单元格使用 `cell-{columnId}` slot，并在内容节点上显式声明角色。
- 窄屏领域卡片使用 `mobile-row` slot。
- `cellClass` 只作用于桌面 FaTable 的 `<td>`；默认移动卡片仍是 `body`，结构化移动值必须在 `mobile-row` 中显式标注。
- 日期和金额优先使用 `DateTimeDisplay`、`AmountDisplay`。
- 默认汇总 label 使用 `meta`，数值使用 `data-emphasis`。
- `summary-{columnId}` slot 同时覆盖桌面表尾和移动端“当前页汇总”，内容必须兼容两个表面。
- `align: 'right'` 只改变布局，不会自动增加 Mono、字重或 `tabular-nums`。
- 不新增 `semantic` 等公共列字段；现有 `cellClass`、slot 和展示组件已经覆盖语义表达。

正确的单值列：

```ts
const columns: QsGenericTableColumn<Settlement>[] = [
  {
    accessorKey: 'settlementNo',
    cellClass: 'qs-type-data-emphasis',
    id: 'settlementNo',
    title: '结算单号',
  },
  {
    accessorKey: 'shipmentCount',
    align: 'right',
    cellClass: 'qs-type-data',
    id: 'shipmentCount',
    title: '票数',
  },
]
```

正确的复合单元格：

```vue
<template #cell-settlementNo="{ row }">
  <QsTableStackedCell>
    <QsTableStackedLine content-class="qs-type-data-emphasis">
      {{ row.original.settlementNo }}
    </QsTableStackedLine>
    <QsTableStackedLine tone="muted" content-class="qs-type-meta">
      {{ row.original.source }}
    </QsTableStackedLine>
  </QsTableStackedCell>
</template>
```

正确的日期、金额和状态：

```vue
<DateTimeDisplay :value="row.updatedAt" />
<AmountDisplay :value="row.amount" currency="CNY" />
<FaTag class="qs-type-status-tag" variant="outline">
  {{ row.statusLabel }}
</FaTag>
```

## 移动端卡片

移动端保持现有 Card、Drawer、断点和业务动作，只显式标注信息角色：

| 卡片内容 | 角色 |
| --- | --- |
| 卡片标题 | `compact-title` |
| 字段名 | `compact-label` |
| 普通值 | `body` |
| 普通中文重点值 | `body-medium` |
| 编码、单号 | `data-emphasis` |
| 数量、百分比 | `data` |
| 日期时间 | `data` |
| 金额、数值重点结果 | `data-emphasis` |
| 状态 | `status-tag` |
| 操作 | `action` |

```vue
<dl class="qs-type-body m-0 gap-3 grid">
  <div class="gap-2 grid grid-cols-[5.75rem_minmax(0,1fr)]">
    <dt class="qs-type-compact-label">
      创建时间
    </dt>
    <dd class="qs-type-data m-0">
      {{ formatDate(row.createdAt) }}
    </dd>
  </div>
  <div class="gap-2 grid grid-cols-[5.75rem_minmax(0,1fr)]">
    <dt class="qs-type-compact-label">
      显示名称
    </dt>
    <dd class="qs-type-body m-0">
      {{ row.displayName }}
    </dd>
  </div>
</dl>
```

长编码和用户输入内容仍应保留 `break-all`、`break-words` 或 `[overflow-wrap:anywhere]` 等布局保护；排版语义类不能替代溢出处理。

## 正确与错误用法

### 标题

```vue
<!-- 正确：一个稳定语义角色，布局 class 独立保留。 -->
<h1 class="qs-type-page-title m-0">
  用户管理
</h1>

<!-- 错误：语义角色与旧排版 utility 竞争。 -->
<h1 class="qs-type-page-title text-2xl font-bold leading-tight">
  用户管理
</h1>
```

### 普通值与结构化数据

```vue
<!-- 正确 -->
<span class="qs-type-body">{{ routeName }}</span>
<code class="qs-type-data-emphasis">{{ orderNo }}</code>
<span class="qs-type-data">{{ completionRate }}%</span>

<!-- 错误：把所有右对齐内容都推断为重点数据。 -->
<span class="text-right font-medium font-mono">{{ routeName }}</span>
```

### 主题颜色

```vue
<!-- 正确：角色随主题变化。 -->
<p class="qs-type-description">{{ helpText }}</p>

<!-- 错误：硬编码亮色文字。 -->
<p class="text-[#71717B]">{{ helpText }}</p>
```

### 标签与状态

```vue
<!-- 普通分类标签 -->
<FaTag variant="secondary">{{ categoryName }}</FaTag>

<!-- 明确业务状态 -->
<FaTag class="qs-type-status-tag text-primary" variant="outline">
  启用
</FaTag>
```

不得因为 `variant="destructive"`、`variant="secondary"` 或某个颜色类自动判断标签是状态。排版角色与业务颜色分别由调用点明确表达；`primary` 也不能替代成功色语义。

### 禁止做法

- 不在页面或业务组件中重复声明 `Noto Sans SC`、`Noto Sans Mono` 或系统字体栈。
- 不用全局 `!important` 强制覆盖所有组件排版。
- 不按列名、文案、对齐方式或 Tag variant 推断语义。
- 不给所有 `<code>`、所有数字字符或所有表格单元格统一套 Mono。
- 不给 `QsGenericTableColumn` 新增公共 `semantic` 字段。
- 不为了排版修改日期、金额、空值、时区、精度或业务状态格式化。
- 不通过排版 bridge 修改组件高度、padding、颜色、焦点、loading、disabled 或点击行为。

## 新页面接入

新增或迁移页面时按以下顺序处理：

1. 先把内容分类为标题、正文、说明、表单、操作、标签、普通值或结构化数据。
2. 优先使用自动映射的 Fa/Arco 组件，不在每个调用点重复声明基础排版。
3. 只有需要区分业务语义的节点才显式增加 `qs-type-*`。
4. 表格通过 `cellClass`、slot 或展示组件表达语义；移动卡片单独标注字段名和值。
5. 保留原有布局、响应式断点、权限判断、格式化、Drawer/Modal 生命周期和业务动作。
6. 为新增的稳定消费关系补充源码契约测试；修改共享组件时同时验证参考应用。
7. 在桌面与 `390×844`、亮色与受控暗色状态检查 computed style、禁用透明度和水平溢出。

验收至少确认：

- `font-family`、`font-size`、`font-weight`、`line-height` 和 `letter-spacing`。
- 结构化数据的 `font-variant-numeric: tabular-nums`。
- 文字颜色来自当前主题语义。
- disabled action 的 `opacity: 0.5`。
- `document.documentElement.scrollWidth <= document.documentElement.clientWidth`。
- `document.fonts.check()` 能确认 Sans 与 Mono 已加载。
- 浏览器控制台没有新增 warning/error。

## 工程边界

- 不修改 `web/examples/**` 的默认字体和展示风格；共享组件变更只触发其回归验证。
- 不修改 `node_modules` 或 Arco 第三方 CSS；以正式应用后加载的 bridge 和 computed style 为准。
- 不修改 `server/`、公共 API、数据结构或数据库 schema。
- 不新增第三套业务字体，不用 `font-spider` 代替既有字体资产与构建守卫。
