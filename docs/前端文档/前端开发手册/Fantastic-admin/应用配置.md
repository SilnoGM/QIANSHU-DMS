# 应用配置

本册只记录 Fantastic-admin `6.3.0` 在正式应用中的真实配置类型、默认值和覆盖值。官网页面用于理解用途；发生差异时，以 `web/packages/settings/src/types.ts`、`default.ts` 和 `web/apps/qsmds-arco/src/settings.ts` 为准。

## 应用配置介绍

上游[《应用配置》](https://fantastic-admin.hurui.me/guide/settings.md)规定每个应用在自身 `src/settings.ts` 写差异配置。本项目的完整入口为 `web/apps/qsmds-arco/src/settings.ts`：

```ts
import { setSettings } from '@fantastic-admin/settings'

export default setSettings({
  menu: {
    mainMenuClickMode: 'smart',
  },
})
```

`setSettings()` 通过 `web/packages/settings/src/utils.ts` 把应用覆盖合并到 `web/packages/settings/src/default.ts`。因此当前有效配置只有一个项目覆盖：`menu.mainMenuClickMode` 从默认 `'switch'` 改为 `'smart'`；其余键使用共享默认值。不要直接编辑 `default.ts` 来做千树 DMS 定制，也不要从官网复制本地类型不存在的旧键。

七个顶层分组及类型真相源如下：

| 分组 | 类型 | 用途 |
| --- | --- | --- |
| `app` | `AppSettings` | 账号、路由、产品级能力、布局、主页、版权、可开放偏好 |
| `theme` | `ThemeSettings` | 亮暗主题、基础色、圆角与色弱模式 |
| `menu` | `MenuSettings` | 主/次导航模式、视觉和交互 |
| `topbar` | `TopbarSettings` | 标签栏/工具栏是否显示及顶栏定位 |
| `tabbar` | `TabbarSettings` | 标签样式、记忆、快捷键与双击动作 |
| `toolbar` | `ToolbarSettings` | 收藏、面包屑、搜索、通知、语言等工具 |
| `page` | `PageSettings` | 页面动画、进度、iframe 保活和快捷键 |

`app.preferences` 可以把 `theme`、`menu`、`topbar`、`tabbar`、`toolbar`、`page` 的部分设置开放给用户；`preferences.ts` 保存时会明确删除 `app`，所以应用级安全与路由开关不应当被当作个人偏好。

## 应用

上游[《应用》](https://fantastic-admin.hurui.me/guide/settings/app.md)列出了账号、路由、主页和偏好等能力。正式应用通过 `src/settings.ts` 覆盖认证、反馈、错误日志、更新检查、窄屏、版权和偏好项；下表记录与共享默认值合并后的当前值：

| 键 | 当前值 | 说明 |
| --- | --- | --- |
| `app.account.auth` | `true` | 正式应用启用权限体验；实际比较只读取 `/api/auth/me` 权限快照，不依赖此开关建立安全边界 |
| `app.account.expiredMode` | `'redirect'` | 最终 `401` 跳转登录页，而不是重新登录弹窗 |
| `app.account.multipleAccounts` | `false` | 正式认证流程不提供多账号切换或持久化 |
| `app.routeMode` | `'hash'` | Router 使用 hash history |
| `app.routeBaseOn` | `'frontend'` | 从本地 `asyncRoutes` 生成路由 |
| `app.dynamicTitle` | `false` | 页面标题不拼接当前路由标题 |
| `app.watermark` | `false` | watermark Store 已实现但不创建水印 |
| `app.feedback` | `true` | 启用反馈入口 |
| `app.lockScreen` | `false` | 锁屏入口不启用 |
| `app.errorLog` | `true` | 启用框架错误记录入口；不得记录认证敏感信息 |
| `app.checkUpdates` | `true` | 启用前端更新检查 |
| `app.rip` | `false` | 不启用灰度哀悼模式 |
| `app.mobile` | `true` | 允许移动端/窄屏布局 |
| `app.layout.center` | `false` | 不使用居中布局 |
| `app.layout.centerScope` | `'inner'` | 居中布局开启时作用于内层 |
| `app.layout.centerWidth` | `1400` | 居中布局最大宽度 |
| `app.home.enable` | `true` | 启用首页 |
| `app.home.title` | `'app.route.home'` | 使用 i18n key |
| `app.home.fullPath` | `'/'` | 首页完整路径 |
| `app.copyright.enable` | `false` | 不展示版权区 |
| `app.copyright.dates/company/website` | 已配置 | 因 `enable=false` 不展示；配置值不参与认证或发布身份 |
| `app.preferences.theme/menu/topbar/tabbar/toolbar/page` | `false` | 六个偏好分组均未开放给用户 |

将 `routeMode` 改为 `'html5'` 需要同步部署服务器的 SPA fallback；将 `routeBaseOn` 改为 `'backend'` 需要先确认公共路由 API 和返回结构。目前 `apiApp.routeList()` 仍为 fake 调用，不能只改配置便声称已经接入后端路由。

响应式模式由 `web/apps/qsmds-arco/src/store/modules/app/settings.ts` 判断：移动设备 UA 直接使用 `mobile`，桌面宽度小于 `1024px` 也切到 `mobile`。`app.mobile: true` 只表示框架壳允许窄屏访问，不保证每个业务表格、表单或弹窗自动可用；业务页面仍要做真实窄屏验收。

## 主题

上游[《主题》](https://fantastic-admin.hurui.me/guide/settings/theme.md)说明基础色与主题色的组合。当前正式应用全部使用共享默认值：

| 键 | 当前值 | 约束 |
| --- | --- | --- |
| `theme.sync` | `true` | 切换亮暗时同步基础色与主题名 |
| `theme.baseColorLight` | `'neutral'` | 必须是 `BASE_COLORS` 的键 |
| `theme.baseColorDark` | `'neutral'` | 必须是 `BASE_COLORS` 的键 |
| `theme.light` | `'default'` | 必须是 `THEMES` 的键 |
| `theme.dark` | `'default'` | 必须是 `THEMES` 的键 |
| `theme.colorScheme` | `'light'` | 可选 `'light'`、`'dark'` 或 `''`（跟随系统） |
| `theme.radius` | `0.5` | 写入 CSS `--radius`，类型注释建议范围 `0..1` |
| `theme.colorAmblyopia` | `false` | 开启时对根元素应用颜色滤镜 |

`appSettings` Store 将选择写入 `data-base-color`、`data-theme`、`color-scheme` 和 `dark` class；正式应用已移除 Arco，不再设置 `arco-theme`，参考应用的同步逻辑只存在于 `web/examples/core-arco-design-vue`。改变主题时必须同时检查 Fantastic-admin 壳、Fa 组件、focus ring、错误/警告状态和文字对比度，不能只看主色。

页面使用当前主题时，按以下真相源和落地顺序处理：

1. `web/packages/themes/index.ts` 定义 `BASE_COLORS`、`THEMES` 与 `FRAMEWORK_COLORS`，是当前主题 token 的值与框架映射真相源。
2. `web/uno.config.ts` 把 `background`、`foreground`、`card`、`primary`、`muted`、`accent`、`destructive`、`border`、`input`、`ring` 等 token 映射为 UnoCSS 语义色。
3. 业务页面优先使用 `bg-background`、`text-foreground`、`text-muted-foreground`、`border-border` 等语义类；只有原子类不能表达时，才直接引用 `oklch(var(--...))`。
4. 不得默认硬编码颜色，也不得另建脱离当前 Store 的主题状态；实施后同时验证亮色、暗色与跟随系统三种路径。

## 导航菜单

上游[《导航菜单》](https://fantastic-admin.hurui.me/guide/settings/menu.md)解释各类布局。当前值如下，其中只有一项是正式应用覆盖：

| 键 | 共享默认 | 正式应用有效值 |
| --- | --- | --- |
| `menu.mode` | `'side'` | `'side'` |
| `menu.style` | `''` | `''` |
| `menu.dark` | `false` | `false` |
| `menu.mainMenuClickMode` | `'switch'` | `'smart'` |
| `menu.subMenuUniqueExpand` | `true` | `true` |
| `menu.subMenuCollapse` | `false` | `false` |
| `menu.subMenuAutoCollapse` | `false` | `false` |
| `menu.subMenuCollapseButton` | `false` | `false` |
| `menu.hotkeys` | `false` | `false` |

`'smart'` 会在当前主菜单只有一个可访问的深层菜单时直接跳转，否则只切换主菜单。`mode` 的合法值来自 `MenuMode`：`'side'`、`'head'`、`'single'`、`'only-side'`、`'only-head'`、`'side-panel'`、`'head-panel'`。调整模式后要同时验证桌面、`<1024px`、RTL、键盘操作、菜单收起与无权限菜单被过滤后的行为。

## 顶栏

上游[《顶栏》](https://fantastic-admin.hurui.me/guide/settings/topbar.md)把标签栏和工具栏作为两个独立区域。当前均为共享默认：

| 键 | 当前值 | 说明 |
| --- | --- | --- |
| `topbar.tabbar` | `false` | 不显示标签栏 |
| `topbar.toolbar` | `true` | 显示工具栏 |
| `topbar.mode` | `'static'` | 随页面滚动；另可选 `'fixed'`、`'sticky'` |
| `topbar.switchTabbarAndToolbar` | `false` | 标签栏位于工具栏上方 |

顶栏是否真正有高度还取决于布局组件的计算：工具栏开启且 `toolbar.layout` 至少有一个有效工具时才显示。改成 fixed/sticky 后要检查滚动容器、预留插槽高度、移动端安全区域与焦点可见性。

## 标签栏

上游[《标签栏》](https://fantastic-admin.hurui.me/guide/settings/tabbar.md)说明标签样式、记忆和快捷键。当前 `topbar.tabbar` 为 `false`，因此下列能力虽然实现但界面未启用：

| 键 | 当前值 | 可选值/行为 |
| --- | --- | --- |
| `tabbar.style` | `''` | `''`、`'fashion'`、`'card'`、`'square'` |
| `tabbar.minMaxWidth` | `[150, 150]` | 每项可为像素数字或 `'unset'` |
| `tabbar.icon` | `false` | 是否显示路由图标 |
| `tabbar.dblclickAction` | `'close'` | `reload/close/pin/maximize/window` |
| `tabbar.memory` | `false` | 是否把非固定临时标签写入 `sessionStorage` |
| `tabbar.hotkeys` | `false` | 是否启用标签切换/关闭快捷键 |

固定标签默认按账号写入 `localStorage.tabbarPinData`；`memory` 开启后临时标签写入 `sessionStorage.tabbarTempData`。这些数据受项目 Storage 前缀约束，但不加密。启用标签栏后必须验证登出清理、重复 route name、动态参数、保活组件名和 iframe 关闭联动。

## 工具栏

上游[《工具栏》](https://fantastic-admin.hurui.me/guide/settings/toolbar.md)列出了各工具。当前有效配置如下：

| 键 | 当前值 |
| --- | --- |
| `toolbar.favorites` | `false` |
| `toolbar.breadcrumb.enable` | `true` |
| `toolbar.breadcrumb.style` | `''` |
| `toolbar.breadcrumb.mainMenu` | `false` |
| `toolbar.menuSearch.enable` | `true` |
| `toolbar.menuSearch.hotkeys` | `true` |
| `toolbar.notification` | `false` |
| `toolbar.i18n.enable` | `false` |
| `toolbar.i18n.defaultLang` | `''`（浏览器语言无法匹配时回退 `zh-cn`） |
| `toolbar.fullscreen` | `false` |
| `toolbar.pageReload` | `false` |
| `toolbar.colorScheme` | `false` |
| `toolbar.layout` | `['favorites', 'breadcrumb', '->', 'menuSearch', 'notification', 'i18n', 'fullscreen', 'pageReload', 'colorScheme']` |

`'->'` 是左右分隔符。`ToolbarSettings` 的注释要求 `layout` 保留默认列表中的所有项，只调整顺序和分隔位置；是否渲染由对应布尔/对象设置决定。开启通知、收藏或服务端偏好前，先核对当前 API 仍是 fake；开启 i18n 时还要同步验证应用语言包与路由标题，正式应用不再涉及 Arco locale。

## 页面

上游[《页面》](https://fantastic-admin.hurui.me/guide/settings/page.md)聚焦页面动画、进度、iframe 和快捷键。当前有效默认：

| 键 | 当前值 | 说明 |
| --- | --- | --- |
| `page.transitionMode` | `''` | 无路由切换动画；可选多种 fade/slide |
| `page.progress` | `true` | Router 导航期间显示 NProgress |
| `page.iframeKeepAliveMax` | `3` | iframe Store 最多保留 3 个打开项 |
| `page.hotkeys` | `true` | 页面最大化/恢复相关快捷键启用 |

动画不是无障碍豁免项。若开启 `transitionMode`，应验证 `prefers-reduced-motion` 场景并为业务页面提供降级；当前配置类型没有“全局减少动效”键，不要杜撰。`iframeKeepAliveMax` 只限制 iframe 项数量，不能替代外部站点可信性、安全策略和内存监控。

### 配置修改与验证流程

1. 先从 `web/packages/settings/src/types.ts` 确认键名、联合类型和说明，再从 `default.ts` 确认当前默认。
2. 只在 `web/apps/qsmds-arco/src/settings.ts` 写最小项目差异；数组会整体替换，尤其要谨慎处理 `toolbar.layout`。
3. 若开放用户偏好，核对 `web/packages/settings/src/preferences.ts` 的可开放字段和 `web/apps/qsmds-arco/src/store/modules/app/preferences.ts` 的持久化行为。
4. 运行静态验证：

```bash
pnpm -C web typecheck
pnpm -C web build
```

5. 在真实页面验证桌面/窄屏、亮暗主题、键盘焦点、登录/登出和刷新恢复。仅设置值能通过类型检查，不代表布局、可访问性或部署条件已经满足。
