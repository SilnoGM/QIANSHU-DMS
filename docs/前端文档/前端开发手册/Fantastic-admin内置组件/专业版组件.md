# Fantastic-admin 专业版组件

本文记录千树 DMS 当前锁定的 Fantastic-admin Pro `6.3.0` 专业组件。它们已经由唯一正式应用 `web/apps/qsmds-arco` 接入，是可直接使用的正式能力，不是可跳过的候选清单；但正式能力不等于所有业务页面默认优先使用，标准业务日期、选择、Tree、流程和反馈仍按[选型与使用规则](./选型与使用规则.md)优先评估 Arco Design Vue。

| 项目 | 当前事实 |
| --- | --- |
| 最后核对 | 2026-07-15 |
| 运行时边界 | `web/packages/components/src/index.ts` 的 `// 专业版组件` 至文件末尾 |
| 覆盖规模 | 50 个运行时公开名、47 个源码目录 |
| 源码与 API | `web/packages/components/src/pro/*` |
| 自动导入 | `web/packages/components/resolver.ts`、`web/apps/qsmds-arco/vite/plugins.ts` 与生成声明 |
| 上游追溯 | [Fantastic-admin 专业版组件目录](https://fantastic-admin.hurui.me/components/) |

本地导出和 Pro `6.3.0` 源码是唯一可用性与 API 真相源，官网仅用于解释与追溯。具体组件页可能随上游继续演进；本地 `README.md` 与实现或类型冲突时，以 `index.ts`、`*.vue`、composable 和 types 为准，本文会明确冲突，不猜测 Props、Events 或 Slots。

## 使用前的共同规则

- 模板中的 `Fa*` 由 `FantasticAdminComponentsResolver()` 自动解析，`useFaLoading` 由 `FantasticAdminComponentsAutoImports` 自动引入；类型、Node 脚本、测试、共享包和 Vite 配置仍显式从 `@fantastic-admin/components` 导入。
- 大部分组件的样式入口是各自 `index.vue` 中的 UnoCSS 原子类和 `cn()` 合并的 `class` 类 Props；有 `<style scoped>`、字体文件或第三方 CSS 的组件会在条目中单列。不要假设存在可单独导入的组件 CSS。
- 动画、背景、轮播和持续刷新组件必须在真实密度、窄屏、低性能设备上验证，并为 `prefers-reduced-motion` 提供停用或静态替代；不得只依赖悬停表达信息。
- 选择与交互组件必须验证键盘、焦点、禁用态、可访问名称和触摸操作。装饰组件不能替代语义化按钮、链接、标题或状态文本。
- `FaCodePreview` 只展示可信源码文本，不执行字符串；`FaLinkPreview` 的外链与图片地址必须经过协议和来源校验；二维码内容必须可验证且不能暗示可信身份；`FaStorageBox` 只存非敏感偏好，绝不保存 token、密码、Cookie、连接字符串或授权信息。
- 以下静态中文示例只演示组件契约，不虚构千树 DMS 的业务 API、路由、权限或后端字段。只给出 `<template>` 的片段也默认位于 Vue 3 的 `<script setup lang="ts">` SFC 中。

根入口显式导出的主要类型包括：三个 Range 家族各自的 `Value` / `CompleteValue`、`CascaderOption`、`ComboboxOption`、`ComboboxGroupOption`、`ComboboxProps`、`LoadingProps`、`Step`、`StepContext`、`StepsItem`、`StepsStatus`、`TreeNode` 和 `TreeProps`。此外两条受控 star export 公开以下非 `Fa*` 能力：

| star export | 主要公共符号 |
| --- | --- |
| `./pro/mention/mention` | `MentionRoot`、`MentionLabel`、`MentionInput`、`MentionPortal`、`MentionContent`、`MentionItem`；`MentionSide`、`MentionAlign`、`MentionDirection`、`MentionOption`、`MentionRange`、`MentionItemRegistration`、`MentionCollisionPadding`、`MentionClassName` |
| `./pro/pattern-bg/variants` | `patternBgVariants`、`patternBgMaskVariants`；`BaseProps`、`PatternBgVariants`、`PatternBgMaskVariants` |

## FaAnimatedBeam

- **用途与边界**：在同一相对定位容器里的两个 DOM 元素间绘制动态 SVG 光束，适合解释关系或数据流；不适合高密度表格、关键状态或仅靠动画才能理解的流程。
- **公开入口与 API**：根入口把 `AnimatedBeam` 别名为本名称，源码目录为 `pro/animated-beam`。必传 `containerRef`、`fromRef`、`toRef`，常用 `curvature`、`reverse`、`duration`、`pathWidth`、`gradientStartColor`、`gradientStopColor` 与 `class`；无 Events、Slots、Expose 或根导出专属类型。
- **样式与选择**：样式来自 `index.vue` 的 SVG、渐变和 UnoCSS 类，无独立 CSS。需求命中关系动效时可用本组件；普通连线、业务状态和可访问流程说明优先静态结构，并在减少动态偏好下隐藏光束。
- **依据**：[官网具体页](https://fantastic-admin.hurui.me/components/pro/FaAnimatedBeam.html)、`web/packages/components/src/pro/animated-beam/README.md`、`index.ts`、`index.vue`。

```vue
<script setup lang="ts">
const container = useTemplateRef<HTMLElement>('container')
const source = useTemplateRef<HTMLElement>('source')
const target = useTemplateRef<HTMLElement>('target')
</script>

<template>
  <div ref="container" class="relative flex justify-between">
    <span ref="source">录入</span><span ref="target">完成</span>
    <FaAnimatedBeam :container-ref="container" :from-ref="source" :to-ref="target" />
  </div>
</template>
```

## FaAnimatedCountTo

- **用途与边界**：用 `@number-flow/vue` 平滑过渡统计数字，适合低频 KPI 变化；不适合持续高频行情、必须即时读出的精确值或减少动态模式。
- **公开入口与 API**：根入口把 `AnimatedCountTo` 别名为本名称，源码目录为 `pro/animated-count-to`。必传 `value`，常用 `format`、`locales`、`prefix`、`suffix`、`trend`、三个 timing 与 `willChange`；Events 为 `animationsstart`、`animationsfinish`，无 Slot/Expose/根导出专属类型。
- **样式与选择**：`index.vue` 组合 NumberFlow 与 UnoCSS 类，无独立 CSS。普通静态数值用文本或 Arco 数据展示；确需数字过渡时才用，并控制刷新频率。
- **依据**：[官网具体页](https://fantastic-admin.hurui.me/components/pro/FaAnimatedCountTo.html)、`web/packages/components/src/pro/animated-count-to/README.md`、`index.ts`、`index.vue`。


## FaAnimatedCountToGroup

- **用途与边界**：让多个数字动画共享 NumberFlow group 上下文并同步过渡；它不是布局网格，也不负责标题、单位或响应式排版。
- **公开入口与 API**：根入口把同一 `pro/animated-count-to` 目录的 `AnimatedCountToGroup.vue` 别名为本名称。这是专业运行时名多于源码目录的第一个别名：无 Props/Events/Expose，只有 `default` Slot，未导出专属类型。
- **样式与选择**：组容器自身没有独立视觉样式；布局仍由调用方或 Arco 栅格/Space 负责。仅在至少两个数字需要同步时使用。
- **依据**：[官网所在组件页](https://fantastic-admin.hurui.me/components/pro/FaAnimatedCountTo.html)（上游把组容器 API 与数字组件放在同页）、同目录 `README.md`、`index.ts`、`AnimatedCountToGroup.vue`；官网侧栏的独立别名链接当前返回 404，因此不作为可达依据。

```vue

  </FaAnimatedCountToGroup>
```


## FaCountTo

- **用途与边界**：从 `startVal` 动画到 `endVal`，支持千分位、小数、前后缀和 VueUse easing；适合低频统计值，不适合高频数据流或减少动态模式。
- **公开入口与 API**：`CountTo` 从 `pro/count-to` 被别名导出。必传起止值，常用 `autoplay`、`duration`、`transition`、`decimals`、`separator`；Events 的源码名为 `onStarted`、`onFinished`（模板监听写作 `@on-started`、`@on-finished`），Expose 为 `start()`、`reset()`，无 Slots/根导出专属类型。
- **样式与选择**：`index.vue` 仅输出文本 span，动画来自 `useTransition`，无独立 CSS。静态 KPI 直接用文本；需要更精细的数字格式过渡可比较本组件与前面的 NumberFlow 版本。
- **依据**：[官网具体页](https://fantastic-admin.hurui.me/components/pro/FaCountTo.html)、`web/packages/components/src/pro/count-to/README.md`、`index.ts`、`index.vue`；事件与 Expose 以源码为准。
