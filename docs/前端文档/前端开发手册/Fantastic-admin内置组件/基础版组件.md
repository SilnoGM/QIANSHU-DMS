# Fantastic-admin 基础版组件

本文覆盖 `web/packages/components/src/index.ts` 中 `// 基础版组件` 到 `// 专业版组件` 之间的全部 52 个运行时公开名：48 个 `Fa*` 组件与 4 个 `useFa*` composable，共对应 44 个 `basic/` 源码目录。这里的“基础版”是源码区段名称；标准业务交互按[选型与使用规则](./选型与使用规则.md)优先使用本文公开的 Fantastic-admin 内置组件，无法满足已确认契约时才逐级回退。

所有示例均面向 Vue 3 `<script setup lang="ts">`。正式应用 `web/apps/qsmds-arco` 已配置组件和 composable 自动导入，示例因此不重复写运行时 import；type 必须从 `@fantastic-admin/components` 显式导入。Props、Events、Slots、Expose、composable 与 exported types 如有差异，以条目所列本地源码/类型为准，官网当前页面只解释上游用法。

## FaAlert

- **用途与边界**：展示重要状态、说明或风险，框架与业务页都优先使用本组件；无法满足关闭生命周期或已确认反馈契约时才回退 Arco Alert/Message。
- **公开与源码**：根入口导出 `FaAlert`，源码目录 `web/packages/components/src/basic/alert/`。高频 Props 为 `icon`、`title`、`description`、`variant: 'default' | 'destructive'`、`class`；`description` slot 覆盖同名 prop。
- **样式与选择**：`class` 由 `cn()` 合并，可使用 UnoCSS；错误/风险才使用 `destructive`，不能只靠颜色表达语义。
- **最小用法**：

```vue
<template>
  <FaAlert title="同步提示" description="数据将在保存后生效" icon="i-lucide:info" />
</template>
```

- **依据**：[官方 FaAlert](https://fantastic-admin.hurui.me/components/basic/FaAlert.html)；[本地 README](../../../../web/packages/components/src/basic/alert/README.md)；`index.vue`。

## FaAvatar

- **用途与边界**：展示头像并在图片失败时显示降级文本；框架用户入口和业务人员列表都优先本组件，缺少已确认图片契约时再回退 Arco。
- **公开与源码**：根入口导出 `FaAvatar`，源码目录 `basic/avatar/`。`src` 必填，`fallback` 提供最多前两个字符的降级文本，default slot 可覆盖降级内容，`class` 控制尺寸和形状。
- **样式与选择**：通过 `class="size-8 rounded-full"` 等 UnoCSS 类调整；业务头像必须使用受信 URL，并为周边可访问文本保留用户名称。
- **最小用法**：

```vue
<template>
  <FaAvatar src="https://assets.example.invalid/avatar.png" fallback="千树" class="size-8 rounded-full" />
</template>
```

- **依据**：[官方 FaAvatar](https://fantastic-admin.hurui.me/components/basic/FaAvatar.html)；[本地 README](../../../../web/packages/components/src/basic/avatar/README.md)；`index.vue`。

## FaBadge

- **用途与边界**：在包裹内容上展示数量、文本或点状状态；框架通知与业务状态徽标都优先本组件，变体无法满足语义时才回退 Arco Badge/Tag。
- **公开与源码**：根入口导出 `FaBadge`，源码目录 `basic/badge/`。`value` 在源码类型中必填，高频 Props 另有 `variant`、`class`、`badgeClass`；`0`、`false`、空值会隐藏，`true` 显示圆点；default slot 是被标记内容。
- **样式与选择**：`class` 控制容器，`badgeClass` 控制徽章；数量和状态要有非颜色文本或可访问名称。
- **最小用法**：

```vue
<template>
  <FaBadge :value="3" variant="destructive">
    <FaButton variant="ghost">待处理</FaButton>
  </FaBadge>
</template>
```

- **依据**：[官方 FaBadge](https://fantastic-admin.hurui.me/components/basic/FaBadge.html)；[本地 README](../../../../web/packages/components/src/basic/badge/README.md)；`index.vue`。

## FaButton

- **用途与边界**：触发框架或业务操作，支持加载、危险、轮廓、图标等样式；标准业务按钮优先 `FaButton`，无法满足已确认交互契约时才回退 `AButton`。
- **公开与源码**：根入口导出 `FaButton`，源码目录 `basic/button/`。高频 Props 为 `variant`、`size`、`disabled`、`loading`、`class`，default slot 放图标和文字；原生 `type`、点击事件由底层按钮透传。
- **样式与选择**：`class` 可用 UnoCSS；纯图标按钮使用 `size="icon"` 并提供可访问名称。加载时组件会禁用交互。
- **最小用法**：

```vue
<script setup lang="ts">
import { ref } from 'vue'

const saving = ref(false)
</script>

<template>
  <FaButton :loading="saving" @click="saving = true">
    保存设置
  </FaButton>
</template>
```

- **依据**：[官方 FaButton](https://fantastic-admin.hurui.me/components/basic/FaButton.html)；[本地 README](../../../../web/packages/components/src/basic/button/README.md)；`index.vue`。

## FaButtonGroup

- **用途与边界**：把紧密相关的按钮组合为水平或垂直控件组；不是普通按钮间距容器，标准业务工具栏优先本组件与 UnoCSS gap，交互分组不足时再回退 Arco。
- **公开与源码**：与 `FaButton` 同属 `basic/button/` 的 component group alias。Props 为 `orientation: 'horizontal' | 'vertical'`、`separator`、`class`；default slot 放按钮。
- **样式与选择**：`class` 控制整体布局；组内按钮应属于同一操作集合，危险操作不要与主操作造成误触。
- **最小用法**：

```vue
<template>
  <FaButtonGroup separator>
    <FaButton variant="outline">上一项</FaButton>
    <FaButton variant="outline">下一项</FaButton>
  </FaButtonGroup>
</template>
```

- **依据**：[官方 FaButton](https://fantastic-admin.hurui.me/components/basic/FaButton.html)；[本地 README](../../../../web/packages/components/src/basic/button/README.md)；`ButtonGroup.vue`。

## FaCheckboxGroup

- **用途与边界**：通过 `options` 数组维护多选值，支持描述、最少/最多数量与 option slot；业务字段多选优先本组件，数据或选项契约不足时才回退 Arco CheckboxGroup。
- **公开与源码**：与 `FaCheckbox` 同属 `basic/checkbox/` 的 component group alias。高频 Props 为 `options`、`disabled`、`min`、`max`、`dir`、`class`、`optionClass`、`itemClass`、`labelClass`；`v-model` 为值数组，`change` 返回数组。`option` slot 接收 `{ option, checked, disabled, id }`。
- **样式与选择**：`class`/`optionClass` 可创建多列或卡片布局；使用自定义 option slot 后默认复选框会隐藏，插槽必须自行保留选中与键盘语义。本目录的 `CheckboxGroupOption` 不是根入口公开 type，跨文件不要假设可导入。
- **最小用法**：

```vue
<script setup lang="ts">
import { ref } from 'vue'

const channels = ref<Array<string | number>>([])
const options = [
  { label: '站内信', value: 'inbox' },
  { label: '邮件', value: 'email' },
]
</script>

<template>
  <FaCheckboxGroup v-model="channels" :options="options" :max="2" />
</template>
```

- **依据**：[官方 FaCheckbox](https://fantastic-admin.hurui.me/components/basic/FaCheckbox.html)；[本地 README](../../../../web/packages/components/src/basic/checkbox/README.md)；`CheckboxGroup.vue`。

## FaCollapsible

## FaContextMenu

- **用途与边界**：在右键触发区展示分组菜单、子菜单和危险项；适合确有右键语义的交互。普通业务行操作优先可见 `FaButton` 或 `FaDropdown`，Fa 契约不足时再回退 Arco。
- **公开与源码**：根入口导出 `FaContextMenu`，源码目录 `basic/context-menu/`。必填 `items: (MenuItem | MenuSubItem)[][]`；default slot 是触发区，`label` slot 是菜单头。`MenuItem` 高频字段为 `label`、`icon`、`variant`、`disabled`、`handle`，子菜单继续持有二维 `items`。
- **样式与选择**：本地未公开 class prop；二维数组表示分组。不要把关键操作只藏在右键菜单，危险项必须二次确认并传播失败。
- **最小用法**：

```vue
<script setup lang="ts">
const items = [[
  { label: '刷新', icon: 'i-lucide:refresh-cw', handle: () => undefined },
  { label: '移除', variant: 'destructive' as const, handle: () => undefined },
]]
</script>

<template>
  <FaContextMenu :items="items">
    <div tabindex="0">在此区域打开右键菜单</div>
  </FaContextMenu>
</template>
```

- **依据**：[官方 FaContextMenu](https://fantastic-admin.hurui.me/components/basic/FaContextMenu.html)；[本地 README](../../../../web/packages/components/src/basic/context-menu/README.md)；`index.vue`。

## useFaDrawer

- **用途与边界**：在组件 setup 上下文中命令式创建抽屉；业务表单流程先评估声明式 `FaDrawer`，确有命令式需求再用本 composable，Fa 能力不足时才回退 Arco。
- **公开与源码**：根入口公开 composable，源码 `basic/drawer/useDrawer.ts`。返回 `{ create }`；`create(options)` 返回 `{ open(), close(), update(newOptions) }`。options 继承 `DrawerProps`（除 `modelValue`）并增加 `content`、`onOpen`、`onOpened`、`onClose`、`onClosed`、`onConfirm`、`onCancel`；该内部 option type 未从包根公开。
- **生命周期与选择**：实例继承当前 app context，并在当前组件卸载时清理；应在 setup 内调用。不要承诺 open/close event 在所有交互路径严格仅触发一次。
- **最小用法**：

```vue
<script setup lang="ts">
const drawer = useFaDrawer()

function showHelp() {
  drawer.create({
    title: '使用说明',
    content: '此处只展示静态说明。',
    showCancelButton: true,
  }).open()
}
</script>

<template>
  <FaButton @click="showHelp">查看说明</FaButton>
</template>
```

- **依据**：[官方 FaDrawer](https://fantastic-admin.hurui.me/components/basic/FaDrawer.html)；[本地 README](../../../../web/packages/components/src/basic/drawer/README.md)；`useDrawer.ts`。

## FaFileUpload

- **用途与边界**：上传单个/多个文件或目录，维护进度、状态和文件列表；标准业务上传优先本组件，本地 request/progress 契约无法满足需求时才回退 Arco Upload。
- **公开与源码**：根入口导出 `FaFileUpload`、`FileItem`、`FileUploadRequestOptions`，源码目录 `basic/file-upload/`。`v-model` 必须是 `FileItem[]`；高频 Props 为 `action`、`method`、`headers`、`data`、`name`、`beforeUpload`、`httpRequest`、`afterUpload`、`multiple`、`max`、`directory`、`disabled`、`description`。真实 Events 名为 `onSuccess(response, file)`、`onClick(fileItem, index)`，default slot 自定义上传区。
- **请求契约**：`FileUploadRequestOptions` 包含 `action`、`method`、`headers`、`data`、`name`、`file`、`onProgress(percent)`；自定义请求返回值先交给 `afterUpload` 提取 URL，再更新 model。鉴权必须走统一 HTTP client，`beforeUpload` 不能替代服务端校验。
- **样式与选择**：组件没有公开 class prop；默认 `max=0` 表示不限数量。目录上传会扁平化文件且禁用粘贴。
- **最小用法**：

```vue
<script setup lang="ts">
import type { FileItem, FileUploadRequestOptions } from '@fantastic-admin/components'
import { ref } from 'vue'

const files = ref<FileItem[]>([])

async function upload(options: FileUploadRequestOptions) {
  options.onProgress(100)
  return { url: 'https://cdn.example.invalid/uploaded-file.pdf' }
}

function readUrl(response: { url: string }) {
  return response.url
}
</script>

<template>
  <FaFileUpload
    v-model="files"
```

- **样式与选择**：样式来自 vue-sonner CSS 与源码中的语义 UnoCSS classes，不存在供调用方传入的 class prop。消息应简短、可恢复且不包含敏感内容。

```vue
<template>
```

## useFaToast

- **用途与边界**：返回 `vue-sonner` 的 toast 函数对象，发送全局提示；业务反馈优先本 composable，上下文契约不足时才回退 Arco，长内容或可追溯通知不要用短暂 toast 承载。
- **公开与源码**：根入口公开 composable，源码 `basic/toast/useToast.ts`，直接 `return toast`，不是二次封装。当前依赖提供 callable、`success`、`info`、`warning`、`error`、`custom`、`message`、`promise`、`dismiss`、`loading`、`getHistory`、`getToasts`；本地 README 只列出其中一部分，以安装版本类型为准。
- **失败处理与选择**：先确保根层已挂载 Toaster。Promise 反馈不能吞掉原始 rejection；消息不得回显 token、密码、Cookie、连接字符串或完整敏感响应。
- **最小用法**：

```vue
<script setup lang="ts">
const toast = useFaToast()

function notify() {
  toast.success('框架设置已保存')
}
</script>

<template>
  <FaButton @click="notify">显示提示</FaButton>
</template>
```

- **依据**：[官方 FaToast](https://fantastic-admin.hurui.me/components/basic/FaToast.html)；[本地 README](../../../../web/packages/components/src/basic/toast/README.md)；`useToast.ts`、当前 `vue-sonner` types。

## FaTooltip

- **用途与边界**：悬停/聚焦时展示短说明；图标按钮和标准业务 tooltip 优先本组件，复杂内容优先 `FaPopover`，触发或碰撞契约不足时才回退 Arco。
- **公开与源码**：根入口导出 `FaTooltip`，源码目录 `basic/tooltip/`。Props 为 `text`、`delay`、`side`、`align`、`disabled`；default slot 是触发元素，`content` slot 覆盖文本；没有 class prop。
- **样式与选择**：tooltip 不能承载关键操作或唯一帮助信息；触发元素必须可聚焦，触屏场景要有可见替代说明。

```vue
<template>
```

## FaTrend

- **用途与边界**：用箭头和颜色展示上升/下降趋势，可反转“好/坏”颜色语义；业务指标卡优先结合 `FaCard`/领域组件，并给出可读基准，Fa 契约不足时再回退 Arco。
- **公开与源码**：根入口导出 `FaTrend`，源码目录 `basic/trend/`。必填 `value`；Props 另有 `type`、`prefix`、`suffix`、`reverse`、`size`、`variant`；没有 event/slot/class prop。
- **样式与选择**：`reverse` 适用于成本、错误率等“下降更好”的指标。趋势必须同时显示方向和值，不能只靠红绿；value 由调用方格式化。
- **最小用法**：

```vue
<template>
  <FaTrend value="12.4" type="down" suffix="%" reverse variant="soft" />
</template>
```

- **依据**：[官方 FaTrend](https://fantastic-admin.hurui.me/components/basic/FaTrend.html)；[本地 README](../../../../web/packages/components/src/basic/trend/README.md)；`index.vue`。
