# 轻提示：QsToast

[返回自定义组件库](../README.md)

## 1. 组件定位

`QsToast` 是 `web/apps/qsmds-arco` 内的项目级轻提示基础组件。它基于
`useFaToast().custom()` 复用全局队列、计时、堆叠、悬停暂停、移动端滑动关闭和
安全区能力，并统一千树 DMS 的提示视觉、状态语义与调用接口。

组件不读取业务 Store、不请求 API，也不内置权限或业务文案。应用中的全局
`<FaToast>` Host 保持唯一，业务调用方只需使用 `useQsToast()`。

| 项目 | 当前值 |
| --- | --- |
| 视觉组件 | `web/apps/qsmds-arco/src/components/base/QsToast/index.vue` |
| 组合式 API | `web/apps/qsmds-arco/src/components/base/QsToast/useQsToast.ts` |
| 类型 | `web/apps/qsmds-arco/src/components/base/QsToast/types.ts` |
| Showcase | `web/apps/qsmds-arco/src/views/component_library/basic/components/QsToastShowcase.vue` |
| 路由 | `/component-library/basic/toast` |
| 测试 | `web/apps/qsmds-arco/test/views/qs-toast.test.ts` |

## 2. 快速使用

```ts
import { useQsToast } from '@/components/base/QsToast/useQsToast'

const toast = useQsToast()

toast.success('保存成功', {
  description: '内容已同步到服务器。',
})

toast.error('保存失败', {
  description: '请检查网络连接后重试。',
})
```

`useQsToast()` 返回的展示方法均可直接调用，不需要在页面中挂载 `QsToast`。

## 3. API

| 方法 | 说明 |
| --- | --- |
| `show(title, options?)` | 普通提示 |
| `success(title, options?)` | 成功提示 |
| `info(title, options?)` | 信息提示 |
| `warning(title, options?)` | 警告提示 |
| `error(title, options?)` | 错误提示 |
| `loading(title, options?)` | 默认永久存在的加载提示 |
| `promise(task, options)` | 编排 loading 与成功或失败提示，并保留原 Promise 结果 |
| `dismiss(id?)` | 传入展示方法返回的 id 时关闭单条；不传时关闭全部 |

展示方法的 `options`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `description` | `string` | 可选补充说明 |
| `duration` | `number` | 大于 `0` 的有限毫秒数，或 `Infinity` |
| `closable` | `boolean` | 控制有限时长提示的内部关闭按钮；永久提示始终可关闭 |
| `action` | `QsToastAction` | 提供一个受控文本动作 |

`QsToastAction` 包含 `label`、`onClick` 和可选的 `closeOnClick`。动作执行后默认关闭
当前提示；设置 `closeOnClick: false` 时保留提示。

组件不接受自定义 `class`、`style`、`icon`、Vue 组件或输入 id，避免业务页面绕过
统一视觉，并规避底层假值 id 的关闭歧义。

## 4. 默认状态

| 状态 | 默认时长 | 默认关闭按钮 | 无障碍角色 |
| --- | ---: | --- | --- |
| `default` | `3200ms` | 否 | `status` |
| `success` | `2800ms` | 否 | `status` |
| `info` | `4000ms` | 否 | `status` |
| `warning` | `5000ms` | 否 | `status` |
| `error` | `6000ms` | 是 | `alert` |
| `loading` | `Infinity` | 是 | `status` |

任意 `duration: Infinity` 的提示始终提供关闭按钮；即使传入 `closable: false`，
也不会移除永久提示的键盘关闭入口。错误提示默认可关闭，但在保持有限时长时允许
调用方显式关闭该按钮。

## 5. Promise 行为

```ts
const saved = await toast.promise(saveDraft(), {
  loading: '正在保存草稿',
  success: result => ({
    title: '草稿已保存',
    description: `版本 ${result.version}`,
  }),
  error: error => ({
    title: '保存失败',
    description: getErrorMessage(error),
  }),
})
```

`promise()` 接受 Promise 或返回 Promise 的函数。成功时返回原值，失败时重新抛出
原异常；提示文案映射器自身报错只会回退到通用提示，不改变业务 Promise 结果。

当前锁定的 `vue-sonner@2.0.9` 不会为同 id 的 custom toast 重置剩余时长。因此
异步完成后会先关闭永久 loading，再创建具有正常自动关闭时长的成功或失败提示，
不采用同 id 原位更新。

## 6. 视觉、响应式与无障碍

- 浮层使用中性主题表面，语义色只用于左侧细线、状态岛和 Lucide 图标。
- 字体继承项目全局 `Noto Sans SC` 排版体系，不引入系统字体或独立字体。
- 错误使用 `role="alert"`，其余状态使用 `role="status"`。
- 操作和关闭按钮支持键盘焦点；关闭按钮具有“关闭提示”无障碍名称。
- 宽度不超过 `calc(100vw - 32px)`；窄屏时动作换到内容下方。
- `prefers-reduced-motion: reduce` 下停止加载旋转和局部交互动效。

外层提示位置、进入退出、悬停暂停、滑动关闭、队列和安全区继续由 `FaToast`
负责，`QsToast` 不复制这些运行时能力。

## 7. 使用边界

适合：

- 保存、提交、复制、同步等短时操作结果。
- 需要提示但不应打断当前任务的系统信息或风险提醒。
- 有一个轻量撤销、重试或查看动作的反馈。
- 需要把异步 loading 与最终状态统一编排的操作。

不适合：

- 必须阻止用户继续操作的确认或高风险决策，应使用模态框。
- 需要长期保留、展开详情或承载多个操作的内容，应使用 Alert、卡片或任务容器。
- 表单字段级错误，应靠近对应字段展示。
- 依赖 Toast 作为唯一记录的关键业务结果；重要状态必须在页面中保留可追溯入口。
