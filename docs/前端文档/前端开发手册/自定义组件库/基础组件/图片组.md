# 图片组

## 1. 定位

`ImageGroup` 是正式应用中的无业务语义图片展示组件，用于表格单元格和窄屏卡片中紧凑展示一张或多张图片。

源码：

```text
web/apps/qsmds-arco/src/components/base/ImageGroup/
├── index.vue
├── logic.ts
├── types.ts
└── README.md
```

调用方必须显式导入：

```ts
import type { ImageGroupItem } from '@/components/base/ImageGroup/types'
import ImageGroup from '@/components/base/ImageGroup/index.vue'
```

组件不读取 API、Store，也不认识产品、SKU、附件等领域字段。业务页面负责将自己的数据映射为 `ImageGroupItem[]`。

## 2. 底层能力

- 缩略图使用原生 `img`，保持表格密度。
- 默认通过逐图 `FaTooltip` 展示图片、说明和序号。
- 点击复用 `useFaImagePreview().open(srcList, index)` 打开整组预览。
- 使用一个 Tab 停靠点和方向键在可见图片之间移动。
- 覆盖加载、失败、空值和 `+N` 溢出状态。

## 3. 公共接口

```ts
export interface ImageGroupItem {
  alt?: string
  key?: number | string
  previewSrc?: string
  src: string
  tooltip?: string
}
```

主要 Props：

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly ImageGroupItem[]` | 必填 | 已按展示顺序排列的图片 |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | `'md'` | 预设尺寸或 24–96px 数字 |
| `radius` | `'none' \| 'sm' \| 'md' \| 'lg' \| 'full' \| number` | `'md'` | 圆角预设或非负像素值 |
| `maxCount` | `number` | `4` | 最大可见位置数，`+N` 也占一个位置 |
| `overlap` | `number` | 尺寸的 25% | 相邻图片重叠像素 |
| `fit` | `'cover' \| 'contain'` | `'cover'` | 图片填充方式 |
| `preview` | `boolean` | `true` | 是否允许点击打开整组预览 |
| `tooltip` | `boolean` | `true` | 是否启用内置逐图 Tooltip |
| `tooltipDelay` | `number` | `300` | Tooltip 显示延迟 |

Slots：

- `tooltip({ item, index, total })`：替换当前可见图片的 Tooltip 内容。
- `empty()`：替换无有效图片时的占位。
- `error({ item, index })`：替换单张缩略图加载失败状态。

Events 为 `preview` 与 `imageError`。完整边界以组件目录 README 和测试为准。

## 4. 基本使用

```vue
<ImageGroup
  :items="row.images"
  :max-count="4"
  radius="lg"
/>
```

产品、SKU 或附件字段先在页面层映射：

```ts
const images: readonly ImageGroupItem[] = product.assets.map(asset => ({
  alt: asset.name,
  key: asset.id,
  previewSrc: asset.originalUrl,
  src: asset.thumbnailUrl,
  tooltip: asset.name,
}))
```

## 5. 选择提示类型

默认内置 `FaTooltip` 适合逐图预览。需要展示产品信息时，按图片与产品的实际对应关系选择组合。

### 每张图片对应不同 SPU / SKU

保留内置 Tooltip，并在逐项插槽中复用 `QsGoodTooltipContent`：

```vue
<ImageGroup
  :items="row.images"
  :max-count="row.images.length"
  radius="lg"
>
  <template #tooltip="{ item }">
    <QsGoodTooltipContent
      :image-src="item.src"
      :image-alt="item.alt"
    >
      <template v-if="productByImageKey.get(String(item.key))">
        <!-- 渲染该图片对应的 SPU / SKU 名称、编码和规格。 -->
      </template>
      <span v-else>该图片暂未关联 SPU / SKU</span>
    </QsGoodTooltipContent>
  </template>
</ImageGroup>
```

逐项映射使用调用方提供的稳定唯一 `item.key`，不要使用可能因过滤或排序改变的 `index`。此模式保持 `tooltip=true`，不能在 `tooltip` 插槽中嵌套 `QsGoodTooltip`。要求每张图片都能单独 hover 时，`maxCount` 必须覆盖全部图片，不能把待验收图片收进 `+N`。

### 整组图片对应同一产品

整个图片组只对应同一产品时，由调用方使用外层 `QsGoodTooltip`：

```vue
<QsGoodTooltip :image-src="row.mainImage" side="right">
  <ImageGroup
    :items="row.images"
    :tooltip="false"
    tabindex="0"
  />

  <template #content>
    <!-- 产品信息由调用方组织。 -->
  </template>
</QsGoodTooltip>
```

外层模式必须传入 `:tooltip="false"`，确保同一触发区域只有一个 Tooltip。`QsGoodTooltipContent` 是纯内容层，可以安全放进内置 Tooltip；完整的 `QsGoodTooltip` 不能嵌套。不要给 `ImageGroup` 增加 `tooltipType`、产品对象或业务组件依赖。
