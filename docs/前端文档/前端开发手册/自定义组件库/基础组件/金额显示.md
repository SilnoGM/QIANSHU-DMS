# 金额显示：AmountDisplay

[返回自定义组件库](../README.md)

## 1. 组件定位

`AmountDisplay` 是 `web/apps/qsmds-arco` 内的只读金额显示组件，负责统一四种币种的符号、千分位、两位小数、舍入和空值表现。

组件只格式化调用方传入的值，不读取业务 Store、不请求 API，也不决定币种换算、税务口径或字段权限。当前属于应用内可复用基础组件，尚未从 `web/packages/*` 导出，也没有注册为全局组件。

| 项目 | 当前值 |
| --- | --- |
| 组件源码 | `web/apps/qsmds-arco/src/components/base/AmountDisplay/index.vue` |
| 格式化内核 | `web/apps/qsmds-arco/src/components/base/AmountDisplay/format.ts` |
| Showcase | `web/apps/qsmds-arco/src/views/component_library/basic/index.vue` |
| 路由 | `/component-library/basic/amount-display` |
| 测试 | `web/apps/qsmds-arco/test/views/amount-display.test.ts` |

## 2. 快速使用

组件必须显式导入：

```vue
<script setup lang="ts">
import AmountDisplay from '@/components/base/AmountDisplay/index.vue'
</script>

<template>
  <AmountDisplay value="12846.37" currency="CNY" />
</template>
```

输出：

```text
¥12,846.37 CNY
```

精确金额优先使用十进制字符串。把后端 decimal 先转换成 JavaScript `number` 可能在组件接收前就已经丢失精度。

## 3. Props

| Prop | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `value` | `number \| string \| null \| undefined` | 是 | 无 | 待显示金额；空值或非法值显示 `—` |
| `currency` | `'CNY' \| 'TWD' \| 'MYR' \| 'USD'` | 是 | 无 | 决定币种符号和输出末尾的币种代码 |

`value` 是必填 Prop，但类型允许调用方显式传入 `undefined`，用于把缺失字段统一显示为 `—`。

组件没有 Slots、Events、`v-model` 或公开方法。

## 4. 应用内导出的类型与格式化函数

非模板代码可以直接复用纯格式化能力：

```ts
import type {
  CurrencyAmountValue,
  CurrencyCode,
} from '@/components/base/AmountDisplay/format'
import {
  CURRENCY_SYMBOLS,
  EMPTY_AMOUNT_TEXT,
  formatCurrencyAmount,
} from '@/components/base/AmountDisplay/format'

const amount = formatCurrencyAmount('9007199254740993.21', 'TWD')
// NT$9,007,199,254,740,993.21 TWD
```

| Export | 契约 |
| --- | --- |
| `CurrencyCode` | `'CNY' \| 'TWD' \| 'MYR' \| 'USD'` |
| `CurrencyAmountValue` | `number \| string \| null \| undefined` |
| `CURRENCY_SYMBOLS` | `{ CNY: '¥', TWD: 'NT$', MYR: 'RM', USD: '$' }` |
| `EMPTY_AMOUNT_TEXT` | `'—'` |
| `formatCurrencyAmount(value, currency)` | 返回稳定金额文本；输入无效时返回 `—` |

## 5. 输出规则

| 输入值 | 币种 | 输出 |
| --- | --- | --- |
| `'12846.37'` | `CNY` | `¥12,846.37 CNY` |
| `'384590'` | `TWD` | `NT$384,590.00 TWD` |
| `'27518.4'` | `MYR` | `RM27,518.40 MYR` |
| `'-864.72'` | `USD` | `-$864.72 USD` |
| `'12.345'` | `CNY` | `¥12.35 CNY` |
| `null` | `CNY` | `—` |

固定规则：

- 有效输入始终输出币种符号、千分位、两位小数和末尾币种代码。
- 小数使用十进制 `half-up` 舍入，当前不支持自定义精度。
- 负号位于币种符号之前。
- 舍入后为零时移除负号，例如 `-0.004 USD` 输出 `$0.00 USD`。
- 输出不依赖浏览器默认语言，所有运行环境保持同一结构。

## 6. 输入边界与精度

字符串在去除首尾空白后必须满足以下十进制语法：

```regex
^[+-]?(?:\d+(?:\.\d*)?|\.\d+)$
```

因此，字符串可以使用 `.5`、`12.`、`+12.3`、负数和前导零，但不能包含千分位、币种文字、科学计数法或多个小数点。

以下输入统一显示 `—`：

- `null`、`undefined`、空字符串或纯空白。
- `NaN`、`Infinity` 和 `-Infinity`。
- `1,000`、`CNY 12`、`1e3` 等不符合十进制语法的字符串。
- 运行时绕过 TypeScript 后传入的不支持币种。

十进制字符串通过字符运算完成舍入和分组，可以保留超过 `Number.MAX_SAFE_INTEGER` 的 decimal 精度。`number` 输入仍受 JavaScript IEEE 754 精度限制，只适合调用方已经确认可安全表示的数值。

## 7. DOM、无障碍与排版

组件根节点为单个 `<span>`，默认类为：

```text
qs-type-data-emphasis text-right inline-flex whitespace-nowrap items-baseline justify-end
```

默认排版遵循[全局排版规范](../../../全局排版规范.md)的 `data-emphasis` 角色：

| 项目 | 当前规则 |
| --- | --- |
| 字体 | `Noto Sans Mono`，中文回退 `Noto Sans SC` |
| 字号 / 行高 | `14px / 20px` |
| 字重 | `500` |
| 数字特性 | `tabular-nums` |
| 颜色 | 主题 `foreground`；浅色主题当前为 `#09090B` |
| 布局 | 右对齐、不换行、基线对齐 |

组件不提供币种专属颜色或业务状态色。调用方可把普通 `class`、`style` 和原生 attribute 传到根节点，但不应覆盖组件生成的语义属性：

- 有效值的 `aria-label` 等于完整展示文本。
- 空值的 `aria-label` 为 `${currency} 金额不可用`。
- `data-currency` 记录币种。
- `data-empty` 标记空值或非法输入形成的占位状态。

## 8. 适用与不适用场景

适合：

- 表格、详情、卡片和汇总中的只读金额。
- 需要稳定显示 `CNY`、`TWD`、`MYR` 或 `USD` 的 decimal 字段。
- 需要在不同浏览器语言下保持相同文本结构的场景。

不适合：

- 金额输入、币种选择或数字校验。
- 汇率换算、税费计算、会计舍入策略或本地化货币文案。
- 需要自定义小数位、符号位置或负数格式的场景。
