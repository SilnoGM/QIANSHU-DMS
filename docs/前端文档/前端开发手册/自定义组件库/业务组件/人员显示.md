# 人员显示

## 1. 定位

`QsPersonDisplay` 是千树 DMS 系统人员的唯一展示出口，输出“圆形头像 + 显示名称”。它只负责展示，不读取 API、Store、权限或人员主数据，也不处理点击、跳转和人员查询。

源码：

```text
web/apps/qsmds-arco/src/components/business/QsPersonDisplay/
├── index.vue
├── logic.ts
├── types.ts
└── README.md
```

调用方必须显式导入：

```ts
import QsPersonDisplay from '@/components/business/QsPersonDisplay/index.vue'
```

## 2. 公共接口

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `displayName` | `string` | 必填 | 人员显示名称；去除首尾空白后为空时显示“未知人员” |
| `avatarUrl` | `string \| null` | `null` | 头像地址；缺失或加载失败时显示名称的首个可见字素 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 头像尺寸，依次为 24px、32px、40px |

组件没有 Events、Slots 和 `v-model`。宽度跟随内容；调用方通过列宽、`max-w-*` 和父容器 `min-w-0` 控制截断。

## 3. 使用边界

- 所有系统人员展示必须使用本组件，包括创建人、更新人、审核人、提交人、出单人、采购人、付款人、入仓人、装柜人、操作人、申请人、核对人和账户归属人。
- 只显示人员 ID 的位置不再直接输出 ID：主显示使用本组件，原始 ID 如确需保留，作为次级等宽文本放在姓名下方。
- 账户主体、关联用户等位置只显示人员姓名，不再拼接 `username`；账号识别由筛选、选择项或独立字段承担。
- 审计日志的 `SYSTEM`、`ANONYMOUS` 操作者没有人员姓名，不得强行使用本组件，应显示中性占位符。
- 纯文本例外仅限单据、打印预览、图片说明和表单只读字段，且必须在 `web/scripts/person-display-governance.test.mjs` 的 `ALLOWED_PERSON_TEXT_FILES` 中登记理由。
- 尺寸由调用方按容器选择：表格主人员列通常 `md`，审核人、提交人、操作人等次要字段通常 `sm`；不强制统一。
- 人员引用 DTO 统一提供 `avatarUrl`（可能为 `null`）：调用方必须把人员对象上的头像一并传给组件；不要只传 `displayName` 而丢掉头像，也不要为了展示头像去猜测或拼接其它字段。没有头像数据的管理端/历史接口才回退到首字头像。

## 4. 基本使用

```vue
<QsPersonDisplay
  :display-name="row.createdBy.displayName"
  :avatar-url="row.createdBy.avatarUrl"
  size="sm"
/>
```

带真实头像的用户资料：

```vue
<QsPersonDisplay
  :display-name="user.displayName"
  :avatar-url="user.profile.avatarUrl"
  size="sm"
/>
```

可空人员：

```vue
<QsPersonDisplay v-if="payment.paidBy" :display-name="payment.paidBy.displayName" size="sm" />
<span v-else class="text-muted-foreground">—</span>
```

## 5. 验证

```bash
# 组件契约：名称归一化、头像回退、尺寸与展示边界
pnpm -C web exec tsx --test apps/qsmds-arco/test/views/qs-person-display.test.ts

# 应用级治理：禁止在模板插值中手写系统人员姓名或人员 ID
node --test web/scripts/person-display-governance.test.mjs
```

治理脚本会扫描 `src/views` 与 `src/components/business` 下的 `.vue` 模板插值；新增例外必须先确认业务边界，再登记文件与理由。

## 6. 真相源

同一事实发生冲突时，按以下顺序判断：

1. `web/apps/qsmds-arco/src/components/business/QsPersonDisplay/` 中的实现与类型。
2. `web/apps/qsmds-arco/test/views/qs-person-display.test.ts` 中的组件契约。
3. `web/scripts/person-display-governance.test.mjs` 中的例外清单与扫描规则。
4. 本说明书与组件目录 README。
