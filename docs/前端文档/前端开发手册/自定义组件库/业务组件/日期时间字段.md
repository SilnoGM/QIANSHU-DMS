# 日期时间字段

## 1. 定位

`QsDateTimeField` 是正式应用统一的日期与日期时间输入。日期部分复用 `FaDate` / `FaCalendarDate` 的日历语义，时间部分使用 `FaInput type="time"`；组件负责业务时区、精度、边界、清除和提交值转换，不读取 API、Store 或权限上下文。

源码：

```text
web/apps/qsmds-arco/src/components/business/QsDateTimeField/
├── index.vue
├── logic.ts
├── types.ts
└── README.md
```

调用方必须显式导入：

```ts
import QsDateTimeField from '@/components/business/QsDateTimeField/index.vue'
```

## 2. 值契约

`v-model` 是 API-ready 值，不是本地墙钟字符串；空字符串表示未选择。

| `precision` | v-model 格式 | 示例 |
| --- | --- | --- |
| `date` | `YYYY-MM-DD` | `2026-10-26` |
| `minute` | 规范化 UTC ISO，秒与毫秒归零 | `2026-10-26T06:30:00.000Z` |
| `second` | 规范化 UTC ISO，保留毫秒 | `2026-10-26T06:30:45.123Z` |

组件内部固定使用 `Asia/Shanghai` 墙钟，与 `DateTimeDisplay`、服务端 `businessToday` 口径一致。浏览器本地时区不参与换算；无时区的 ISO 字符串会被拒绝。

## 3. 公共接口

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `modelValue` | `string` | 必填 | API-ready 值；空字符串表示未选择 |
| `precision` | `'date' \| 'minute' \| 'second'` | `'date'` | 精度，决定 v-model 格式与时间滚轮列数 |
| `disabled` | `boolean` | `false` | 禁用触发器与面板 |
| `clearable` | `boolean` | `false` | 是否显示框内清除按钮 |
| `disableFuture` | `boolean` | `false` | 禁止未来日期与未来时刻，打开面板时重新取当前时刻 |
| `min` | `string` | - | 最早可选值，格式与 v-model 相同 |
| `max` | `string` | - | 最晚可选值，格式与 v-model 相同 |
| `placeholder` | `string` | 选择日期 / 选择日期时间 | 空值触发器文案 |
| `ariaLabel` | `string` | 同 placeholder | 触发器与面板的无障碍名称 |
| `triggerClass` | `string` | - | 追加到触发器的 class |

| 事件 | 说明 |
| --- | --- |
| `update:modelValue` | 选中或清除后写回 API-ready 值 |
| `change` | 值提交后触发，用于清除页面字段错误 |
| `blur` | 触发器失焦，兼容 `FaFormItem` 自动绑定 |
| `update:open` | 面板打开状态变化 |

## 4. 交互与边界

- `date`：点击日期即提交并关闭，与 `FaDate picker` 一致。
- `minute` / `second`：日期与时间先写入面板草稿，点“完成”才提交；取消、Esc、点击外部不写值。
- 未选择日期前时间按钮禁用；改日期保留当前时间。
- 点击“时间”按钮会从主面板右侧弹出时间滚轮，空间不足时自动翻到左侧；时/分/秒三列支持滚轮、点击和键盘选择。
- 时间滚轮的“现在”只重置时间；“取消”只关闭滚轮；“确定”提交整个字段并关闭主面板。
- 主面板不设内部滚动，弹层同时使用 `sticky="always"` 与 `prioritize-position` 优先完整显示；视口高度小于面板完整高度时才会超出视口。
- `disableFuture` 下当天未来时刻显示内联错误并阻止提交；时间滚轮同时禁用当前日期下越界的小时/分钟/秒。
- `min` / `max` 的日期部分通过日历禁用，时刻部分在滚轮和提交前校验；服务端校验仍是最终边界。
- `disableFuture` 与显式 `max` 同时存在时取更早的一个。

## 5. 使用边界

- 必填校验由页面负责；组件只表达空/非空，不替代业务规则。
- 表单中建议显式写 `:auto-bind="false"`，由页面继续维护字段错误，避免 `FaFormItem` 自动绑定覆盖 `v-model`。
- 日期范围筛选继续使用 `QsDateRangeFilter`，不要把范围语义塞进本组件。
- 月份字段（例如 SLH 账单月份）仍使用 `FaCalendarMonth`；本组件当前不提供 `month` 精度。
- 展示时间仍使用 `DateTimeDisplay`，不要手写格式化；不要把本地 `YYYY-MM-DDTHH:mm` 字符串直接赋给 `minute` / `second` 字段。
- 时间选择使用自绘三列滚动面板（`time-wheel-panel.vue`），复用 `logic.ts` 的小时/分钟/秒边界函数；不要退回原生 `input[type="time"]`。
