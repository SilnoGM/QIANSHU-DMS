# 产品提示

## 1. 定位

产品提示包含完整包装器 `QsGoodTooltip` 和纯内容层 `QsGoodTooltipContent`。前者基于 `FaTooltip` 管理触发与定位，后者只提供左图右文布局，可复用到已有 Tooltip 的内容插槽中。

源码：

```text
web/apps/qsmds-arco/src/components/business/QsGoodTooltip/
├── QsGoodTooltipContent.vue
├── index.vue
├── types.ts
└── README.md
```

调用方必须显式导入：

```ts
import QsGoodTooltip from '@/components/business/QsGoodTooltip/index.vue'
import QsGoodTooltipContent from '@/components/business/QsGoodTooltip/QsGoodTooltipContent.vue'
```

两个组件都不读取 API、Store，不接收完整产品 DTO，也不决定字段优先级。

## 2. 公共接口

### QsGoodTooltip

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `imageSrc` | `string \| null` | `null` | 左侧产品图片；空值或失败显示占位 |
| `imageAlt` | `string` | `''` | 产品图片替代文本 |
| `imageFit` | `'cover' \| 'contain'` | `'cover'` | 图片裁切方式 |
| `delay` | `number` | `300` | Tooltip 显示延迟 |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'top'` | 浮层方向 |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | 浮层对齐 |
| `disabled` | `boolean` | `false` | 是否禁用产品提示 |

Slots：

- 默认插槽：单个稳定、可聚焦的触发根节点。
- `content`：右侧只读产品信息，调用方自行组织名称、SPU / SKU 编码、规格和状态。

组件没有 Events，不提供 `v-model:open`、任意样式透传、业务对象或交互动作。

### QsGoodTooltipContent

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `imageSrc` | `string \| null` | `null` | 左侧产品图片；空值或失败显示占位 |
| `imageAlt` | `string` | `''` | 产品图片替代文本 |
| `imageFit` | `'cover' \| 'contain'` | `'cover'` | 图片裁切方式 |

默认插槽承载右侧只读产品信息。组件不创建 `FaTooltip`、没有 Events，也不接收 `side`、`align`、`delay` 或 `disabled`；这些能力由外层 Tooltip 宿主管理。

## 3. 基本使用

```vue
<QsGoodTooltip
  :image-src="product.mainImage"
  :image-alt="product.name"
  side="right"
>
  <button type="button" :aria-label="`查看${product.name}信息`">
    <img :src="product.mainImage" alt="">
  </button>

  <template #content>
    <div class="min-w-0">
      <p class="text-sm font-semibold">
        {{ product.name }}
      </p>
      <p class="font-mono opacity-70">
        {{ product.spuCode }}
      </p>
    </div>
  </template>
</QsGoodTooltip>
```

产品数据和右侧样式属于调用方。组件不会根据 `SPU`、`SKU` 等字段名推测类型或自动格式化。

## 4. 与 ImageGroup 组合

### 每张图片对应不同 SPU / SKU

`ImageGroup` 默认已经为每张可见图片创建独立 `FaTooltip`。调用方应保留该宿主，通过 `#tooltip="{ item }"` 渲染 `QsGoodTooltipContent`，并按稳定的 `item.key` 查找对应产品：

```vue
<ImageGroup
  :items="productImages"
  :max-count="productImages.length"
>
  <template #tooltip="{ item }">
    <QsGoodTooltipContent
      :image-src="item.src"
      :image-alt="item.alt"
    >
      <template v-if="productByImageKey.get(String(item.key))">
        <!-- 渲染该图片对应的 SPU / SKU 信息。 -->
      </template>
      <span v-else>该图片暂未关联 SPU / SKU</span>
    </QsGoodTooltipContent>
  </template>
</ImageGroup>
```

每个图片条目必须提供显式、稳定且字符串化后仍唯一的 `key`，例如 `spu:SPU-BAG-001` 或 `sku:SKU-BAG-NV-M-001`。不要按 `index` 映射：空地址过滤、排序或插入会改变索引。此模式不能传入 `:tooltip="false"`，也不能在 `tooltip` 插槽中嵌套 `QsGoodTooltip`。

`maxCount` 小于图片数量时，隐藏项会合并为 `+N`，没有逐图 Tooltip；要求每张图片都能独立 hover 时，应让 `maxCount >= productImages.length`。

### 整组图片对应同一产品

只有当整个图片组对应同一产品时，才使用外层 `QsGoodTooltip`，并关闭内部提示：

```vue
<QsGoodTooltip :image-src="product.mainImage" side="right">
  <ImageGroup
    :items="product.images"
    :tooltip="false"
    tabindex="0"
  />

  <template #content>
    <!-- SPU / SKU 信息 -->
  </template>
</QsGoodTooltip>
```

`ImageGroup` 继续负责缩略图、方向键和整组图片预览。任何一种组合都只能保留一个 Tooltip 宿主；`QsGoodTooltipContent` 是纯内容层，不属于嵌套浮层。

## 5. 可访问性与交互边界

- 默认触发插槽只有一个稳定根节点，并能通过键盘获得焦点。
- Tooltip 打开后由 `FaTooltip` 提供 `aria-describedby` 和 `role="tooltip"`。
- `content` 只放说明文字、标签等非交互内容；按钮、链接、输入和选择器应改用 `FaPopover`。
- `ImageGroup` 逐图模式沿用其 roving tabindex；Tab 进入后使用左右方向键、`Home` 和 `End` 切换图片。
- 触屏没有可靠 hover 入口，业务必需信息不能只存在于 Tooltip。
- 图片失败占位保持固定尺寸；`imageSrc` 变化时会清除上一张图片的失败状态。
