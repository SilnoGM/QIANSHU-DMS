# 海运柜次卡片

`QsOceanContainerList` 是面向运营和销售的业务展示组件：单列柜次卡片提供整柜概览，展开后按行展示本人销售订单关联的装柜明细。它只处理展示、展开、分页请求和用户事件，业务查询与授权由调用方负责。

## 数据职责

- 整柜概览：柜次名称、系统编号、装柜日期、仓库、整柜明细数、总毛重与总材积。
- 个人计数单独使用 `myItemCount`；明细只接收已由服务端按销售归属授权的数据。
- 无本人货物的柜次保留整柜概览；展开显示个人空态，不发起明细请求。
- 海运唛头支持复制，一行始终对应一条装柜明细，范围唛头不拆行。
- 代收金额沿用 `AmountDisplay`，`null` 与零金额含义不同。
- 列表分页、个人明细分页、失败重试和完整详情交给调用方；组件不请求领域 API 或读取 Store。

## 交互与验收

组件默认收起，允许多柜同时展开。首次展开通知调用方加载个人明细，默认每页 20 条；收起再展开保留现有页，不重复加载已就绪内容。明细加载或失败仅影响对应柜次，列表空态和列表失败独立展示。窄屏明细采用紧凑资料块，保留数据与查看入口。

组件库提供静态演示和可恢复的加载/失败场景，完整明细通过 `QsGenericDrawer` 展示。展示代码不连接真实用户、货件或业务数据。

本阶段交付范围是组件及组件库，尚未接入运营工作台的海运柜次页面，未新增服务端销售归属过滤接口。
