# Arco Design Vue 反馈组件

本册覆盖 `@arco-design/web-vue@2.58.0` 的 9 个反馈家族。反馈必须与真实操作结果一致；示例只演示静态交互，不代表仓库存在对应业务请求。

## Alert

用于页面内持续展示可恢复的提示、警告或错误，不用于短暂操作成功提示。

- 当前接入：`AAlert` 已由 `app.use(ArcoVue)` 全局注册。
- 实际组件名：`AAlert`。
- 高频契约：props 为 `type`、`title`、`content`、`show-icon`、`closable`、`banner`、`center`；事件 `close` 在触发关闭时发出，`afterClose` 在离场动画完成后发出；slots 为 `icon`、`title`、`default`、`action`、`close-element`。需要释放区域资源时使用 `afterClose`，不要把它与 `close` 混为一谈。2.58.0 内置关闭控件为 `tabindex="-1"`，不能据此宣称完整键盘可访问。
- 可访问性与响应式：标题先说结果，再给恢复动作；危险程度不能只靠颜色。窄屏让正文与 action 纵向排列，关闭按钮保持足够点击面积。

```vue
<script setup lang="ts">
function recordClosed() {
  console.info('提示已完成离场')
}
</script>

<template>
  <AAlert
    type="warning"
    title="部分静态数据尚未核对"
    closable
    show-icon
    @after-close="recordClosed"
  />
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/alert) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/alert)

## Drawer

用于保留页面上下文的侧边详情或编辑流程。复杂多步骤任务应进入独立页面。

- 当前接入：模板 `ADrawer` 已全局注册；也可显式导入 `Drawer.open()`，组件实例可使用注入的 `$drawer`。plugin 包装命令式调用时默认传递 app-level `app._context`，但不会自动继承调用位置最近的局部 `AConfigProvider`。
- 实际组件名：`ADrawer`；命令式对象为 `Drawer`，全局实例入口为 `$drawer`。
- 高频契约：受控状态为 `visible` / `update:visible`；props 为 `title`、`width`、`placement`、`mask`、`mask-closable`、`esc-to-close`、`unmount-on-close`、`ok-loading`、`hide-cancel`、`on-before-ok`、`on-before-cancel`；事件为 `before-open`、`open`、`before-close`、`close`、`ok`、`cancel`；slots 为 `header`、`default`、`footer`。`ok` / `cancel` 与 model 更新发生在关闭动作阶段，`close` 在 afterLeave 后发出。命令入口返回 `{ close, update }`，但 update 不用于替换 title、content 或 callbacks。
- 异步关闭：`onBeforeOk(done)` 有三种模式：返回 `true` 关闭、返回 `false` 保持打开、返回 `Promise<boolean | void>` 并等待；Promise resolve `undefined` 按成功关闭处理。若函数返回 `undefined`，组件进入 callback 模式，必须调用 `done(true)` 或 `done(false)`。异步业务应在 `catch` 中展示失败并 `return false`，不要把 rejection 留给组件。`onBeforeCancel` 只按同步 boolean 处理；显式返回 `true` 才关闭，返回 `false` 或 `undefined` 均阻止关闭。
- 可访问性与响应式：打开后焦点进入抽屉，关闭后回到触发器；标题应描述任务。窄屏使用接近全宽但保留关闭入口，内容区独立滚动，不能让 footer 被软键盘遮挡。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const visible = ref(false)

async function beforeOk() {
  try {
    await Promise.resolve()
    return true
  }
  catch {
    return false
  }
}

function beforeCancel() {
  return true
}
</script>

<template>
  <AButton @click="visible = true">打开详情</AButton>
  <ADrawer
    v-model:visible="visible"
    title="静态详情"
    :width="480"
    :on-before-ok="beforeOk"
    :on-before-cancel="beforeCancel"
  >
    当前内容仅用于演示。
  </ADrawer>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/drawer) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/drawer)

## Message

用于短暂、低打断地反馈一次操作结果。持续错误、需要恢复动作或必须确认的内容改用 Alert、Notification 或 Modal。

- 当前接入：Message 没有模板组件；使用显式导入的 `Message` 静态对象，或组件实例上的 `$message`。plugin 注入方法默认携带 app-level `app._context`，但不会自动继承调用位置最近的局部 `AConfigProvider`；不要虚构模板标签。
- 实际组件名：无模板组件；命令式入口为 `Message`、`$message`。
- 高频契约：静态方法与实例方法包含 `info()`、`success()`、`warning()`、`error()`、`loading()`、`normal()`、`clear()`；配置使用 `content`、`id`、`position`、`showIcon`、`closable`、`duration`、`onClose`。默认 duration 为 3000ms，`0` 表示不自动关闭；同 id 会更新现有消息。调用返回的 handle 可 `close()`，持久 loading 应在业务 `finally` 中关闭。超时或 handle.close 触发的 `onClose` 发生在移除/离场前；`Message.clear()` 直接清空同位置或全部消息，不逐项触发 `onClose`。
- 可访问性与响应式：文案直接说明结果，不连续刷屏；关键失败必须在页面内保留恢复路径。窄屏控制长度，不在 Message 中塞按钮或长堆栈。

```vue
<script setup lang="ts">
import { Message } from '@arco-design/web-vue'

function showResult() {
  Message.success({
    content: '静态数据已核对',
    duration: 3000,
    onClose: () => console.info('消息已关闭'),
  })
}
</script>

<template>
  <AButton type="primary" @click="showResult">显示结果</AButton>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/message) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/message)

## Modal

用于必须中断当前流程的确认、短表单或结果说明；只读长详情优先 Drawer 或独立页面。

- 当前接入：`AModal` 已全局注册；也可显式导入静态 `Modal`，组件实例可使用 `$modal`。命令式 plugin 包装默认携带 app-level `app._context`，但不会自动继承调用位置最近的局部 `AConfigProvider`。
- 实际组件名：模板组件 `AModal`；命令式对象 `Modal`；全局实例入口 `$modal`。
- 高频契约：受控状态为 `visible` / `update:visible`；props 为 `title`、`width`、`mask-closable`、`esc-to-close`、`simple`、`draggable`、`fullscreen`、`unmount-on-close`、`ok-loading`、`on-before-ok`、`on-before-cancel`；事件为 `before-open`、`open`、`before-close`、`close`、`ok`、`cancel`；静态方法含 `open()`、`confirm()`、`info()`、`success()`、`warning()`、`error()`。`ok` / `cancel` 与 model 更新发生在关闭动作阶段，`close` 在 afterLeave 后发出。命令入口返回 `{ close, update }`，但 update 不用于替换 title、content 或 callbacks。
- 异步关闭：`onBeforeOk(done)` 返回 `true` 时关闭，返回 `false` 时保留；返回 `Promise` 时等待，resolve `undefined` 按成功处理。直接返回 `undefined` 表示 callback 模式，必须调用 `done(true)` 或 `done(false)`。异步失败在 `catch` 中处理并 `return false`。`onBeforeCancel` 是同步 boolean 守卫，返回 `true` 才取消；返回 `false` 或 `undefined` 都阻止关闭。
- 可访问性与响应式：标题、确认动作和危险后果要明确；焦点锁定在弹窗内，关闭后恢复。窄屏使用合理边距或 fullscreen，正文滚动而 footer 保持可见。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const visible = ref(false)

async function beforeOk() {
  try {
    await Promise.resolve()
    return true
  }
  catch {
    return false
  }
}

function beforeCancel() {
  return true
}
</script>

<template>
  <AButton status="danger" @click="visible = true">打开确认</AButton>
  <AModal
    v-model:visible="visible"
    title="确认执行静态演示"
    :on-before-ok="beforeOk"
    :on-before-cancel="beforeCancel"
  >
    本示例不会提交真实数据。
  </AModal>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/modal) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/modal)

## Notification

用于可持续阅读、带标题的异步结果或后台事件。简单即时结果优先 Message。

- 当前接入：Notification 没有模板组件；使用显式导入的静态 `Notification`，或组件实例上的 `$notification`。plugin 注入方法默认携带 app-level `app._context`，但不会自动继承调用位置最近的局部 `AConfigProvider`。
- 实际组件名：无模板组件；命令式入口为 `Notification`、`$notification`。
- 高频契约：方法包含 `info()`、`success()`、`warning()`、`error()`、`clear()`；配置使用 `title`、`content`、`id`、`position`、`showIcon`、`closable`、`duration`、`onClose`。默认 duration 为 3000ms，`0` 表示保持显示，同 id 会更新现有通知。静态入口支持 `Notification.remove(id)`；当前 `$notification` 包装只提供各类型方法与 `clear()`，没有实例 `remove`。调用返回的 handle 也可 `close()`；超时或 close 的 `onClose` 在移除/离场前发生，而 `clear()` 直接清空，不逐项触发 `onClose`。
- 可访问性与响应式：标题先写事件，正文写影响和下一步；同类通知应合并，避免读屏轰炸。窄屏限制同时显示数量，内容与关闭按钮不能互相遮挡。

```vue
<script setup lang="ts">
import { Notification } from '@arco-design/web-vue'

function showNotice() {
  Notification.info({
    id: 'static-review-result',
    title: '核对结果',
    content: '静态示例已完成核对。',
    duration: 0,
    onClose: () => console.info('通知已关闭'),
  })
}

function removeNotice() {
  Notification.remove('static-review-result')
}
</script>

<template>
  <ASpace>
    <AButton @click="showNotice">显示通知</AButton>
    <AButton @click="removeNotice">移除通知</AButton>
  </ASpace>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/notification) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/notification)

## Popconfirm

用于在触发器附近确认一个短、明确的操作；复杂影响说明或多字段确认改用 Modal。

- 当前接入：`APopconfirm` 已全局注册。
- 实际组件名：`APopconfirm`。
- 高频契约：props 为 `content`、`position`、`type`、`ok-text`、`cancel-text`、`ok-loading`、`hide-cancel`、`on-before-ok`、`on-before-cancel`；受控状态为 `popup-visible` / `update:popup-visible`；事件为 `ok`、`cancel`、`popup-visible-change`；slots 为 `default`、`content`、`icon`。
- 异步关闭：`onBeforeOk(done)` 返回 `true` 关闭、返回 `false` 保持；返回 `Promise` 时等待，resolve `undefined` 视为成功。直接返回 `undefined` 进入 callback 模式，必须调用 `done(true)` 或 `done(false)`。失败应在 `catch` 中转成可读反馈并 `return false`。`onBeforeCancel` 只接受同步 boolean 语义，返回 `true` 才关闭，返回 `false` 或 `undefined` 都保留弹层。
- 可访问性与响应式：触发器名称应包含动作对象，确认文案说明结果；关闭后焦点返回触发器。窄屏确保弹层不越界，危险操作不能只靠红色提示。

```vue
<script setup lang="ts">
async function beforeOk() {
  try {
    await Promise.resolve()
    return true
  }
  catch {
    return false
  }
}

function beforeCancel() {
  return true
}
</script>

<template>
  <APopconfirm
    content="确认移除这条静态记录吗？"
    :on-before-ok="beforeOk"
    :on-before-cancel="beforeCancel"
  >
    <AButton status="danger">移除记录</AButton>
  </APopconfirm>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/popconfirm) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/popconfirm)

## Result

用于展示一个流程的最终状态和后续动作，不用于页面内短暂提示。

- 当前接入：`AResult` 已全局注册。
- 实际组件名：`AResult`。
- 高频契约：props 为 `status`、`title`、`subtitle`；slots 为 `icon`、`title`、`subtitle`、`extra`、`default`。`status` 负责图标与色彩，业务结果仍由标题和正文表达。
- 可访问性与响应式：标题必须明确成功、失败或影响，错误时给恢复路径；图标不能成为唯一含义。窄屏 extra 操作纵向排列，保持主要动作优先。

```vue
<template>
  <AResult status="success" title="静态检查已完成" subtitle="本示例没有提交真实数据">
    <template #extra>
      <AButton type="primary">返回列表</AButton>
    </template>
  </AResult>
</template>
```

## Skeleton

用于首次加载时保持页面结构稳定；有旧数据可读时优先保留旧数据并标注刷新状态。

- 当前接入：Skeleton 家族已全局注册。
- 实际组件名：`ASkeleton`、`ASkeletonLine`、`ASkeletonShape`。
- 高频契约：容器 props 为 `loading`、`animation`。`loading=true` 时渲染默认 slot 中的骨架，`loading=false` 时才渲染 `#content` 中的真实内容；不能把两个 slot 写反。Line 使用 `rows`、`widths`、`line-height`、`line-spacing`；Shape 使用 `shape`、`size`。骨架只模拟布局，不应展示可交互假控件。
- 可访问性与响应式：加载容器提供可读状态，骨架图形对读屏隐藏；完成后避免焦点跳转。尺寸跟随真实断点布局，防止内容出现时大幅位移。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const loading = ref(true)
</script>

<template>
  <ASkeleton :loading="loading" animation>
    <ASkeletonShape shape="circle" />
    <ASkeletonLine :rows="3" />
    <template #content>
      静态内容已加载。
    </template>
  </ASkeleton>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/skeleton) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/skeleton)

## Spin

用于局部或全屏加载遮罩。短到无法感知的请求不应立即闪烁 loading。

- 当前接入：`ASpin` 已全局注册。
- 实际组件名：`ASpin`。
- 高频契约：props 为 `loading`、`size`、`tip`、`dot`、`delay`；`delay` 用于抑制短加载闪烁；slots 为 `default`、`icon`、`tip`。有默认内容时 `ASpin` 才作为局部区域遮罩；无 default slot 时始终显示 spinner，`loading` 只影响 class。`Message.loading` 是非阻塞短反馈，按钮 `okLoading` 只锁按钮，项目 `FaLoading` / shell overlay 才负责正式应用的全局 loading；这些能力不能互相冒充。
- 可访问性与响应式：加载状态与区域关联并提供可读 tip；遮罩期间明确哪些控件不可操作。窄屏避免全页多层 Spin，长任务应补充进度或取消能力。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const loading = ref(true)
</script>

<template>
  <ASpin :loading="loading" :delay="300" tip="正在整理静态数据">
    <ACard title="区域内容">当前展示静态内容。</ACard>
  </ASpin>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/spin) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/spin)
