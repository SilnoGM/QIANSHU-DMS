# Arco Design Vue 通用与布局组件

本册覆盖 `@arco-design/web-vue@2.58.0` 的 7 个通用与布局家族。示例在正式应用的全局注册环境中直接使用 `A*` 标签；文案和数据均为静态演示。

## Button

用于提交、确认、取消和触发局部操作。`type` 是视觉类型，原生按钮类型由 `html-type` 决定；表单提交必须显式写 `html-type="submit"`。

- 当前接入：`app.use(ArcoVue)` 已全局注册本家族，无需在 SFC 模板中导入组件。
- 实际组件名：`AButton`、`AButtonGroup`。`Button.Group` 对应全局名 `AButtonGroup`。
- 高频契约：props 为 `type`、`shape`、`status`、`size`、`loading`、`disabled`、`long`、`html-type`、`href`；事件为 `click`；slots 为 `default`、`icon`。传 `href` 后根节点变为链接，`html-type` 与 `autofocus` 不再生效。
- 与 Fa* 选择：标准业务动作默认 `AButton`；只有框架壳既有交互明确要求 Fantastic-admin 语义时才用对应 `Fa*` 能力，不能只换标签名。
- 可访问性与响应式：按钮文字应描述结果；图标按钮提供可访问名称。窄屏优先收起次要操作，危险操作保留确认，不用颜色作为唯一状态；loading 时避免重复提交。

```vue
<template>
  <AButtonGroup>
    <AButton>取消</AButton>
    <AButton type="primary" html-type="submit">
      保存
    </AButton>
  </AButtonGroup>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/button) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/button)

## Link

用于导航到资源或页面，不应代替执行状态变化的按钮。`ALink` 始终渲染为 `<a>`；disabled 会移除 `href`，loading / disabled 会阻止 click。

- 当前接入：正式应用已通过全局 Arco plugin 注册 `ALink`。
- 实际组件名：`ALink`。
- 高频契约：props 为 `href`、`status`、`hoverable`、`icon`、`loading`、`disabled`；事件为 `click`；slots 为 `default`、`icon`。外链目标、下载行为和路由行为应由调用方明确。
- 与 Fa* 选择：业务正文与资源链接默认 `ALink`；应用内部路由若需要 Router 的活动态、守卫和 replace 语义，应使用项目路由链接，不要伪造成普通 `href`。
- 可访问性与响应式：链接文字应说明目标；新窗口行为需告知用户。不要使用空 `href` 承载按钮动作；长链接文字允许换行，窄屏不依赖 hover 才显示含义。

```vue
<template>
  <ALink href="https://arco.design/vue/docs/start">
    查看 Arco Design Vue 官方入门
  </ALink>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/link) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/link)

## Typography

用于建立标题、段落、行内强调、复制、编辑与省略层级。家族根组件只是语义容器，不会自动替代页面标题结构。

- 当前接入：Typography 家族随 `ArcoVue` 全局注册。
- 实际组件名：`ATypography`、`ATypographyTitle`、`ATypographyParagraph`、`ATypographyText`。
- 高频契约：子组件共享 `type`、`bold`、`mark`、`underline`、`delete`、`code`、`editable`、`copyable`、`ellipsis`；事件含 `edit-start`、`change`、`edit-end`、`copy`、`ellipsis`、`expand`；slots 含 `default`、`copy-icon`、`copy-tooltip`、`expand-node`。`heading` 仅属于 Title，`blockquote` / `spacing` 仅属于 Paragraph；`ATypography` 根节点是 `<article>`。
- 与 Fa* 选择：业务内容排版默认本家族；纯 CSS 文字样式可直接使用语义 HTML，不必为每一行引入组件。
- 可访问性与响应式：页面标题保持真实的层级顺序；不要只靠字号模拟 heading。省略内容要提供展开或可访问的完整文本，窄屏避免固定行宽；可编辑文本要有明确保存与取消反馈。

```vue
<template>
  <ATypography>
    <ATypographyTitle :heading="3">
      数据概览
    </ATypographyTitle>
    <ATypographyParagraph :ellipsis="{ rows: 2, expandable: true }">
      当前区域展示静态说明；展开后仍保持完整、可复制的文本内容。
    </ATypographyParagraph>
    <ATypographyText type="secondary">
      最近核对：2026-07-15
    </ATypographyText>
  </ATypography>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/typography) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/typography)

## Divider

用于分隔同一区域中的内容组，不用来补偿错误的布局间距。

- 当前接入：`ADivider` 已由全局 plugin 注册。
- 实际组件名：`ADivider`。
- 高频契约：props 为 `direction`、`orientation`、`type`、`size`、`margin`；slot 为 `default`。默认槽文字只在 horizontal 模式渲染，vertical 模式不会显示文字。
- 与 Fa* 选择：普通业务内容分隔默认 `ADivider`；框架导航自身的边界由框架组件负责，不重复叠加。
- 可访问性与响应式：分隔线不能替代标题和分组语义。vertical 分隔只适合横向工具组；窄屏换行后应切换为 horizontal 或移除，避免悬空短线。

```vue
<template>
  <section aria-labelledby="summary-title">
    <h3 id="summary-title">本期摘要</h3>
    <ADivider orientation="left">
      核对信息
    </ADivider>
    <p>所有数据均为静态示例。</p>
  </section>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/divider) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/divider)

## Grid

用于响应式栅格和规则网格。2.58.0 同时提供 `ARow` / `ACol` 的 24 栅格，以及 `AGrid` / `AGridItem` 的网格 API；同一层级选择一套，不混搭两套计算模型。

- 当前接入：两套 Grid API 均由 `ArcoVue` 全局注册。
- 实际组件名：`ARow`、`ACol`、`AGrid`、`AGridItem`。
- 高频契约：Row 使用 `gutter`、`justify`、`align`；Col 使用 `span`、`offset`、`flex` 和响应式 `xs`、`sm`、`md`、`lg`、`xl`、`xxl`。Grid 使用 `cols`、`row-gap`、`col-gap`、`collapsed`、`collapsed-rows`；GridItem 使用 `span`、`offset`、`suffix`。
- 与 Fa* 选择：业务表单和卡片排布默认 Arco Grid；框架页面壳的主栏、侧栏继续服从 Fantastic-admin 布局，不在页面内重新实现应用壳。
- 可访问性与响应式：视觉顺序应与 DOM 和键盘顺序一致，不用 offset 改变含义顺序。先设计窄屏单列，再为宽屏添加列数；表单 label 与错误提示不能因栅格压缩而截断。

```vue
<template>
  <ARow :gutter="[16, 16]">
    <ACol :xs="24" :md="12" :xxl="8">
      <ACard title="待处理">12</ACard>
    </ACol>
    <ACol :xs="24" :md="12" :xxl="8">
      <ACard title="处理中">5</ACard>
    </ACol>
  </ARow>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/grid) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/grid)

## Layout

用于页面区域级布局。正式应用的顶级框架壳已经由 Fantastic-admin 管理；本家族只用于确有独立 header / content / footer / sider 语义的业务子区域。

- 当前接入：Layout 家族随默认 plugin 全局注册。
- 实际组件名：`ALayout`、`ALayoutHeader`、`ALayoutSider`、`ALayoutContent`、`ALayoutFooter`。
- 高频契约：Sider 使用 `v-model:collapsed`、`default-collapsed`、`collapsible`、数值 `width`、`collapsed-width`、`breakpoint`、`resize-directions`；事件 `collapse(collapsed, type)` 的 type 为 `clickTrigger` 或 `responsive`，另有 `breakpoint`；slots 为 `default`、`trigger({ collapsed })`。
- 与 Fa* 选择：应用主壳、导航和工具栏继续使用 Fantastic-admin；只有业务页面内部的独立工作区才考虑 `ALayout`，避免嵌套两套全局导航。
- 可访问性与响应式：Header、Content、Footer 组件提供结构但不替代唯一 `main` 的治理；页面内不要创建第二个主 landmark。Sider 在断点折叠后仍要保留键盘可达的展开入口，并让 `collapse` 来源可观察。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const collapsed = ref(false)
</script>

<template>
  <ALayout>
    <ALayoutSider v-model:collapsed="collapsed" collapsible :width="240" breakpoint="lg">
      <nav aria-label="业务区域导航">区域菜单</nav>
    </ALayoutSider>
    <ALayoutContent>
      <section aria-label="业务区域内容">静态内容</section>
    </ALayoutContent>
  </ALayout>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/layout) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/layout)

## Space

用于一维内容组的稳定间距，适合按钮组、标签组和短字段；复杂二维响应式布局改用 Grid。

- 当前接入：`ASpace` 已全局注册。
- 实际组件名：`ASpace`。
- 高频契约：props 为 `align`、`direction`、`size`、`wrap`、`fill`；slots 为 `default`、`split`。`size` 可为单个预设/数值，也可为 `[horizontal, vertical]`。
- 与 Fa* 选择：业务内联操作默认 `ASpace`；如果 Fantastic-admin 框架组件已有自己的 spacing，不再套一层造成双倍间距。
- 可访问性与响应式：Space 只改变视觉间距，不建立分组语义；相关控件仍用 fieldset、nav 或有名称的容器。窄屏为操作组启用 `wrap`，主要按钮不要被挤出视口；垂直布局可用 `fill` 对齐宽度。

```vue
<template>
  <ASpace wrap :size="[12, 8]">
    <AButton>重置</AButton>
    <AButton type="primary">查询</AButton>
    <ALink href="https://arco.design/vue/component/space">布局说明</ALink>
  </ASpace>
</template>
```
