# Arco Design Vue 数据录入组件

本册覆盖 `@arco-design/web-vue@2.58.0` 的 21 个数据录入家族。示例只使用静态数据，不代表仓库存在对应业务 API、路由、权限或字段。所有表单都应同时考虑键盘、焦点、可见 label、错误提示、窄屏布局和敏感输入安全。

## AutoComplete

用于用户仍可输入任意文本、同时需要候选建议的场景；必须从固定集合选值时改用 Select。

- 当前接入：`AAutoComplete` 已由 `app.use(ArcoVue)` 全局注册。
- 实际组件名：`AAutoComplete`。
- 高频契约：字符串 `v-model`；props 为 `data`、`strict`、`filter-option`、`allow-clear`、`trigger-props`、`virtual-list-props`；事件为 `change`、`search`、`select`、`clear`、`dropdown-scroll`、`dropdown-reach-bottom`；slots 为 `option({ data })`、`footer`；公开 methods 为 `focus()`、`blur()`。`data` 类型允许 number，但 model / events 固定为 string，业务候选值宜统一为 string。
- 可访问性与响应式：提供可见 label，异步候选变化不能抢走输入焦点；键盘必须能浏览和选择。大数据候选配合 `virtual-list-props`，窄屏限制弹层宽度并保留完整文本的可读方式。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const keyword = ref('')
const options = ['华东区域', '华南区域', '西南区域']
</script>

<template>
  <label for="region-keyword">区域关键词</label>
  <AAutoComplete
    id="region-keyword"
    v-model="keyword"
    :data="options"
    allow-clear
    placeholder="请输入或选择区域"
  />
</template>
```

## Cascader

用于从稳定的层级选项中逐级选择。`multiple` 与 `path-mode` 都会改变受控值形状，类型必须先于模板确定。

- 当前接入：`ACascader` 与 `ACascaderPanel` 已全局注册。
- 实际组件名：`ACascader`、`ACascaderPanel`。
- 高频契约：props 为 `options`、`multiple`、`path-mode`、`check-strictly`、`load-more`、`field-names`、`value-key`、`allow-search`、`input-value`、`popup-visible`；事件为 `change`、`search`、`input-value-change`、`popup-visible-change`、`clear`、`focus`、`blur`；slots 为 `option`、`empty`、`label`、`prefix`、`arrow-icon`、`loading-icon`、`search-icon`。对象值需稳定 `value-key`；懒加载必须调用 `done(children)`。
- 可访问性与响应式：受控 `v-model` 的层级和 TypeScript 类型要与 multiple / path-mode 对齐。键盘逐级导航后焦点应回到触发器；空结果和加载失败要可读。大数据先按层懒加载或核对虚拟列表边界，窄屏避免展示过长完整路径。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const regionPath = ref<string[]>([])
const regionOptions = [
  { label: '华东', value: 'east', children: [{ label: '示例城市', value: 'sample-city' }] },
]
</script>

<template>
  <ACascader
    v-model="regionPath"
    :options="regionOptions"
    path-mode
    allow-search
    placeholder="请选择区域"
  />
</template>
```

## Checkbox

用于相互独立的布尔选择或多选集合。单体 model 是 boolean，Group model 是数组；不要用同一状态兼容两种形状。

- 当前接入：Checkbox 家族已随默认 plugin 全局注册。
- 实际组件名：`ACheckbox`、`ACheckboxGroup`。
- 高频契约：单体使用 boolean `v-model` 与 `default-checked`；组使用数组 `v-model`、`options`、`max`、`direction`；事件为 `change(value, event)`；slots 为 `default`、`checkbox`，Group 另有 `label`。`indeterminate` 仅是视觉状态，不是第三种 model 值。
- 可访问性与响应式：每一项必须有文字 label，分组用 fieldset / legend 或等价语义；错误提示与组关联。键盘 Space 可切换；窄屏使用 vertical，不能只用颜色表达已选或部分选择。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const channels = ref<string[]>(['email'])
</script>

<template>
  <ACheckboxGroup v-model="channels" direction="vertical">
    <ACheckbox value="email">邮件通知</ACheckbox>
    <ACheckbox value="desktop">桌面通知</ACheckbox>
  </ACheckboxGroup>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/checkbox) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/checkbox)

## ColorPicker

用于选择可视化颜色值。2.58.0 确实导出本家族，但只包含一个组件。

- 当前接入：`AColorPicker` 已全局注册。
- 实际组件名：`AColorPicker`，没有家族子组件。
- 高频契约：props 为 `model-value`、`format`（`hex` / `rgb`）、`size`、`show-text`、`show-history`、`show-preset`、`disabled-alpha`、`hide-trigger`、`trigger-props`、`history-colors`、`preset-colors`；事件为 `change`、`popup-visible-change(visible, value)`；只有 `default` 自定义触发器 slot。没有直接 `popup-visible` 或 `allow-clear`；弹层控制走 `trigger-props`。alpha 开启时 hex 可输出 `#RRGGBBAA`，rgb 可输出 `rgba(...)`；history 不会自动持久化。
- 可访问性与响应式：颜色值旁必须有可读文字或业务含义，不能只靠色块。键盘触发器要有名称；窄屏为面板预留空间。保存前根据后端契约规范化格式，历史颜色若需持久化必须由业务明确实现。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const accentColor = ref('#165DFFFF')
</script>

<template>
  <AColorPicker v-model="accentColor" format="hex" show-text show-preset />
</template>
```

## DatePicker

用于日期、周、月、季度、年或日期范围。`format` 控制展示，`value-format` 控制 model 类型和序列化格式，两者不能混为一谈。

- 当前接入：DatePicker 家族已全局注册。
- 实际组件名：`ADatePicker`、`ARangePicker`、`AWeekPicker`、`AMonthPicker`、`AQuarterPicker`、`AYearPicker`。
- 高频契约：props 为 `format`、`value-format`、`show-time`、`disabled-date`、`disabled-time`、`shortcuts`、`picker-value`、`popup-visible`；事件为 `change`、`select`、`ok`、`clear`、`select-shortcut`、`picker-value-change`、`popup-visible-change`；slots 为 `default`、`cell`、`extra`、`prefix`、`suffix-icon` 及翻页图标，Range 另有 `separator`。`value-format="timestamp"` 返回 number，大小写严格的 `value-format="Date"` 返回 Date，格式串返回 string；省略时也默认返回格式化 string，而不是 Date。
- 可访问性与响应式：输入必须有可见 label，禁用日期要有业务说明；键盘选择、清除和焦点返回均需测试。窄屏核对范围面板是否溢出；提交前明确时区、起止边界与空值语义。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const reportDate = ref<string>()
</script>

<template>
  <ADatePicker
    v-model="reportDate"
    format="YYYY-MM-DD"
    value-format="YYYY-MM-DD"
    allow-clear
    placeholder="请选择报表日期"
  />
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/date-picker) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/date-picker)

## Form

用于组织 model、字段校验、错误展示和提交生命周期。标准业务表单默认 Arco；`FaForm` 仅在 Fantastic-admin 框架语义明确要求时使用，不能只替换组件名完成迁移。

- 当前接入：`AForm`、`AFormItem` 已全局注册；TypeScript 实例类型应显式导入。
- 实际组件名：`AForm`、`AFormItem`（`Form.Item`）。
- 高频契约：Form 使用 `model`、`rules`、`layout`、`label-col-props`、`wrapper-col-props`、`scroll-to-first-error`；Item 使用 `field`、`label`、`rules`、`validate-trigger`、`help`、`extra`、`validate-status`；事件为 `submit`、`submit-success`、`submit-failed`；methods 为 `validate()`、`validateField()`、`resetFields()`、`clearValidate()`、`setFields()`、`scrollToField()`。`validate()` 成功返回 `undefined`、失败返回 error map；2.58.0 自定义 validator 是 callback 契约，不应假定靠 throw 失败。
- 可访问性与响应式：每个 `field` 应对应稳定 label，错误提示与控件关联；提交失败后把焦点或视口移到首个错误。窄屏优先 vertical，不压缩 label；敏感输入不写入日志、URL 或持久化草稿。

从 `FaForm` 迁移时必须重写语义：`validation-schema` → `rules`，`name` → `field`，外部 `FormExpose.submit()` → 内部 `validate()`，`componentField` → Arco props / slots，并重新核对 `v-model`、`model`、`html-type="submit"`、`@submit-success` 与 `@submit-failed`。

```vue
<script setup lang="ts">
import type { FormInstance } from '@arco-design/web-vue'
import { reactive, ref } from 'vue'

const formRef = ref<FormInstance>()
const model = reactive({ name: '' })
const rules = {
  name: [{ required: true, message: '请输入名称' }],
}
</script>

<template>
  <AForm ref="formRef" :model="model" :rules="rules" layout="vertical">
    <AFormItem field="name" label="名称">
      <AInput v-model="model.name" />
    </AFormItem>
    <AButton type="primary" html-type="submit">保存</AButton>
  </AForm>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/form) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/form)

## Input

用于单行文本、搜索和密码输入；多行文本使用独立 Textarea 家族。

- 当前接入：Input 家族已全局注册。
- 实际组件名：`AInput`、`AInputSearch`、`AInputPassword`、`AInputGroup`。
- 高频契约：共享 props 为 `model-value`、`allow-clear`、`max-length`、`show-word-limit`、`input-attrs`；事件为 `input`、`change`、`press-enter`、`clear`、`focus`、`blur`；slots 为 `prefix`、`suffix`、`prepend`、`append`；公开 methods 为 `focus()`、`blur()`。Search 增加 `search` 和 `button-default` / `button-icon` slots；Password 增加 `visibility-change` 与 `v-model:visibility`。
- 可访问性与响应式：placeholder 不是 label。2.58.0 的内置 clear 与 password visibility 控件都基于 `IconHover`，最终渲染为绑定 click 的普通 `span`，没有 `tabindex`、原生 button 语义或键盘事件，因此不能声称它们已经键盘可达。键盘可访问性是硬要求时，关闭 `allow-clear` / `invisible-button`，在 suffix slot 中使用原生 button 自行控制状态。窄屏让输入框占满可用宽度。密码、token 等不得写日志、遥测、URL 或本地明文缓存。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const keyword = ref('')
const password = ref('')
// 2.58.0 源码中该受控值为 true 时底层 input 使用 password 类型。
const passwordMasked = ref(true)
</script>

<template>
  <label for="search-keyword">关键词</label>
  <AInput id="search-keyword" v-model="keyword" :allow-clear="false" placeholder="请输入关键词">
    <template #suffix>
      <button v-if="keyword" type="button" aria-label="清空关键词" @click="keyword = ''">
        清空
      </button>
    </template>
  </AInput>

  <label for="account-password">密码</label>
  <AInputPassword
    id="account-password"
    v-model="password"
    v-model:visibility="passwordMasked"
    :allow-clear="false"
    :invisible-button="false"
  >
    <template #suffix>
      <button
        type="button"
        :aria-label="passwordMasked ? '显示密码' : '隐藏密码'"
        :aria-pressed="!passwordMasked"
        @click="passwordMasked = !passwordMasked"
      >
        {{ passwordMasked ? '显示' : '隐藏' }}
      </button>
    </template>
  </AInputPassword>
</template>
```

## InputNumber

用于有上下界、步长或格式要求的数值，不用普通 Input 手工解析。

- 当前接入：`AInputNumber` 已全局注册。
- 实际组件名：`AInputNumber`。
- 高频契约：props 为 `min`、`max`、`step`、`precision`、`mode`、`formatter`、`parser`、`model-event`、`hide-button`、`allow-clear`；事件为 `input(number, raw, event)`、`change`、`clear`、`focus`、`blur`、`keydown`；slots 为 `prefix`、`suffix`、`prepend`、`append`、`plus`、`minus`；methods 为 `focus()`、`blur()`。`formatter` 与 `parser` 应成对；`model-event` 默认 change，实时 model 才改为 input；清空值为 `undefined`。
- 可访问性与响应式：label、单位和范围说明必须可读；错误不能只用红色。键盘增减时核对 step 与边界；窄屏避免附加单位挤压输入。金额和精度规则必须在服务端再次验证。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const quantity = ref<number>()
</script>

<template>
  <AInputNumber v-model="quantity" :min="0" :max="999" :step="1" allow-clear>
    <template #suffix>件</template>
  </AInputNumber>
</template>
```

## InputTag

用于录入可增删的短标签集合，不应用于大规模实体选择。

- 当前接入：`AInputTag` 已全局注册。
- 实际组件名：`AInputTag`。
- 高频契约：支持 `v-model` 与 `v-model:input-value` 两份受控状态；props 为 `max-tag-count`、`retain-input-value`、`unique-value`、`format-tag`、`field-names`；事件为 `change`、`input-value-change`、`press-enter`、`remove`、`clear`、`focus`、`blur`；slots 为 `tag({ data })`、`prefix`、`suffix`；methods 为 `focus()`、`blur()`。`max-tag-count` 只折叠展示，不是录入上限；对象标签要配 `field-names`。
- 可访问性与响应式：移除按钮应有可访问名称，键盘删除前保留可预测焦点；错误提示说明数量、重复和格式。窄屏允许标签换行并限制单个标签宽度；敏感值不应作为标签显示。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const tags = ref<string[]>(['已核对'])
</script>

<template>
  <AInputTag v-model="tags" unique-value allow-clear placeholder="输入后按 Enter" />
</template>
```

## Mention

用于在一段完整文本中插入带前缀的候选项。model 始终是完整字符串，不会输出 token 数组。

- 当前接入：`AMention` 已全局注册。
- 实际组件名：`AMention`。
- 高频契约：props 为 `data`、`prefix`、`split`、`type`（input / textarea）、`allow-clear`；事件为 `search(query, prefix)`、`select`、`change`、`clear`、`focus`、`blur`；slot 为 `option({ data })`；methods 为 `focus()`、`blur()`。textarea 模式不会转发 Input 的 prefix / suffix slots。

```vue
import { ref } from 'vue'

const note = ref('')
const candidates = ['示例成员甲', '示例成员乙']
</script>

<template>
  <AMention v-model="note" :data="candidates" type="textarea" placeholder="输入 @ 获取候选" />
</template>
```

## Radio

用于从少量互斥选项中选择一个值。选项多、文本长或需要搜索时改用 Select。

- 当前接入：Radio 家族已全局注册。

```vue
</script>

<template>
  <ARadioGroup v-model="density" direction="vertical">

    <ARadio value="compact">紧凑</ARadio>
  </ARadioGroup>
</template>
```

## Rate

用于有限等级的主观评分，不用于高精度数值录入。

- 当前接入：`ARate` 已全局注册。
- 实际组件名：`ARate`。
- 高频契约：props 为 `count`、`allow-half`、`allow-clear`、`grading`、`readonly`、`color`；事件为 `change`、`hover-change`；slot 为 `character({ index })`。`grading` 源码固定生成 5 级，不再按 `count` 生成普通星级。
- 可访问性与响应式：为评分提供 label 和当前数值文本，不能只显示图形；键盘调整后朗读结果。窄屏保证每个目标有足够点击区域；readonly 应显示为内容而非可操作控件假象。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const score = ref(3)
</script>

<template>
  <ARate v-model="score" allow-half />
  <span aria-live="polite">当前评分：{{ score }}</span>
</template>
```

## Select

用于从受控选项集合中单选或多选。可自由输入的建议场景使用 AutoComplete。

- 当前接入：Select 家族已全局注册。
- 实际组件名：`ASelect`、`AOption`、`AOptgroup`；静态 API 名是 `Select.Option` 与 `Select.OptGroup`，全局标签不是 `AOptionGroup`。
- 高频契约：props 为 `multiple`、`options`、`allow-search`、`allow-create`、`input-value`、`filter-option`、`field-names`、`value-key`、`limit`、`popup-visible`；事件为 `change`、`search`、`remove`、`clear`、`exceed-limit`、`dropdown-scroll`、`dropdown-reach-bottom`；slots 为 `default`、`option`、`label`、`trigger`、`header`、`footer`、`empty`、`prefix` 和图标 slots。multiple 时 model 是数组；对象值必须提供稳定 `value-key`；没有公开 `focus()` / `blur()` method。
- 可访问性与响应式：提供可见 label，键盘搜索、清除和多选移除均需测试；错误提示与触发器关联。大数据结合服务端过滤、分页或已验证的虚拟列表能力，不能一次渲染无限选项；窄屏控制弹层和 tag 折叠。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const status = ref<string>()
</script>

<template>
```

## Slider

```vue
<script setup lang="ts">
import { ref } from 'vue'

<template>
  <ASlider v-model="threshold" :min="0" :max="100" :step="5" show-input />
</template>
```

用于时间或时间范围。2.58.0 只有 `ATimePicker`：范围模式通过 `type="time-range"`，不存在 `ATimeRangePicker`。

```vue
import { ref } from 'vue'

const serviceWindow = ref<string[]>([])
</script>

<template>
  <ATimePicker
    v-model="serviceWindow"
    type="time-range"
    format="HH:mm"
    :step="{ minute: 15 }"
  />
</template>
```

## Transfer

用于在来源栏和目标栏之间移动一组 string value。目标集合与当前勾选集合是两份不同的受控状态。

- 当前接入：`ATransfer` 已全局注册。
- 实际组件名：`ATransfer`。
- 高频契约：props 为 `data`、`model-value`、`selected`、`simple`、`one-way`、`show-search`、`show-select-all`、`title`；事件为 `change`、`select`、`search`；支持 `v-model` 与 `v-model:selected`；slots 为 `source`、`target`、`source-title`、`target-title`。`v-model` 是目标栏 value 集合，selected 是两栏当前勾选集合，不能共用一个 ref。
- 可访问性与响应式：2.58.0 的两个内置移动按钮固定为 `tabindex="-1"`，固定英文 aria-label 只说明左右方向、不包含数量；`to-target-icon` / `to-source-icon` slots 只能替换箭头图标，没有覆盖 API 可改按钮的 tabindex、完整 aria-label 或键盘处理。因此不能承诺 `ATransfer` 的移动操作满足键盘与数量播报要求。若这是硬要求，应另建业务双列表或分步选择器，以原生 `<button type="button">` 实现移动动作并把动态选中数量写进可访问名称。大数据先搜索、分页或验证虚拟列表策略；窄屏优先使用上下布局或分步选择，不强行横向滚动。

```vue
<script setup lang="ts">
import type { TransferItem } from '@arco-design/web-vue/es/transfer/interface'
import { ref } from 'vue'

const targetValues = ref<string[]>([])
const selectedValues = ref<string[]>([])
const items = [
  { label: '示例成员甲', value: 'member-a', disabled: false },
  { label: '示例成员乙', value: 'member-b', disabled: false },
] satisfies TransferItem[]
</script>

<template>
  <ATransfer
    v-model="targetValues"
    v-model:selected="selectedValues"
    :data="items"
    show-search
  />
</template>
```

业务替代组件的操作控件至少应使用真实按钮和动态数量标签，例如：

```vue
<button
  type="button"
  :aria-label="`将选中的 ${selectedSourceValues.length} 项移至目标列表`"
  @click="moveSelectedToTarget"
>
  移至目标列表
</button>
```

## Upload

用于选择文件并管理上传状态。组件不是安全边界：文件类型、大小、内容、所有权和权限都必须做服务端验证。

- 当前接入：`AUpload` 已全局注册；`RequestOption`、`UploadRequest`、`FileItem` 等 TypeScript 类型需显式导入。
- 实际组件名：`AUpload`。
- 高频契约：props 为 `file-list`、`action`、`accept`、`multiple`、`limit`、`auto-upload`、`list-type`、`custom-request`、`on-before-upload`、`on-before-remove`、`response-url-key`；事件为 `change`、`progress`、`success`、`error`、`preview`、`exceed-limit`；slots 为 `upload-button`、`upload-item`；methods 为 `submit()`、`abort()`、`updateFile()`、`upload()`。before 回调是 props，不是 emit 事件。
- 可访问性与响应式：选择按钮有明确文件要求，进度与错误使用 live region 或可读文本；键盘可以选择、重试和移除。窄屏文件名可换行但保留扩展名与状态；预览不暴露敏感文件。不得硬编码 token，不能把完整认证头写日志。

`customRequest(option)` 必须主动调用 `onProgress(0..1)`、`onSuccess()` 或 `onError()`，并**同步**返回 `UploadRequest`（可带 `abort`）；只返回 Promise 不会驱动 Arco 状态。正式应用的项目 HTTP client 入口 `src/api/index.ts` 默认导出了已配置 Axios instance `api`，但当前没有可直接引用的上传端点和 upload-specific progress adapter，本文不能凭空创建调用。下面把可复用上传组件设计为从父级接收已经基于真实业务契约配置好的 `customRequest`；模板真实绑定该 prop，并保留 Arco 默认自动上传：

```vue
<script setup lang="ts">
import type { RequestOption, UploadRequest } from '@arco-design/web-vue'

type CustomRequest = (option: RequestOption) => UploadRequest

const props = defineProps<{
  customRequest: CustomRequest
}>()
</script>

<template>
  <AUpload :custom-request="props.customRequest">
    <template #upload-button>
      <AButton>选择文件</AButton>
    </template>
  </AUpload>
</template>
```

父级接入真实上传前，先基于项目 `api` 与已确认的服务端契约创建 handler，处理认证注入、取消、超时、进度和错误，再传给本组件；客户端 `accept` 只是提示，不能代替服务端验证。

官方参考：[当前组件文档](https://arco.design/vue/component/upload) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/upload)

## VerificationCode

用于固定长度的分格短码输入。2.58.0 确实存在本家族，但默认允许任意字符，不是“数字验证码”组件的同义词。

- 当前接入：`AVerificationCode` 已全局注册。
- 实际组件名：`AVerificationCode`；没有子组件、slot 或公开 method。
- 高频契约：props 为 `length`（默认 6）、`size`、`disabled`、`masked`、`readonly`、`error`、`separator`、`formatter`；事件为 `input(raw, index, event)`、`change`、`finish`。`formatter(raw, index, currentValue)` 返回 false 拒绝，返回 string 时只取首字符；input 在 formatter 前发出，change / model update 在格式化后发出。`separator` 是返回 VNode 的 prop，不是 slot，并且每格后（含最后一格）都会调用。填满后触发 finish，继续编辑完整值时可能再次触发。
- 可访问性与响应式：fieldset / legend 或等价 label 说明用途，粘贴、退格、方向键和错误焦点均需测试；组件没有 `focus()`，不要编造调用。窄屏确保所有格可见。masked 只改变显示，不代表加密；验证码不得写日志或长期保存，服务端必须限制尝试次数、校验过期与重放。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const code = ref('')
const digitsOnly = (raw: string) => /^\d$/u.test(raw) ? raw : false
</script>

<template>
  <fieldset>
    <legend>输入 6 位数字验证码</legend>
    <AVerificationCode v-model="code" :length="6" :formatter="digitsOnly" masked />
  </fieldset>
</template>
```
