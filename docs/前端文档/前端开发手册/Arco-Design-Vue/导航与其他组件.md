# Arco Design Vue 导航与其他组件

本册覆盖 `@arco-design/web-vue@2.58.0` 的 10 个导航家族与 8 个其他家族。业务页面可以使用这些组件，但不得替换 Fantastic-admin 已负责的顶栏、路由页签、全局返回顶部和应用级配置。

## Affix

用于让局部工具条在指定滚动容器中保持可见，不用于重新实现框架顶栏。

- 当前接入：`AAffix` 已由 `app.use(ArcoVue)` 全局注册。
- 实际组件名：`AAffix`。
- 高频契约：props 为 `offset-top`、`offset-bottom`、`target`、`target-container`；事件为 `change(fixed)`；公开 method 为 `updatePosition()`。设置 `offsetBottom` 后进入 bottom 模式并忽略 top 偏移，业务偏移还要计入 Fantastic-admin Topbar 高度。
- 可访问性与响应式：固定内容不能遮挡 heading、焦点或错误提示；DOM 顺序保持原位。窄屏优先减少固定操作，验证软键盘与安全区域。

```vue
<template>
  <AAffix :offset-top="72">
    <AButton type="primary">保存当前草稿</AButton>
  </AAffix>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/affix) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/affix)

## Anchor

用于同一长页面内的章节定位，不用于应用路由导航。

- 当前接入：Anchor 家族已全局注册。
- 实际组件名：`AAnchor`、`AAnchorLink`。
- 高频契约：容器 props 为 `boundary`、`line-less`、`scroll-container`、`change-hash`、`smooth`；事件为 `select`、`change`。Link 使用 `href`、`title`。`changeHash=false` 才不改变 URL；2.58.0 虽声明 `smooth`，运行时未读取该 prop，实现仍固定执行约 300ms 动画，不能承诺 `smooth=false` 会关闭动画。
- 可访问性与响应式：链接文字与目标 heading 一致，目标需有稳定 id；焦点与视觉滚动都要可恢复。窄屏可折叠目录，但不能让正文只能通过 Anchor 到达。

```vue
<template>
  <AAnchor :change-hash="false">
    <AAnchorLink href="#summary" title="摘要" />
    <AAnchorLink href="#details" title="明细" />
  </AAnchor>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/anchor) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/anchor)

## BackTop

用于独立内滚动容器返回顶部。正式应用已经挂载 `AppBackToTop`，不得再创建第二个全局实例。

- 当前接入：`ABackTop` 已全局注册；应用级返回顶部由 Fantastic-admin 负责。
- 实际组件名：`ABackTop`。
- 高频契约：props 为 `visible-height`、`target-container`、`easing`、`duration`；默认 slot 可替换触发器。`target-container` 接受 selector 或 HTMLElement，必须指向真实滚动容器。
- 可访问性与响应式：自定义默认 slot 使用 `type="button"` 的原生按钮并给 `aria-label`；返回后焦点不能丢失。窄屏避开浮动操作与底部安全区域。

```vue
<template>
  <div id="detail-scroll" style="height: 240px; overflow: auto">
    <div style="height: 720px">独立滚动区域</div>
    <ABackTop target-container="#detail-scroll" :visible-height="120">
      <button type="button" aria-label="返回区域顶部">回到顶部</button>
    </ABackTop>
  </div>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/back-top) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/back-top)

## Breadcrumb

用于业务区域内部的位置层级。Fantastic-admin 顶栏面包屑已由 route meta 与菜单状态生成，不得用本家族替换。

- 当前接入：Breadcrumb 家族已全局注册。
- 实际组件名：`ABreadcrumb`、`ABreadcrumbItem`。
- 高频契约：容器使用 `max-count`、`routes`、`separator`、`custom-url`，slots 为 `default`、`separator`、`item-render`；Item 使用 `droplist` 与 `separator` slots。`routes` 默认生成普通 `<a href>`，不会自动接入 Vue Router；业务路由应显式使用 `RouterLink` 或 `item-render`。
- 可访问性与响应式：置于有名称的 breadcrumb nav 中，并标识当前项；层级名应可理解。窄屏用 `max-count` 折叠中间层，首尾层级仍可见。

```vue
<template>
  <nav aria-label="业务区域路径">
    <ABreadcrumb :max-count="3">
      <ABreadcrumbItem>工作台</ABreadcrumbItem>
      <ABreadcrumbItem>订单中心</ABreadcrumbItem>
      <ABreadcrumbItem>订单详情</ABreadcrumbItem>
    </ABreadcrumb>
  </nav>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/breadcrumb) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/breadcrumb)

## Dropdown

用于从触发器展开短操作列表，不用于复杂表单或大段说明。

- 当前接入：Dropdown 家族已全局注册。
- 实际组件名：`ADropdown`、`ADoption`、`ADgroup`、`ADsubmenu`、`ADropdownButton`。
- 高频契约：受控状态为 `popup-visible` / `update:popup-visible`；props 为 `trigger`、`position`、`hide-on-select`、`popup-max-height`；事件为 `select(value)`、`popup-visible-change`；slots 为 `default`、`content`、`footer`。Option 的稳定 value 使用 `string | number`。
- 可访问性与响应式：默认触发器使用原生 button 或语义按钮，并提供展开状态；键盘操作必须实测。窄屏限制弹层高度，危险项与普通项分组。

```vue
<template>
  <ADropdown trigger="click" @select="value => console.info('选择动作', value)">
    <button type="button">更多操作</button>
    <template #content>
      <ADoption value="duplicate">复制记录</ADoption>
      <ADoption value="archive">归档记录</ADoption>
    </template>
  </ADropdown>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/dropdown) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/dropdown)

## Menu

用于业务区域内部的局部菜单；应用主导航继续由 Fantastic-admin 路由与菜单系统管理。

- 当前接入：Menu 家族已全局注册。
- 实际组件名：`AMenu`、`AMenuItem`、`AMenuItemGroup`、`ASubMenu`。
- 高频契约：三组受控状态为 `selectedKeys` / `update:selectedKeys`、`openKeys` / `update:openKeys`、`collapsed` / `update:collapsed`；props 还有 `mode`、`theme`、`accordion`、`auto-open-selected`；事件为 `menu-item-click`、`sub-menu-click`、`collapse`。MenuItem 以 VNode `key` 标识，不使用 value；本家族不会自动执行路由。
- 可访问性与响应式：选中态、展开态与键盘焦点需可分辨；图标不能替代文字。窄屏局部菜单可折叠，但必须保留可读展开入口。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const selectedKeys = ref<string[]>(['pending'])
const openKeys = ref<string[]>(['orders'])
</script>

<template>
  <AMenu v-model:selected-keys="selectedKeys" v-model:open-keys="openKeys">
    <ASubMenu key="orders" title="订单中心">
      <AMenuItem key="pending">待审核订单</AMenuItem>
      <AMenuItem key="completed">已完成订单</AMenuItem>
    </ASubMenu>
  </AMenu>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/menu) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/menu)

## PageHeader

用于页面或局部业务区域的标题、说明、返回与附加内容。先按三层职责选择，不能只因名称接近就替换。

- 当前接入：业务标准页壳优先项目 `FaPageHeader`；Arco 的 `APageHeader` 已全局注册。
- 实际组件名：项目组件 `FaPageHeader`，Arco 组件 `APageHeader`。
- 高频契约：`FaPageHeader` 提供 `title`、`description` 与 `#title`、`#description`、`#default`，适合标准业务页标题与右侧操作。`APageHeader` 提供 `title`、`subtitle`、`show-back`，以及 `#back-icon`、`#breadcrumb`、`#title`、`#subtitle`、`#extra`；正文使用 `#default`，没有 `#content`。其 back 只发事件，不负责路由，必须由页面显式处理。
- 框架边界：真相源为 `web/packages/components/src/basic/page-header/index.vue`。应用顶栏标题、路由和面包屑仍由 Fantastic-admin shell 管理；`APageHeader` 只用于确有局部 back、breadcrumb 或正文附加区的业务区域。
- 可访问性与响应式：页面只保留清晰的主标题层级，返回按钮说明目标。窄屏让 description 和操作区换行，不重复渲染框架标题。

```vue
<template>
  <APageHeader title="订单详情" subtitle="静态示例" :show-back="false">
    <template #extra>
      <AButton type="primary">保存草稿</AButton>
    </template>
    <p>此处为局部业务内容。</p>
  </APageHeader>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/page-header) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/page-header)

## Pagination

用于分页浏览已知总量的数据；服务端查询状态由页面负责。

- 当前接入：`APagination` 已全局注册。
- 实际组件名：`APagination`。
- 高频契约：两组受控状态为 `current` / `update:current` 与 `pageSize` / `update:pageSize`；事件为 `change`、`page-size-change`；props 为 `total`、`show-total`、`show-jumper`、`show-page-size`、`page-size-options`、`simple`、`auto-adjust`。`autoAdjust` 在 total 或 pageSize 变化时可能再次更新 current，服务端请求需要去重。
- 可访问性与响应式：页码按钮有可读名称，当前页可感知；换页后焦点与列表标题关系明确。窄屏可启用 simple 或隐藏次要控制，但保留总量说明。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const current = ref(1)
const pageSize = ref(20)
</script>

<template>
  <APagination
    v-model:current="current"
    v-model:page-size="pageSize"
    :total="128"
    show-total
    show-page-size
  />
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/pagination) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/pagination)

## Steps

用于表达一个流程的阶段和完成度，不是路由页签或内容分类器。

- 当前接入：Steps 家族已全局注册。
- 实际组件名：`ASteps`、`AStep`。
- 高频契约：受控状态 `current` 从 1 开始；props 为 `status`、`direction`、`label-placement`、`small`、`changeable`；只有 `changeable` 才允许点击切换并发出 `change`。Step 使用 `title`、`description`、`status`、`disabled`，slots 为 `node`、`icon`、`title`、`description`。
- 可访问性与响应式：同时表达当前、完成和错误文本；不能只依赖颜色。窄屏改为 vertical，点击切换不能绕过业务前置校验。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const current = ref(2)
</script>

<template>
  <ASteps v-model:current="current" changeable>
    <AStep title="填写信息" />
    <AStep title="复核内容" />
    <AStep title="完成" />
  </ASteps>
</template>
```

## Tabs

用于页面内部同级内容分类。必须区分项目轻量内容标签、Arco 内容标签和 Fantastic-admin 顶部路由页签。

- 当前接入：项目 `FaTabs` 可用于简单内容切换，Arco 的 `ATabs` / `ATabPane` 已全局注册。
- 实际组件名：项目组件 `FaTabs`；Arco 组件 `ATabs`、`ATabPane`；框架路由页签由 `Topbar/Tabbar` 实现。
- 高频契约：`FaTabs` 接收 `modelValue` 与 `list`。`ATabs` 受控状态为 `activeKey`，props 为 `type`、`direction`、`editable`、`show-add-button`、`destroyOnHide`、`lazyLoad`；事件为 `change`、`add`、`delete`。`editable` 只发 `add` / `delete`，调用方仍需修改 pane 数据。
- 三层边界：`FaTabs` 真相源为 `web/packages/components/src/basic/tabs/index.vue`，适合简单内容分组；`ATabs` 适合需要 editable、销毁或懒加载的复杂内容。顶部路由页签真相源为 `web/apps/qsmds-arco/src/layouts/components/Topbar/Tabbar/index.vue`，以 `routeName` / `tabId` 标识路由，并联合 `Sortable` 拖拽、快捷键、固定、`keepAlive`、`iframe` 与持久化状态；不能用可编辑 `ATabs` 替换。
- 可访问性与响应式：tab 名称简短且面板关系可感知，键盘左右切换不触发路由副作用。窄屏可滚动 tab 列表，但不要把路由页签复制进正文。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const activeKey = ref('summary')
</script>

<template>
  <ATabs v-model:active-key="activeKey" destroy-on-hide lazy-load>
    <ATabPane key="summary" title="摘要">静态摘要</ATabPane>
    <ATabPane key="details" title="明细">静态明细</ATabPane>
  </ATabs>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/tabs) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/tabs)

## ConfigProvider

用于配置 Arco 的 locale、size、prefix、空状态和全局组件参数。正式应用顶层 Provider 已存在，页面只做必要的局部覆盖。

- 当前接入：`AConfigProvider` 已全局注册；正式应用 Provider 已接管语言和主题链路。
- 实际组件名：`AConfigProvider`。
- 高频契约：props 为 `prefix-cls`、`locale`、`size`、`global`、`update-at-scroll`、`scroll-to-close`、`exchange-time`、`rtl`；2.58.0 没有 `component-config`。`#default` 承载后代内容，`#empty` 用于后代空状态且不是 prop。嵌套 Provider 只影响后代组件；命令式反馈不保证继承最近的局部 Provider，而是依赖显式 context 或全局配置。
- 可访问性与响应式：语言变化后重新核对 aria 文案、日期格式和布局长度；不要在局部 Provider 中随意开启 `global`。响应式尺寸应由信息密度决定，不以全局 small 掩盖布局问题。

```vue
<script setup lang="ts">
import zhCN from '@arco-design/web-vue/es/locale/lang/zh-cn'
</script>

<template>
  <AConfigProvider :locale="zhCN" size="medium">
    <AButton>局部配置示例</AButton>
  </AConfigProvider>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/config-provider) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/config-provider)

## Icon

用于呈现 Arco 图标或自定义 SVG 容器。项目通用图标名、Iconify、sprite 与图片仍优先交给 `FaIcon`。

- 当前接入：整包 plugin 在运行时注册 Icon，但 `components.d.ts` 没有 `AIcon` 的全局模板类型增强；正式应用未安装独立 `ArcoVueIcon` plugin。
- 实际组件名：底层组件导出名 `Icon`，运行时全局名 `AIcon`；命名图标如 `IconSearch` 从 `@arco-design/web-vue/es/icon` 显式导入。TypeScript SFC 优先显式导入，不依赖缺失的全局模板类型。
- 高频契约：`Icon` 是 SVG 容器，props 为 `size`、`rotate`、`spin`；它的 `type` 只作为 class，不会按名称生成图标。`IconSearch` 等 `IconXxx` 才包含具体 path。`addFromIconFontCn()` 会加载外部 iconfont script，只允许可信地址，并同步核对 CSP；项目默认不需要它。
- 可访问性与响应式：装饰图标对读屏隐藏，独立图标按钮提供可访问名称；不能只靠图形表达危险状态。图标尺寸跟随文字，不在窄屏无限缩小点击区域。

```vue
<script setup lang="ts">
import { Icon as ArcoIcon } from '@arco-design/web-vue'
import { IconSearch } from '@arco-design/web-vue/es/icon'
</script>

<template>
  <AButton aria-label="搜索静态记录">
    <template #icon><IconSearch /></template>
    搜索
  </AButton>
  <ArcoIcon :size="20" aria-hidden="true">
    <circle cx="8" cy="8" r="6" />
  </ArcoIcon>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/icon-component) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/icon-component)

## OverflowList

用于按可用宽度隐藏尾部或头部项目，并展示隐藏数量；不是分页器。

- 当前接入：整包 plugin 运行时注册本组件，但全局模板类型缺失；TypeScript SFC 建议显式导入。
- 实际组件名：导出名 `OverflowList`，运行时全局名 `AOverflowList`。
- 高频契约：props 为 `min`、`margin`、`from`；事件 `change(number)` 的 number 是隐藏数量；`#overflow` slot 通过 `{ number }` 自定义汇总。组件直接测量子节点宽度，父容器必须有约束宽度并常需 `min-width: 0`；`min` 会强制保留最少项目，即使仍溢出。
- 可访问性与响应式：汇总入口说明隐藏数量并可访问完整项目；隐藏不能改变信息优先级。窄屏先保留关键项，再将其余项放入可键盘操作的菜单。

```vue
<script setup lang="ts">
import { OverflowList } from '@arco-design/web-vue'

const labels = ['订单', '库存', '财务', '日志', '设置']
</script>

<template>
  <OverflowList :min="1" :margin="8" style="max-width: 320px; min-width: 0">
    <ATag v-for="label in labels" :key="label">{{ label }}</ATag>
    <template #overflow="{ number }"><ATag>另有 {{ number }} 项</ATag></template>
  </OverflowList>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/overflow-list) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/overflow-list)

## ResizeBox

用于鼠标拖动调整单个容器尺寸。它没有内置 min/max、键盘或触屏 resize，业务必须自行设定约束和替代操作。

- 当前接入：`AResizeBox` 已全局注册。
- 实际组件名：`AResizeBox`。
- 高频契约：两组受控状态为 `width` / `update:width` 与 `height` / `update:height`，应使用 `v-model:width`、`v-model:height` 回写；props 为 `directions`、`component`；事件依次为 `movingStart(event)`、`moving(size, event)`、`movingEnd(event)`。
- 可访问性与响应式：拖拽柄之外提供可键盘操作的尺寸预设或重置；容器要有业务最小尺寸。窄屏通常禁用横向拖拽，避免内容被压到不可用。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const width = ref(360)
const height = ref(220)
</script>

<template>
  <AResizeBox v-model:width="width" v-model:height="height" :directions="['right', 'bottom']">
    <section aria-label="可调整区域">静态内容</section>
  </AResizeBox>
</template>
```

## Scrollbar

用于需要统一滚动条样式的独立区域，不应包裹整个应用制造嵌套滚动。

- 当前接入：整包 plugin 运行时注册本组件，但全局模板类型缺失；TypeScript SFC 建议显式导入。
- 实际组件名：导出名 `Scrollbar`，运行时全局名 `AScrollbar`。
- 高频契约：props 为 `type`、`outer-class`、`outer-style`、`hide`、`disable-horizontal`、`disable-vertical`；事件为 `scroll`；实例 methods 为 `scrollTo()`、`scrollTop()`、`scrollLeft()`。普通 class/style 落在内部滚动容器，根节点用 outer props；归零使用 `scrollTo({ top: 0, left: 0 })`，不要依赖 `scrollTo(0, 0)` 的 truthy 分支。
- 可访问性与响应式：滚动区域要能用键盘到达并有可读名称；不能隐藏唯一焦点。窄屏避免双轴滚动，内容优先重排。

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Scrollbar } from '@arco-design/web-vue'

const scrollbar = ref<{ scrollTo: (options: { top: number; left: number }) => void }>()

function resetScroll() {
  scrollbar.value?.scrollTo({ top: 0, left: 0 })
}
</script>

<template>
  <AButton @click="resetScroll">返回区域起点</AButton>
  <Scrollbar ref="scrollbar" outer-class="detail-scroll" style="height: 220px">
    <div style="height: 640px">静态长内容</div>
  </Scrollbar>
</template>
```

## Split

用于拖动分隔两个同级面板。不是页面主布局，也不自动保存用户尺寸偏好。

- 当前接入：`ASplit` 已全局注册。
- 实际组件名：`ASplit`。
- 高频契约：受控状态为 `size` / `update:size`，应使用 `v-model:size`；props 为 `direction`、`min`、`max`、`disabled`；事件依次为 `moveStart(event)`、`moving(event)`、`moveEnd(event)`；slots 为 `first`、`second`、`resize-trigger`。数字 `size <= 1` 表示比例，`> 1` 表示 px；50% 应写 `0.5`，字符串 `"50%"` 会被解析成 50px。
- 可访问性与响应式：提供键盘可操作的尺寸预设或切换按钮，分隔柄有可读名称；窄屏切换为上下方向或单面板模式。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const size = ref(0.5)
</script>

<template>
  <ASplit v-model:size="size" :min="0.3" :max="0.7" style="height: 260px">
    <template #first>左侧静态内容</template>
    <template #second>右侧静态内容</template>
  </ASplit>
</template>
```

## Trigger

用于构建需要自定义定位、触发方式和弹层生命周期的底层浮层。常规提示、菜单和下拉框优先使用 Tooltip、Popover、Dropdown 或 Select。

- 当前接入：`ATrigger` 已全局注册。
- 实际组件名：`ATrigger`。
- 高频契约：受控状态为 `popupVisible` / `update:popupVisible`，`popupVisibleChange` 在可见意图变化时发出；`show` / `hide` 是进入或离开动画完成后的生命周期事件，不是公开 methods，也不等同于 `popupVisibleChange`。`trigger` 支持 `click`、`hover`、`focus`、`contextMenu` 及数组组合；props 还包括 `position`、`align-point`、`click-to-close`、`mouse-enter-delay`、`mouse-leave-delay`、`scrollToClose`、`popup-container`。
- DOM 与 attrs 边界：触发事件和 opened class 只注入默认 slot 的第一个元素，多节点必须包成单一 wrapper；按钮语义、ARIA 与原生 attrs 应写在真实 trigger button 上。普通 attrs 主要落在 popup，不要假设会自动转交触发器；2.58.0 没有公开 `updatePosition()`。
- 可访问性与响应式：自定义浮层必须自己管理展开状态、焦点进入/返回、Escape 和外部点击；纯 hover 同时支持 focus。窄屏重新核对定位与滚动关闭，避免浮层越界。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const popupVisible = ref(false)
</script>

<template>
  <ATrigger v-model:popup-visible="popupVisible" :trigger="['click', 'focus']" position="bottom">
    <button type="button" :aria-expanded="popupVisible">打开自定义浮层</button>
    <template #content>
      <div role="status">静态浮层内容</div>
    </template>
  </ATrigger>
</template>
```

## Watermark

用于展示声明性水印，不是防泄漏、鉴权或审计安全机制。

- 当前接入：`AWatermark` 已全局注册。
- 实际组件名：`AWatermark`。
- 高频契约：props 为 `content`、`image`、`width`、`height`、`gap`、`offset`、`rotate`、`font`、`z-index`、`alpha`、`anti-tamper`、`grayscale`、`repeat`、`staggered`；default slot 是被覆盖内容。初始化依赖 `window`、`document`、`canvas`，SSR 必须 client-only。
- 安全边界：`antiTamper` 只尝试恢复被改动的 DOM，不是安全防护；水印内容不得包含 token、密钥或个人敏感信息，真正的访问控制与审计仍由系统实现。
- 可访问性与响应式：水印不应降低正文对比度或拦截交互；读屏无需重复朗读。窄屏调整 gap、字号和旋转角度，但不遮挡关键内容。

```vue
<template>
  <AWatermark content="内部静态示例" :alpha="0.12" :gap="[80, 64]" anti-tamper>
    <ACard title="示例区域">此水印不代表安全控制。</ACard>
  </AWatermark>
</template>
```
