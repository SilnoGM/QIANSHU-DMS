# Arco Design Vue 数据展示组件

本册覆盖 `@arco-design/web-vue@2.58.0` 的 19 个数据展示家族。示例使用静态中文数据；真实页面仍需按业务契约处理空值、加载、错误、权限和大数据性能。

## Avatar

用于显示用户或对象的紧凑身份标识，优先使用图片，失败时以文字或图标降级。

- 当前接入：Avatar 家族已由 `app.use(ArcoVue)` 全局注册。
- 实际组件名：`AAvatar`、`AAvatarGroup`。
- 高频契约：`AAvatar` 使用 `shape`、`size`、`image-url`、`auto-fix-font-size`、`trigger-type`；事件为 `click`、`error`；slots 为 `default`、`trigger-icon`。`AAvatarGroup` 使用 `max-count`、`size`、`shape`、`z-index-ascend`，并通过 `max-style` 与 `max-popover-trigger-props` 控制溢出项。2.58.0 图片的原生 `alt` 固定为 `avatar`，没有 prop 可定制。
- 可访问性与响应式：需要准确身份名称时，在业务外层提供可访问名称或同时显示文字，不能依赖固定 `alt`；文字降级不得暴露敏感信息。头像组在窄屏限制展示数量，身份不能只靠颜色区分。

```vue
<script setup lang="ts">
const members = ['林', '周', '陈', '许']
</script>

<template>
  <AAvatarGroup :max-count="3" :size="36">
    <AAvatar v-for="member in members" :key="member">
      {{ member }}
    </AAvatar>
  </AAvatarGroup>
</template>
```

## Badge

用于在对象旁显示数量、状态点或短文本，不承担完整状态说明。

- 当前接入：`ABadge` 已随 Arco plugin 全局注册。
- 实际组件名：`ABadge`。
- 高频契约：props 为 `count`、`text`、`dot`、`dot-style`、`max-count`、`offset`、`status`、`color`；slot 为 `content`，默认 slot 是被标记对象。数值超过 `max-count` 时显示上限加号，`status` 适合语义状态点。
- 可访问性与响应式：数量或状态必须同时有可读文本；动态变化需要在业务层选择合适的 live region。窄屏避免徽标覆盖主内容。

```vue
<template>
  <ABadge :count="8" :max-count="99">
    <AButton>待处理事项</AButton>
  </ABadge>
</template>
```

## Calendar

用于按月或按年浏览日期数据；它不是带输入框的日期选择器。

- 当前接入：`ACalendar` 已全局注册。
- 实际组件名：`ACalendar`。
- 高频契约：`v-model` / `model-value` 是 `Date`；props 为 `mode`、`modes`、`default-mode`、`allow-select`、`panel`、`panel-width`、`panel-today-btn`、`day-start-of-week`、`is-week`；事件为 `change`、`panel-change`；slots 为 `header`、`default({ year, month, date })`。`mode` 没有 `update:mode`，传入受控值后内置模式切换不会回写业务状态；`panel-change` 只报告可见日期面板变化，不报告模式变化。需要受控切换模式时，由业务提供外部控件并直接更新 `mode`。只读展示也应明确当前日期与面板月份。
- 可访问性与响应式：日期格应保留键盘可达和当前日期提示；不要只用底色表达状态。窄屏优先 `panel` 模式或减少单元格附加内容。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const selectedDate = ref<Date>(new Date(2026, 6, 15))
</script>

<template>
  <ACalendar v-model="selectedDate" panel />
</template>
```

## Card

用于承载单一主题的信息与操作，不能用大量嵌套卡片替代信息层级。

- 当前接入：Card 家族已全局注册。
- 实际组件名：`ACard`、`ACardGrid`、`ACardMeta`。
- 高频契约：`ACard` 使用 `title`、`bordered`、`hoverable`、`loading`、`size`，slots 为 `title`、`extra`、`cover`、`actions`、`default`；`ACardGrid` 是卡片网格单元，hoverable 只提供悬浮样式，不自带点击语义；需要交互时应在单元内放置语义按钮或链接。`ACardMeta` 提供 `title`、`description`、`avatar` slots。
- 可访问性与响应式：卡片标题应进入真实 heading 层级；整卡可点击时避免内部再嵌套交互控件。窄屏网格切为单列，操作区允许换行。

```vue
<template>
  <ACard title="区域概览">
    <ACardGrid hoverable>
      <ACardMeta title="华东区域" description="静态示例数据" />
    </ACardGrid>
    <ACardGrid hoverable>
      <ACardMeta title="华南区域" description="静态示例数据" />
    </ACardGrid>
  </ACard>
</template>
```

## Carousel

用于轮播同等级内容；核心信息和关键操作不应只存在于自动切换的页面中。

- 当前接入：Carousel 家族已全局注册。
- 实际组件名：`ACarousel`、`ACarouselItem`。
- 高频契约：受控状态为数字 `current`，可用 `v-model:current`；公开 current 与 `change(index, prevIndex, isManual)` 的索引都从 1 开始。props 为 `auto-play`、`move-speed`、`animation-name`、`trigger`、`indicator-type`、`indicator-position`；slots 为 `default`、`previous`、`next`。
- 可访问性与响应式：自动播放必须可暂停，并尊重 reduced motion；键盘与读屏应能获知当前页。窄屏避免固定高度裁切正文。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const current = ref(1)
</script>

<template>
  <ACarousel v-model:current="current" :auto-play="false" indicator-type="line">
    <ACarouselItem>第一项：库存摘要</ACarouselItem>
    <ACarouselItem>第二项：订单摘要</ACarouselItem>
  </ACarousel>
</template>
```

## Collapse

用于折叠同一页面中的次要信息组，不用于隐藏必须先阅读的错误或关键操作。

- 当前接入：Collapse 家族已全局注册。
- 实际组件名：`ACollapse`、`ACollapseItem`。
- 高频契约：`activeKey` 在 2.58.0 中始终是 `(string | number)[]` 数组，`accordion` 模式也不改为单值；事件为 `change`。`ACollapseItem` 的 Vue 特殊 attribute `key` 同时作为面板身份，但它不是普通声明 prop；常用 props 为 `header`、`disabled`、`show-expand-icon`、`destroy-on-hide`，slots 为 `header`、`extra`、`expand-icon`、`default`。
- 可访问性与响应式：2.58.0 header 虽有 `role="button"`、`tabindex="0"` 与 `aria-expanded`，但只绑定 click，没有绑定 `keydown`，不能宣称 Enter / Space 会自动切换。需要完整键盘操作时须在项目封装层补充按键处理并做防双触发回归；这是业务补强，不是组件现成能力。header 仍应描述展开内容，且不要把唯一提交入口藏进默认关闭面板；窄屏让标题和 extra 操作分别换行。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const activeKey = ref<Array<string | number>>(['summary'])
</script>

<template>
  <ACollapse v-model:active-key="activeKey" accordion>
    <ACollapseItem key="summary" header="摘要">
      当前展示静态摘要。
    </ACollapseItem>
    <ACollapseItem key="detail" header="明细">
      当前展示静态明细。
    </ACollapseItem>
  </ACollapse>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/collapse) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/collapse)

## Comment

用于展示作者、时间、正文和操作组成的评论结构；编辑、审核和提交状态由业务层管理。

- 当前接入：`AComment` 已全局注册。
- 实际组件名：`AComment`。
- 高频契约：props 为 `author`、`avatar`、`content`、`datetime`、`align`；slots 为 `avatar`、`author`、`datetime`、`content`、`actions`、`default`。default slot 用于嵌套回复，应限制递归深度。
- 可访问性与响应式：作者与时间需要可读文本，操作按钮有明确名称；嵌套回复保持 DOM 顺序。窄屏操作组允许换行，长正文正常断词。

```vue
<template>
  <AComment author="示例用户" datetime="2026-07-15 10:30">
    <template #content>
      已完成静态数据核对。
    </template>
    <template #actions>
      <AButton type="text" size="small">回复</AButton>
    </template>
  </AComment>
</template>
```

## Descriptions

用于展示一个对象的标签—值明细，不适合高频编辑或大批量行数据。

- 当前接入：Descriptions 家族已全局注册。
- 实际组件名：`ADescriptions`、`ADescriptionsItem`。
- 高频契约：容器 props 为 `data`、`column`、`layout`、`align`、`bordered`、`size`、`label-style`、`value-style`；既可传 `data`，也可用 `ADescriptionsItem` 的 `label`、`span` 与 default slot。事件不是本家族核心契约。
- 可访问性与响应式：标签和值的关系必须可感知；空值使用统一文字而非空白。窄屏把 `column` 降为 1，避免横向滚动读取单个对象。

```vue
<template>
  <ADescriptions title="订单摘要" :column="1" bordered>
    <ADescriptionsItem label="订单状态">待审核</ADescriptionsItem>
    <ADescriptionsItem label="所属区域">华东区域</ADescriptionsItem>
  </ADescriptions>
</template>
```

## Empty

用于说明当前区域没有可展示数据，并给出原因或下一步动作。

- 当前接入：`AEmpty` 已全局注册。
- 实际组件名：`AEmpty`。
- 高频契约：props 为 `description`、`img-src`、`in-config-provider`；slots 为 `image`、`default`。默认 slot 用于描述，不会自动提供重试或创建动作。
- 可访问性与响应式：描述应区分首次无数据、筛选无结果和加载失败；装饰图像不重复朗读。窄屏保持行动按钮在可见区域。

```vue
<template>
  <AEmpty description="当前筛选条件下没有记录">
    <AButton type="primary">清除筛选</AButton>
  </AEmpty>
</template>
```

## Image

用于带加载、错误与预览状态的图片展示；不应假设所有图片都能加载或适合预览。

- 当前接入：Image 家族已全局注册。
- 实际组件名：`AImage`、`AImagePreview`、`AImagePreviewGroup`、`AImagePreviewAction`。
- 高频契约：`AImage` 以 `previewVisible` / `update:previewVisible` 控制自身预览，并发出 `preview-visible-change`；`AImagePreview` 以 `visible` / `update:visible` 控制单图预览，关闭事件是 `close`；`AImagePreviewGroup` 同时控制 `visible` 与数字 `current`，current 从 0 开始，运行时 `change(index)` 只传一个参数，不要依赖类型声明中的第二参数。常用 props 还有 `src`、`alt`、`width`、`height`、`fit`、`preview`、`footer-position`；2.58.0 没有 `lazy-load` prop，需要浏览器延迟加载时传原生 `loading="lazy"` attr。
- 自定义预览操作：家族还包括 `AImagePreviewAction`。2.58.0 的 `disabled` 只影响样式，不会阻止业务绑定的 click handler；自定义动作必须在 handler 内再次判断 disabled。
- 可访问性与响应式：信息图片提供准确 `alt`，装饰图片使用空 `alt`；错误 slot 说明加载失败。尺寸预留可减少布局跳动，窄屏用 `object-fit` 并避免预览工具条遮挡内容。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const visible = ref(false)
const current = ref(0)
const images = [
  '/browser_upgrade/chrome.png',
  '/browser_upgrade/edge.png',
]
</script>

<template>
  <AImagePreviewGroup v-model:visible="visible" v-model:current="current" infinite>
    <AImage v-for="(src, index) in images" :key="src" :src="src" :alt="`示例图片 ${index + 1}`" width="160" />
  </AImagePreviewGroup>
</template>
```

官方参考：[当前组件文档](https://arco.design/vue/component/image) · [2.58.0 source](https://github.com/arco-design/arco-design-vue/tree/2.58.0/packages/web-vue/components/image)

## List

用于同构条目列表、分页列表或虚拟列表；列关系复杂的记录改用 Table。

- 当前接入：List 家族已全局注册。
- 实际组件名：`AList`、`AListItem`、`AListItemMeta`。
- 高频契约：`AList` 使用 `data`、`bordered`、`split`、`loading`、`hoverable`、`pagination-props`、`grid-props`、`virtual-list-props`；事件为 `page-change`、`page-size-change`、`scroll`、`reach-bottom`；slots 为 `item`、`header`、`footer`、`scroll-loading`。Item 提供 `actions`、`extra`，Meta 提供 `avatar`、`title`、`description`。内容不足一屏时 `reach-bottom` 可能在挂载阶段触发，加载逻辑必须防重复。
- 可访问性与响应式：条目保持列表语义与稳定 key，加载更多状态可读；窄屏将 extra 内容移到正文下方。大数据使用虚拟列表时必须给出稳定高度并验证焦点回收。

```vue
<script setup lang="ts">
const records = [
  { id: 1, title: '待审核订单', description: '共 8 条静态记录' },
  { id: 2, title: '异常库存', description: '共 2 条静态记录' },
]
</script>

<template>
  <AList :data="records" bordered>
    <template #item="{ item }">
      <AListItem :key="item.id">
        <AListItemMeta :title="item.title" :description="item.description" />
      </AListItem>
    </template>
  </AList>
</template>
```

## Popover

用于触发器旁的补充说明或轻量交互；关键流程和长表单改用 Drawer 或 Modal。

- 当前接入：`APopover` 已全局注册。
- 实际组件名：`APopover`。
- 高频契约：受控状态为 `popup-visible` / `update:popup-visible`；props 为 `title`、`content`、`position`、`trigger`、`trigger-props`、`content-class`、`content-style`；事件为 `popup-visible-change`；slots 为 `default`、`title`、`content`。它基于 Trigger，定位与容器边界通过 `trigger-props` 调整。
- 可访问性与响应式：触发器必须可聚焦并有名称，纯 hover 内容同时支持 focus；关闭后焦点回到触发器。窄屏限制弹层宽度，不在弹层里堆叠复杂操作。

```vue
<template>
  <APopover title="字段说明" position="bottom">
    <AButton>查看说明</AButton>
    <template #content>
      该字段仅用于静态演示。
    </template>
  </APopover>
</template>
```

## Progress

用于展示已知进度或步骤状态；无法计算完成比例时使用 loading 或 Spin。

- 当前接入：`AProgress` 已全局注册。
- 实际组件名：`AProgress`。
- 高频契约：props 为 `percent`、`type`、`status`、`size`、`stroke-width`、`width`、`show-text`、`animation`、`steps`；slot 为 `text({ percent })`。`percent` 使用 0 到 1 的比例，不是 0 到 100。
- 可访问性与响应式：同时表达数值与状态文本，不能只依赖颜色；频繁变化要节流读屏通知。窄屏优先 line 类型并允许说明文字换行。

```vue
<template>
  <AProgress :percent="0.68" status="normal">
    <template #text="{ percent }">
      已完成 {{ Math.round(percent * 100) }}%
    </template>
  </AProgress>
</template>
```

## Statistic

用于突出显示数值或倒计时；趋势含义、单位和时间基准必须由业务明确。

- 当前接入：Statistic 家族已全局注册。
- 实际组件名：`AStatistic`、`ACountdown`。
- 高频契约：`AStatistic` 使用 `value`、`precision`、`separator`、`show-group-separator`、`value-from`、`start`、`animation`，slots 为 `title`、`prefix`、`suffix`；`ACountdown` 使用目标时间 `value`、`now`、`format`、`start`，并触发 `finish`。
- 可访问性与响应式：单位、时间区域和正负趋势要写成文本；动画数字应有稳定的可访问名称。窄屏避免字号撑破卡片，倒计时结束后更新语义状态。

```vue
<script setup lang="ts">
const deadline = Date.now() + 3_600_000
</script>

<template>
  <ASpace direction="vertical">
    <AStatistic title="待处理数量" :value="28" suffix="条" />
    <ACountdown title="静态演示倒计时" :value="deadline" format="HH:mm:ss" />
  </ASpace>
</template>
```

## Table

用于列关系明确的数据集。远端查询、虚拟化、选择和展开是不同状态域，必须分别建模，不能依赖组件内部状态拼出业务请求。

- 当前接入：Table 家族已全局注册。
- 实际组件名：`ATable`、`ATableColumn`，以及原生表结构组件 `AThead`、`ATbody`、`ATr`、`ATh`、`ATd`。
- 高频契约：核心 props 为 `columns`、`data`、`row-key`、`pagination`、`row-selection`、`expandable`、`scroll`、`selectedKeys`、`expandedKeys`。数组 columns 可使用 `dataIndex`、`slotName`、`titleSlotName`、`sortable`、`filterable`、`render`；声明式 `ATableColumn` 使用 props 与 `#cell`、`#title`，不接受数组配置专用的 `render` / `slotName`。受控状态通过 `update:selectedKeys` 与 `update:expandedKeys` 回写；methods 包括 `selectAll()`、`select()`、`expandAll()`、`expand()`、`resetFilters()`、`clearFilters()`、`resetSorters()`、`clearSorters()`。
- 本地与远端：本地排序传 `sortable.sorter` 函数，本地过滤传 `filterable.filter(values, record)` predicate。远端排序用 `sortable.sorter: true` 只发出意图；2.58.0 的 `TableSortable` 类型仍要求同时提供 `sortDirections`，所以严格 TypeScript 配置应写成 `{ sorter: true, sortDirections: ['ascend', 'descend'] }`。过滤没有“远程 `true`”捷径，不能把 `filter` 写成 `true`。由于 2.58.0 类型要求 filter 回调，服务端已过滤但仍需筛选 UI 时可显式传 `filter: () => true`，避免二次本地过滤，并在事件中发起查询。应监听 `sorter-change`、`filter-change` 或统一 `change(data, extra, currentData)`，其中 `extra.type` 是 `'pagination' | 'sorter' | 'filter' | 'drag'`，再由页面查询层替换当前页 `data`。`change` 第三个参数存在声明与运行时包装差异，不应当成原始业务记录。远端分页只传当前页记录并受控 `current`、`pageSize`、`total`。
- 选择与虚拟化：`row-selection.onlyCurrent` 决定翻页时是否只保留当前页选择；跨页选择必须由页面以稳定 `row-key` 保存，不能误读 `onlyCurrent`。启用 `virtual-list-props` 后核对 `height`、`threshold`、`fixedSize`、`estimatedSize`、`buffer`；固定行高优先 `fixedSize`，动态行高需合理 `estimatedSize`。虚拟模式与固定列、展开行、可变高度组合必须做真实滚动验证。
- 可访问性与响应式：列头、排序状态和选择名称必须可读；行操作按钮提供具体名称。窄屏优先卡片或抽屉式明细，不把桌面宽表直接压缩；确需横向滚动时固定关键列并提供滚动提示。

```vue
<script setup lang="ts">
import type { TableColumnData } from '@arco-design/web-vue'
import { ref } from 'vue'

interface RowRecord {
  id: number
  name: string
  status: string
}

type ChangeType = 'pagination' | 'sorter' | 'filter' | 'drag'

const selectedKeys = ref<Array<string | number>>([])
const expandedKeys = ref<Array<string | number>>([])
const rows: RowRecord[] = [
  { id: 1, name: '示例订单一', status: '待审核' },
  { id: 2, name: '示例订单二', status: '已完成' },
]
const columns = [
  { title: '订单', dataIndex: 'name', sortable: { sorter: true, sortDirections: ['ascend', 'descend'] } },
  { title: '状态', dataIndex: 'status' },
] satisfies TableColumnData[]

function handleChange(_data: RowRecord[], extra: { type: ChangeType }) {
  console.info('表格变化类型', extra.type)
}
</script>

<template>
  <ATable
    v-model:selected-keys="selectedKeys"
    v-model:expanded-keys="expandedKeys"
    row-key="id"
    :columns="columns"
    :data="rows"
    :pagination="{ current: 1, pageSize: 20, total: rows.length }"
    :row-selection="{ type: 'checkbox', showCheckedAll: true, onlyCurrent: false }"
    :virtual-list-props="{ height: 320, threshold: 80, fixedSize: true, estimatedSize: 44, buffer: 10 }"
    @change="handleChange"
  />
</template>
```

## Tag

用于短状态、分类或可关闭筛选条件；复杂信息应使用正文或 Popover。

- 当前接入：`ATag` 已全局注册。
- 实际组件名：`ATag`。
- 高频契约：显示状态由 `visible` / `update:visible` 控制，勾选状态由 `checked` / `update:checked` 控制；props 为 `color`、`size`、`bordered`、`closable`、`checkable`；事件为 `close`、`check`；slots 为 `default`、`icon`、`close-icon`。关闭与勾选是两套独立语义。
- 可访问性与响应式：颜色标签同时显示文字；可关闭项要有可读关闭名称，可选项要表达选中状态。窄屏标签组允许换行，不截断唯一含义。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const visible = ref(true)
const checked = ref(false)
</script>

<template>
  <ATag v-model:visible="visible" v-model:checked="checked" checkable closable color="arcoblue">
    待审核
  </ATag>
</template>
```

## Timeline

用于按时间或顺序呈现事件，不能替代需要列对比的数据表。

- 当前接入：Timeline 家族已全局注册。
- 实际组件名：`ATimeline`、`ATimelineItem`。
- 高频契约：容器使用 `reverse`、`direction`、`mode`、`pending`、`label-position`；Item 使用 `label`、`dot-color`、`dot-type`、`line-type`、`line-color`；slots 为 `default`、`dot`、`label`。pending 只表达进行中视觉，业务状态仍需文字。
- 可访问性与响应式：事件时间、状态和正文按 DOM 顺序可读；颜色点不是唯一状态。窄屏使用 vertical，长时间标签放到正文内避免挤压。

## Tooltip

用于解释短标签或图标，不承载必须阅读的正文和复杂交互。

- 当前接入：`ATooltip` 已全局注册。
- 实际组件名：`ATooltip`。
- 高频契约：受控状态为 `popup-visible` / `update:popup-visible`；props 为 `content`、`position`、`mini`、`background-color`、`content-class`、`content-style`；事件为 `popup-visible-change`；slots 为 `default`、`content`。2.58.0 没有公开 `trigger` prop，内置行为固定为 hover。
- 可访问性与响应式：图标触发器必须有可访问名称，tooltip 只是补充。需要键盘 focus 打开时，应显式受控 `popup-visible`，或改用可配置的 Popover / Trigger；触屏不能依赖 hover，窄屏避免长文本弹层越界。

```vue
import { ref } from 'vue'

<template>
  <ATooltip v-model:popup-visible="visible" content="刷新当前静态数据" position="top">
    <AButton aria-label="刷新当前数据" @focus="visible = true" @blur="visible = false">刷新</AButton>
  </ATooltip>
</template>
```

## Tree

用于浏览或选择层级数据。选择、勾选、半选和展开是四组独立状态，大数据、懒加载和过滤必须保留稳定 key。

- 当前接入：`ATree` 已全局注册。
- 实际组件名：`ATree`；2.58.0 没有公开 `ATreeNode`，节点由 `data` 描述。
- 高频契约：核心 props 为 `data`、`field-names`、`checkable`、`selectable`、`multiple`、`draggable`、`load-more`、`filter-tree-node`、`virtual-list-props`。四组受控状态为 `selectedKeys`、`checkedKeys`、`halfCheckedKeys`、`expandedKeys`；事件为 `select`、`check`、`expand`、`drag-start`、`drag-over`、`drag-leave`、`drop`。`checkStrictly` 控制独立勾选，`checkedStrategy` 只调整公开 keys；非严格模式的半选由级联关系计算。JS 配置名分别是 `fieldNames`、`loadMore`、`filterTreeNode`、`virtualListProps`。
- 2.58.0 限制：`defaultExpandAll` 默认 `true`，按指定 keys 初始化时通常要显式关闭。`searchValue` 只提供搜索值，必须配合 `filterTreeNode` 才会筛选。Tree 的 `loadMore(node)` 返回 Promise，业务需更新树数据；空 children 的叶节点应明确 `isLeaf: true`。`onlyCheckLeaf` 不会禁止用户点击父节点；必须限制时使用节点 `checkable` 或 `disableCheckbox`。
- 公开方法：实例 methods 包括 `scrollIntoView()`、`getCheckedNodes()`、`getSelectedNodes()`、`checkAll()`、`checkNode()`、`selectAll()`、`selectNode()`、`expandAll()`、`expandNode()`。命令式方法改变内部状态时仍要监听对应 update 事件，业务状态不能只留在组件实例中。
- 可访问性与响应式：2.58.0 输出没有完整的 `tree` / `treeitem` role、节点 `tabindex` 与方向键处理，不能暗示组件自动满足树形控件键盘规范。若业务要求完整键盘与读屏操作，应在项目封装层补齐语义、焦点漫游、展开、折叠与选择并做专项回归；这是业务补强。半选状态和加载失败也必须可读；窄屏控制层级缩进，大数据配置 `virtualListProps` 后验证滚动定位、异步节点与焦点恢复。

```vue
<script setup lang="ts">
import { ref } from 'vue'

const selectedKeys = ref<Array<string | number>>([])
const checkedKeys = ref<Array<string | number>>([])
const halfCheckedKeys = ref<Array<string | number>>([])
const expandedKeys = ref<Array<string | number>>(['orders'])
const treeData = [
  {
    key: 'orders',
    title: '订单中心',
    children: [
      { key: 'pending', title: '待审核订单' },
      { key: 'completed', title: '已完成订单' },
    ],
  },
]
</script>

<template>
  <ATree
    v-model:selected-keys="selectedKeys"
    v-model:checked-keys="checkedKeys"
    v-model:half-checked-keys="halfCheckedKeys"
    v-model:expanded-keys="expandedKeys"
    :data="treeData"
    :default-expand-all="false"
    checkable
    multiple
    :virtual-list-props="{ height: 280, threshold: 100 }"
  />
</template>
```
