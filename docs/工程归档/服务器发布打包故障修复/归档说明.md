## 4. 结果与归档原因

最终修复保持 archive inspector 对 hardlink member 的拒绝策略，只在 GNU tar 创建参数加入 `--hard-dereference`，将 filesystem hardlink 序列化为 regular file。普通 PR/main CI 的真实 packaging step、`CI gate`、Main CI 和正式 Release 均取得成功证据。

故障根因已修复并合并，安全边界由测试和当前发布规范继续维护；诊断过程与根因方案不再承担当前操作入口，因此按单一故障任务归档。
