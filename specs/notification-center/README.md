## 术语

| 术语 | 含义 |
| --- | --- |
| 通知中心 | 统一的通知域，管理站内与站外两个渠道 |
| 系统通知 | 业务模块调用的统一能力 `SystemNotificationService` |
| 站内通知 | 渠道 `IN_APP`，写入 `notification_inbox_items`，有已读/归档 |
| 千树小助理 | 渠道 `ASSISTANT`，经 GeWe 发送到微信，写入 `assistant_deliveries` |
| 逻辑通知 | `notifications` 表中的一条记录，一次发布对应一条 |
| 收件箱条目 | 站内渠道给每个用户创建的一条消息 |
| 站外交付 | 千树小助理给每个人或每个群的一次发送尝试 |
| 事件 | `eventType`，例如 `PURCHASE_REVIEW_PENDING` |
| 渠道策略 | 事件在某个渠道上的目标、模板、TTL、静默时段配置 |
| 绑定 | 员工与公司号、`wxid` 的映射，仅管理员维护 |
| 群目标 | 已登记的微信群，带 `internal_only` 标记 |
