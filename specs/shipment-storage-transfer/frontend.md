## 3. 寄仓列表

### 3.1 筛选

单列表 + 筛选（不做内地/海外两个页面）：

| 筛选项 | 控件 | 取值 |
|---|---|---|
| 位置范围 | `FaSelect` / 状态工具栏 | 全部 / 内地 / 海外 |
| 仓库 | `QsDictionarySelect` | 内地：`mainland.warehouse`；海外：`overseas.warehouse` |
| 状态 | `QsStatusSwitchToolbar` | 全部 / 在仓 / 已认领 / 已作废 |
| 关键字 | `FaInput` | 货件编号、唛头、来源销售单、来源采购单、客户 |

规则：

- 位置范围与仓库联动：选“海外”时仓库选项只出 `RF_TZ`/`RF_LK`；选“内地”时只出 `mainland.warehouse`；
- 默认停在“全部”，不默认过滤海外；
- 筛选状态写入 URL query，刷新可恢复；
- 空态文案区分“暂无寄仓记录”与“当前筛选无结果”。

### 3.2 列

| 列 | 内容 | 说明 |
|---|---|---|
| 货件编号 | `shipmentNo`，可复制 | 复用 `QsCopyableText` |
| 唛头 | `shippingMarkText` | 单行省略，悬浮完整 |
| 来源销售单 | 单号 + 客户 | 点击跳销售单详情 |
| 来源采购单 | 单号 + 供应商 | 点击跳采购单详情 |
| 位置 | 范围标签 + 仓库名 | 海外仓显示“瑞锋-台中仓”等 |
| 状态 | 在仓 / 已认领 / 已作废 | 语义色 |
| 入池时间 | `createdAt` | 上海时区 |
| 成本 | `AmountDisplay` | CNY，来自快照 |
| 操作 | 详情 / 移动位置 / 认领 | 按权限与状态显示 |

操作列遵循既有规则：最多两个行内动作，其余进“更多”；按钮不带前置图标。

### 3.3 详情抽屉

分区：

1. **货件**：编号、唛头、状态、来源销售单/采购单、出单人；
2. **位置**：当前范围与仓库、位置变更时间、位置变更历史；
3. **物流快照**：柜次、装柜时间、收件人、COD、重量体积；
4. **成本快照**：采购成本、包装成本、已付/未付、原出单人比例、个人腿/公司腿；
5. **归属时间线**：归属事件（创建 → 释放 → 认领）与操作人；
6. **认领信息**：新销售单、认领时间、认领人。

抽屉内只读，不放编辑；移动位置与认领是独立弹窗。

## 4. 释放

### 4.1 入口

| 入口 | 条件 |
|---|---|
| 货件列表行操作 | 货件 `ACTIVE`、未签收、已到仓 |
| 货件详情抽屉 | 同上 |
| 销售单终止流程 | 终止时选择要释放的货件 |

### 4.2 弹窗内容

| 区块 | 内容 |
|---|---|
| 货件摘要 | 编号、唛头、来源销售单、当前状态 |
| 位置 | 未装柜：只读展示 `destinationWarehouseValue`；已装柜：选择 `RF_TZ` / `RF_LK` |
| 原因 | 客户取消 / 客户拒收 / 其他（必填） |
| 备注 | 可空，500 字 |
| 成本预览 | 采购成本、包装成本、当前比例与两腿金额（只读） |
| 风险提示 | 释放后原销售单不可再操作该货件；物流事实冻结；认领后解除 |

交互：

- 未装柜时“位置”不出现选择器，只展示仓库名；
- 目的地仓库为空时禁用提交并提示“缺少目的地仓库，无法内地寄仓”；
- 提交按钮做 loading 与二次确认；
- 成功后关闭弹窗、刷新列表与详情、`toast.success`。

## 5. 位置移动

| 项 | 内容 |
|---|---|
| 入口 | 寄仓详情 → 移动位置 |
| 可选值 | `RF_TZ` / `RF_LK`，排除当前值 |
| 必填 | 原因 |
| 提示 | 只影响仓库记录，不影响成本、归属、唛头与物流事实 |
| 状态限制 | 仅 `IN_STORAGE` 可用；`CLAIMED` 后隐藏 |

## 6. 认领

### 6.1 入口

| 入口 | 说明 |
|---|---|
| 寄仓详情 → 认领 | 选择新销售单与销售行 |
| 销售单详情 → 从寄仓调货 | 预选当前销售单，打开同一弹窗 |

不新增“寄仓货物调货”采购模式；认领是独立动作，不伪造采购生命周期。

### 6.2 弹窗内容

| 区块 | 内容 |
|---|---|
| 寄仓货件摘要 | 编号、唛头、来源销售单、位置、成本 |
| 目标销售单 | `QsSalesOrderSelectorModal` 或等价选择器，只列 `CONFIRMED` |
| 销售行映射 | 目标销售单未移除的销售行，显示产品、数量、已覆盖数量 |
| 数量 | 首期整件认领，数量只读；显示“整件认领”说明 |
| 成本预览 | 池 → 新出单人的两腿金额（只读） |
| 提示 | 认领后货件归新销售单，覆盖与履约按新单推进；物流解冻 |

校验与反馈：

- 目标销售单不可为当前来源单；
- 销售行数量不足时禁用提交并提示；
- 已被其他单预留/认领时给出明确错误文案；
- 成功后关闭并跳转新销售单详情（可选）。

## 7. 销售单终止

| 项 | 内容 |
|---|---|
| 入口 | 销售订单列表“更多”→ 终止；详情页操作区 |
| 前置 | 订单 `CONFIRMED`；无待审核收款；按业务口径校验签收状态 |
| 弹窗 | 原因必填；列出将受影响的货件；说明采购单不会被取消、已收款不冲正 |
| 结果 | 状态显示“已终止”；货件进入可释放状态；复制一段终止摘要供通知 |

文案要求：明确“终止不是取消”，避免用户误以为采购单会被关闭。

## 8. 状态与权限

| 场景 | 规则 |
|---|---|
| 无 `shipment-storage:read` | 菜单不可见，直接访问路由跳 403 |
| 无 `release` | 释放按钮隐藏 |
| 无 `claim` | 认领按钮隐藏 |
| 无 `relocate` | 移动位置隐藏 |
| 货件已签收 | 释放不可用，按钮禁用并 `FaTooltip` 说明 |
| 寄仓已认领 | 移动与重复认领隐藏 |
| 池内货件 | 在货件列表与柜次“我的”中按归属自然消失，详情仍可按权限查看 |

## 10. 数据请求与缓存

- 使用生成的 API 客户端与现有请求封装，不手写 fetch；
- 释放/认领/移动成功后失效：寄仓列表、寄仓详情、货件列表/详情、销售单详情、柜次详情；
- 终止成功后失效：销售单列表/详情、货件列表、寄仓可用货件；
- 错误处理：409/422 用行内提示，不整页“加载失败”；网络错误用统一 toast。
