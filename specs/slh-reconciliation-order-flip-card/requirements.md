# 对账详情调货翻转卡 需求

## 1. 背景

顺联航对账行的来源是采购单的原销售订单（甲），但货件可能已经通过寄仓调货归属到当前销售订单（乙）。原详情页的「销售 + 采购」卡片只展示甲，财务看不到乙和调货过程。

## 2. 已确认口径

| 项 | 口径 |
| --- | --- |
| 适用范围 | 只在甲 ≠ 乙的调货行启用翻转卡；普通行继续使用原「销售 + 采购」卡片 |
| 正面 | 标题「调货后销售单」+ 当前销售订单乙 + 调货记录 |
| 背面 | 标题「原销售单」+ 原销售订单甲 + 甲采购订单信息 |
| 翻转入口 | 卡片右上角翻转图标，键盘可操作 |
| 调货记录 | 寄仓仓库、货件/柜号/唛头、来源销售单→调货后销售单、认领行数/数量、转移成本、变更摘要；寄仓时间/申请/审批/认领时间不在卡面 |
| 卡面布局 | 仓库胶囊更紧凑、固定宽度、超长省略；货件编号、柜号唛头分两行；来源销售单可点击直接翻到背面 |
| 认领明细 | 「N 行 / N 件」放在成本区块内，不带底色，悬停显示小手指，并用 Tooltip 列出产品名 × 数量 |
| 成本 | 转移成本做成独立区块，内含认领明细、总额与承担人；承担人参考「来源销售单 → 调货后销售单」，标签在上、人员在下并放大，中间箭头；只显示人，不展开个人/公司金额与比例，拆解放完整记录 |
| 变更摘要 | 卡面显示改收件人/改代收项数，末尾 info 图标悬停显示完整姓名/电话/地址/COD 前后值（方案 B，不遮蔽）；完整留痕仍在寄仓记录 |
| 完整记录 | 卡片底部固定「查看完整寄仓记录」，打开寄仓详情；无权限时禁用并提示 |
| 核对焦点 | 销售尾款改用当前销售订单乙，标签写「当前销售单 · 尾款」 |
| 数据 | 批次成员 DTO 新增 `transferRecord`；不新增数据库表 |

## 3. 验收

1. 打开调货演示批次，正面标题「调货后销售单」，内容是乙销售单 + 调货记录（成本区块 2,600.00、收件人 3 项、代收 0 项）。
2. 点右上角翻转图标，背面标题「原销售单」，内容是甲销售单 + 采购单；再点回正面。
3. 切换批次成员后卡片回到正面。
4. 普通非调货行不出现翻转图标，仍是原销售+采购双区块。
5. 核对焦点显示乙的尾款，标签为「当前销售单 · 尾款」。
6. 底部入口打开对应 `storageId` 的寄仓详情；无 `shipment-storage:read` 时禁用提示。
7. 减少动效下不播放 3D 翻转；背面内容对读屏器不可见。
8. 货件编号、柜号唛头分两行显示；仓库胶囊比上一版更小，长仓名显示省略号且悬停可看全称。
9. 点来源销售单号与点右上角翻转图标等效，都会翻到背面。
10. 「1 行 / 1 件」在成本区块内，无底色，悬停出现小手指，Tooltip 展示认领产品与数量。
11. 变更摘要末尾 info 图标悬停出现小手指，Tooltip 展示完整姓名/电话/地址/COD 前后值，且不出现滚动条。
12. 转移成本为带边框/底色的独立区块，内含认领明细、转移成本总额与承担人；承担人按「原承担人 / 现承担人」两列，标签在上、人员在下并放大，中间箭头；不出现金额或比例，缺失时该侧显示占位符。
