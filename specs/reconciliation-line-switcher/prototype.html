本原型已覆盖的边界

  1. 首项：上一条 置灰不可点（disabled，不做循环）；末项同理。
  2. 窗口贴边（已确认）：条带始终铺满 2×每侧项数+1 个真实项，无空槽占位；因此首尾处选中项会移动到条带两端，不再固定居中。
  3. 少于条带槽数：显示数组全部项，条带整体居中，宽度不随数据量跳动。
  4. 空数组：槽位区显示空态文案，上一条/下一条/展开 全部禁用。
  5. 展开再收起、切换数据规模与每侧项数：选中项保持不变（选中值由页面持有，本原型里是 state.selectedValue）。
  6. 展开形态左对齐（已确认）：末行不居中，与首行同一起始列。
  7. 键盘：组件内按 ← / → 等同于「上一条」/「下一条」，焦点跟随选中项。
  8. 窄容器：条带横向滚动并把选中槽滚回视口正中（261px 宽实测生效）。
接口设计草案（正式实现以此为契约）
// 调用方定义状态取值，组件只认 tone
type QsLineSwitcherTone = 'danger' | 'success' | 'warning' | 'neutral'

interface QsLineSwitcherItem {
  value: string         // 稳定标识，= 明细行 id
  label: string         // 唛头
  status: string        // 状态取值，仅用于查表
  statusLabel?: string  // 可选：无障碍朗读用的状态文案，缺省回退到 status
}

// 受控：选中项由页面持有（v-model），组件不擅自选择默认值
const model = defineModel<string | null>({ required: true })

props:
  items: readonly QsLineSwitcherItem[]              // 必填，顺序即左右顺序
  statusTones?: Readonly<Record<string, QsLineSwitcherTone>>  // 默认 {}，未登记状态回退 neutral
  visibleSideCount?: number                         // 默认 3；条带槽位数 = 2 * visibleSideCount + 1
  ariaLabel?: string                                // 默认「明细行切换」
// 形态（折叠/展开）是纯视图状态，组件内部持有，不外露
