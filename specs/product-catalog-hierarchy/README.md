# 产品分类与产品头改造（方案、原型与实施记录）

本目录保存勘察、方案、可交互原型与实施记录；实际实现位于 `server/` 与 `web/`。

## 文件

- `requirements.md`：勘察记录与历史需求稿；最终口径以 `implementation.md` 为准。
- `design.md`：历史技术设计稿；最终目录实体、外键、权限与状态设计见 `implementation.md`。
- `implementation.md`：**最终口径、提交、实际改动、验证结果与剩余风险**。
- `prototype.html`：独立单文件原型，保留历史交互演示；供应商必选、目录实体、空分类与启停以实际页面为准。

> 最终实现：供应商 → 分类目录 → 产品头目录 → 产品；分类/产品头按作用域唯一；产品供应商必填；
> 状态只保留启用/停用，新建默认启用并在列表操作列启停；选品必须先选供应商。

## 预览原型

直接打开：

```bash
open specs/product-catalog-hierarchy/prototype.html
```

或启动本地静态服务（便于在浏览器中反复刷新）：

```bash
cd specs/product-catalog-hierarchy
python3 -m http.server 4173 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:4173/prototype.html
```

## 原型可操作内容

1. 左侧分类列：全部 / 各分类 / 未分类，点击后筛选产品并重置滚动位置。
2. 顶部供应商下拉：筛选后分类数量同步变化，并重置到「全部」分类。
3. 产品卡片按「分类 · 产品头」分组；单分类视图下组头只显示产品头。
4. 点击卡片选择产品，右侧「已选择的产品」同步；再次点击已选卡片出现「增加数量」确认气泡。
5. 点击产品图片打开原图预览：支持 0.5x–3x 缩放、旋转、拖拽、Esc/遮罩关闭；点击卡片名称/编号/操作区才是选择产品。
6. 点击「确认添加」关闭弹窗并显示演示 Toast；点击背景「打开选择数据库产品」可重新打开。

原型使用内联 SVG 作为示例产品图，避免依赖网络图片；实际实现使用产品主图 `contentUrl` 与项目现有的 `useFaImagePreview()`。
