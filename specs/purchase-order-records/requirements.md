# 采购订单记录补齐

用户已确认本期结构与实施；migration 仅生成，不应用当前业务数据库。

- 当记录实际付款时，系统应保留 `DEPOSIT / BALANCE / OTHER`，凭证可选；只累加 `voidedAt IS NULL` 的所有类型付款，允许分次支付，禁止超付，累计等于采购总价时为 `PAID`。
- 采购约定应始终满足产品小计 = 采购总价 = 定金 + 尾款。
- 当归档订单凭证时，系统应支持采购单、付款凭证、签收单；付款凭证必须属于本单付款，其他两类不得关联付款。每单最多一张有效采购单，每次付款最多一张有效付款凭证，签收单可多张。
- 上传采购签收单只归档，不自动签收；凭证操作不能改写付款事实。
- 当发生状态变更时，系统应记录真实操作或自动推导原因；历史空原因展示“未记录原因”，不推测回填。
- 系统应提供约定金额变更前后快照、原因、操作人与时间的存储及查询展示结构。本期无修改金额入口，不凭空生成金额历史。
- 抽屉实际付款内保留付款凭证；订单凭证独立展示采购单、签收单；状态与金额记录合并倒序。不得恢复作废付款、下载、解除关联按钮。
