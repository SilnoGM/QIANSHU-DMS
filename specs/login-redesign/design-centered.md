## 1. 方向

这一版刻意不复用分栏版的品牌栏、Slogan、白色卡片、圆角输入框和绿色主按钮，改为 **单列「技术档案页」**：

- 页面只有一条居中的编辑式文档列，没有左右分栏。
- 去掉卡片边界和阴影，表单直接落在页面上；用 **左侧细线 + 绿色短标记** 定义文档边界。
- 输入框改为 **下划线式**，按钮改为 **黑底白字**（暗色下白底黑字），绿色只用于眉题、书脊、成功提示和按钮 hover。
- 背景是淡网格 + 大字「千树」描边水印，替代品牌栏的实色块。
- 信息按「文档头 / 品牌 lockup / 登录表单 / 文档尾」组织，字段带 `01 / 02` 索引，整体更接近技术手册或访问凭证，而不是营销式登录页。

目标：给分栏版之外一个完全不同的气质选项——更安静、更工程化、更少品牌装饰，但仍然保留千树的绿色识别。

## 2. 与分栏版的差异

| 维度 | 分栏版 | 居中档案版 |
| --- | --- | --- |
| 结构 | 左侧品牌栏 + 右侧表单区 | 单列文档，无分栏 |
| 背景 | 深绿→翠绿渐变、点阵、同心圆环 | 白/深底细网格 + 「千树」描边水印 |
| 品牌区 | 大面积绿色面板、Slogan、业务范围 | 文档头 + 圆形 Logo + 产品名，弱化品牌装饰 |
| 表单表面 | 520px 白色卡片、边框、轻阴影 | 无卡片；左侧 1px 书脊 + 56px 绿色短标记 |
| 输入框 | 44px 圆角描边框 | 48px 下划线输入，聚焦黑色下划线 |
| 主按钮 | 绿色实心 | 黑底白字（暗色白底黑字），hover 绿色 |
| 标题 | 欢迎登录 + 说明 | SECURE ACCESS + 登录工作台 + 索引字段 |
| 版本 | 底部说明「内部业务数据工作台 · v0.8.4版」 | 同位置，文档尾 |
| 气质 | 品牌展示、企业门户 | 技术文档、内部访问凭证 |

```text
│  ┃  ■ SIGN IN                                                │
│  ┃  登录工作台                                                │
│  ┃  使用管理员分配的账号继续                                   │
│  ┃                                                           │
│  ┃  01 账号 *                                                 │
│  ┃  [图标] 请输入账号                                          │
│  ┃  ───────────────────────────────────────                  │
│  ┃  02 密码 *                                                 │
│  ┃  [图标] 请输入登录密码                             [眼睛]    │
│  ┃  ───────────────────────────────────────                  │
│  ┃  [            登录系统                         → ]         │
│  ┃                                                           │
│  ┃  ───────────────────────────────────────                  │
│  ┃  内部业务数据工作台 · v0.8.4版                              │
│  ┃  Copyright © ...                                          │
└──────────────────────────────────────────────────────────────┘
        ↑ 整列约 560px，表单 420px，页内居中
```

- 外层 `.sheet` 最大 560px，左侧 1px 边框 + 56px 绿色书脊；页面垂直居中。
- 表单 `.auth-form` 最大 420px，左对齐于文档列；meta、masthead、footer 使用完整的 523px 内容宽度。
- 页脚放在文档列底部，版本与版权分两行，左侧对齐。
- 背景网格 48px；右下角「千树」大字描边水印，仅桌面显示。

### 3.2 窄屏（≤ 640px）

- 页面改为顶部对齐，内边距 28px/20px；文档列铺满宽度。
- 隐藏左侧书脊与大字水印，改用顶部 40×2px 绿色短线。
- 表单宽度 100%，输入框字号 16px（避免移动端缩放），按钮仍 48px。
- 390px 下实测：按钮距页面顶部 508–556px，页脚 596–668px，无横向溢出，均在 780px 设备框内。
- 640px 是这一版的响应式断点，不跟随后台框架的 1024px 分栏断点；因为没有横向分栏，需要更早收窄。

## 5. 交互与反馈

行为与分栏版一致，视觉状态换成本版语言：

- **校验**：blur 校验当前字段；submit 校验全部并聚焦首个错误；字段已出错后随输入立即恢复。
- **必填**：账号、密码都只校验非空；登录页不做 8–20 位密码校验，密码输入保留 20 字符上限。设置/修改密码页继续保留 8–20 规则。
- **错误文案**：账号空「请输入账号」；密码空「请输入密码」；401 展示为「账号或密码错误」（服务端仍返回 `INVALID_CREDENTIALS` + 原中文文案，展示层映射）。
- **全局错误**：放在说明与字段之间；左侧 2px 红线；429/503/网络错误沿用同一 callout；结果未知时提供「检查登录状态」，检查中显示「检查中…」。
- **提交**：按钮禁用、文字「登录中…」、spinner；输入框与密码可见性按钮同时禁用；`form[aria-busy=true]`；保留 `if (loading) return`。
- **密码可见性**：常显，带 `aria-label`「显示密码/隐藏密码」和 `aria-pressed`；隐藏用 `eye`，显示用 `eye-off`；清空后复位为隐藏。
- **回车**：真实 `<form>` 默认提交；密码可见性按钮 `type="button"`。
- **可访问性**：真实 label、`aria-required`、错误 `aria-describedby`、全局 `role="alert"`；Tab 顺序账号 → 密码 → 眼睛 → 登录系统。

## 8. 适用判断

- **选分栏版**：希望登录页承担品牌展示、首屏更有企业门户感，愿意保留较大面积品牌色。
- **选居中档案版**：希望更像内部工具/技术系统，信息密度低、品牌装饰少、单列阅读；适合不希望在登录页放大 Slogan 的场景。
- 两版可以共用同一套登录表单行为、错误码映射、按钮文案和测试更新，只替换 `views/login.vue` 外壳与表单视觉。
