功能新增
- 货件管理新增「已签收」状态和「签收」操作，已装柜的货件可以确认签收并填写签收备注。
- 销售订单确认签收后，订单下全部货件会同步变为已签收；反过来，订单下全部货件都签收且已上传订单签收单时，销售订单会自动完成签收。
- 货件新增「已签收」页签，可按签收状态筛选；货件详情新增签收记录。

功能优化
- 货件列表的状态和数量统计已包含已签收；「已装柜」页签只显示尚未签收的货件。
- 销售订单签收弹窗会明确提示将同步签收全部货件；若仍有货件未装柜或待审核，提交会被阻断并提示原因。
- 货件列表新增签收时间列（默认隐藏），可在列设置中打开。

缺陷修复
- 无

已知问题
- 如果只签收了货件、尚未上传销售订单签收单，销售订单会停留在待签收；补传签收单后才会自动完成签收。
- 货件签收目前只支持填写备注，不支持为每个货件单独上传签收凭证。
- 已签收的货件和销售订单都不能撤销，请在签收前核对。
