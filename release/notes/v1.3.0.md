本版影响角色：运营人员、财务人员、采运人员、系统管理员

功能新增
- 【运营人员】货件可以从销售订单释放进寄仓，并在寄仓管理页查看、移动仓库位置和查看成本。
- 【采运人员】寄仓货件可以调货给另一张待采购销售订单，支持提交调货申请由他人审批，也可以直接认领。
- 【运营人员】销售订单新增终止操作，未签收的货件可以在终止时释放进寄仓。
- 【财务人员】对账详情页新增调货记录翻转卡片，可以直接查看原销售单、当前销售单和采购信息。
- 【财务人员】结算时可以逐项选择由原销售单、当前销售单或公司承担，并分别入账。
- 【系统管理员】角色权限分配新增寄仓、调货相关权限，可以按岗位授予。

功能优化
- 【运营人员】寄仓列表和详情改版：显示产品图片、装柜唛头、来源单与当前位置，并支持复制信息和按状态筛选。
- 【运营人员】取消已认领寄仓货件的销售订单时，货件会自动退回寄仓池，不再需要手工处理。
- 【采运人员】调货弹窗会显示货件与销售行的对应关系；收件人和代收信息可以逐行修改，并生成可复制的通知内容。
- 【财务人员】结算弹窗的目标改为出单人加单号，增加应入账、应转出提示、金流费和合计核对。
- 【财务人员】核对记录的分摊明细改为全宽展示，能看到每笔费用归属、承担人和调整原因。
- 【运营人员】货件列表、装柜、入仓和签收会按货件当前归属显示和推进。

缺陷修复
- 【运营人员】修复取消已认领订单后货件仍显示为已认领、无法继续使用的问题。
- 【采运人员】修复采购可采数量未扣除已调货数量、导致超量采购的问题。
- 【财务人员】修复调货行结算金额和金流费按原销售单计算的问题。
- 【系统管理员】修复寄仓相关菜单、权限和错误提示不完整的问题。

已知问题
- 【运营人员】一次调货只能整件货件调走，暂不支持拆分部分数量。
- 【财务人员】顺联航对账结算暂只支持台币销售订单，其他币种订单不能按本流程结算。
- 【财务人员】账单比调货更早到达时，相关明细行要等货件被认领后才能继续对账；目前没有超期提醒清单。
- 【运营人员】客户退款仍需按线下流程处理，系统不会自动把已收款退回。
- 【系统管理员】寄仓查看权限可以看到所有仓库的成本和客户信息，授予时需要按岗位谨慎处理。
