对账
- 财务工作台的对账流程做成完整闭环：选账单建批次 → 逐行核对 → 完成本批对账。
- 对账详情页按明细行逐条核对：销售与采购资料、装柜明细、账单资料三块并排对照，另有三张卡把「销售尾款、装柜代收货款、账单代收货款」摆在一起供人工比对。
- 每一行的核对结果都会留痕：同一行可以重新核对，旧结果自动标为已被取代，历史结果在「查看核对记录」里按卡片逐条查看。
- 完成一批对账时按每行的最新核对结果自动入账：结算金额与金流费用分别计入对应人员的资金账户，个人与公司的分摊按账户管理里设置的比例拆分。账户或比例尚未配置时会阻止完成，并提示先去账户管理配置。
- 完成过程有进度提示（获取资金账户 → 确认规则和比例 → 执行入账），失败会立即结束并说明原因。

账单管理
- 账单列表的操作列可直接开始或继续对账：还没有批次的账单显示「开始对账」，已有未完成批次的显示「继续对账」并跳回那一批。
- 正在对账的账单会在对账状态旁标注所属批次号码；当前没有可核对行的账单不会进入对账流程，点击会说明原因。
- 上一次对账后剩下的明细行可以再开一轮新的对账，已核对的行不会被重复带入。

说明
- 顺联航账单对账位于财务工作台的「账单对账」分组下；账单的导入方式与之前一致，没有变化。
- 本版不改动其他工作台与其他页面的入口和操作方式。
